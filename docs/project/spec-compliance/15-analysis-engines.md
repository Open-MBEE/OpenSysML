## Analysis Engines (`internal/exec/analysis`) — OpenSysML extension, not a conformance claim

**Standard:** none. SysML v2 defines what an execution of a model is and what a condition evaluates to; it defines no notion of *how strong* the evidence behind a verdict is, nor which of several ways of asking about a model's executions a tool should use. The analysis framework (`docs/internals/design/analysis-framework.md`) is therefore an extension over the runtime: the interpreter stays normative, an engine is a way of asking about the executions it defines, and a disagreement between engines is resolved in the interpreter's favor.
