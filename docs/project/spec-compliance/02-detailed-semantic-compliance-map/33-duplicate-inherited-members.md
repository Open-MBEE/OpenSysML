### Duplicate Inherited Members, Usage Typing and KerML Specialization

25 Xpect rows on two defects: the duplicate-inherited-member warning masking a set of
unimplemented usage-typing and specialization constraints. The resolver's
`checkInheritedAmbiguity` canonicalizes redefinition, so a name reached through two supertypes
is a duplicate only where two distinct features survive (`Annex_A_VehicleViews.sysml` reports 6
diagnostics, none of them duplicate-inherited; `TestW11ADiamondRedefinitionIsNotDuplicate` guards
the pass-tier producer). The library index cache keys records by build identity
(`internal/workspace/libs`), so the differential is measured on a fresh cache; the figures are in
[pilot-differential.md](pilot-differential.md).
