### SysML Notation the Reference Accepts — the ten classes, adjudicated

The ten classes the 373 only-ours diagnostics on the two OMG SysML corpora once fell into,
adjudicated construct by construct against the pinned reference (pilot `2026-09`) in
[pilot-differential.md](pilot-differential.md). Each row names the production, where it is read
now, and the fixtures that pin it; the ⚠️ rows state what is still approximate.
The grammar production each row cites is in `build/pilot-grammars/SysML.xtext`.
