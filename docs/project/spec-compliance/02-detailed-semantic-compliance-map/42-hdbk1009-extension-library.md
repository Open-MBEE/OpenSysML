### HDBK1009 Extension Library (`OpenSysML Libraries/HDBK1009.sysml`; an OpenSysML extension, non-normative)

NASA-HDBK-1009A is modeling guidance written for SysML v1.7, not a modeling language; the library
carries its metamodel in SysML v2 terms (see `docs/project/hdbk1009-library.md`) and
`passes.HDBK1009Pass` audits a model against the relationships Figures 7-1 and 7-2 draw, as
warnings at the constraint tier. The rows claim agreement with the Handbook's figures, not with
SysML v2 semantics.
