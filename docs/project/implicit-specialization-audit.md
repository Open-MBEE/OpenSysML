# Implicit specialization audit

Every implied generalization this implementation adds — a base type a definition
kind specializes, a base feature a usage kind subsets, the owner feature a nested
usage subsets by its role, a role redefinition (`entry`, `render`, …) — audited
row by row against the two normative tables and the pilot's map.

Sources:

- KerML 1.1 Beta 2 §8.4 semantic library constraints (`check…Specialization`,
  `check…Redefinition`): 67 constraints, read from `build/spec-docs/kerml.txt`
  (`scripts/download-spec-examples.sh`; line numbers are `pdftotext -layout` lines).
- SysML v2 1.1 Beta 2 §8.4 implied specialization constraints: 123 constraints,
  `build/spec-docs/sysml.txt`.
- The pilot's `org.omg.sysml.util.ImplicitGeneralizationMap` at commit
  `38665073bbf02849bd309b106eba79cbb3a1ee1d` of
  Systems-Modeling/SysML-v2-Pilot-Implementation: 232 `put(metaclass, role, target)`
  entries, read only.
- Ours: `internal/semantic/semantics/implicit.go` (kind bases), `nested.go` (nested
  role subsettings), `roles.go` (role redefinitions), `connector.go` (end redefinitions
  and `participant`), `crossing.go`, `metadata.go`, `model.go` (`DirectSupertypes`
  assembles them). `file:line` is the literal of the library name in the current tree.

Verdicts describe the tree before this change: **match** — ours implies what the clause requires; **missing** — the clause's
general is not implied (a note says whether this change adds it, or why it cannot be
represented, with a reproducer); **wrong** — ours implied a different or extra general
(all fixed in this change); **spec-only** — the clause has no pilot map entry (marked on
the verdict); **pilot-only** — a pilot entry no clause requires (recorded, not copied).
Where the pilot and the spec differ, the spec is implemented and the difference noted.

Counts — KerML: {'missing': 28, 'match': 36, 'wrong': 3}; SysML: {'match': 82, 'missing': 30, 'wrong': 11}; pilot-only entries: 17.

`TestImpliedSpecializationAuditRows` (`internal/semantic/semantics/implicit_audit_test.go`)
proves every row this change fixes: the implied general is present and a member it
supplies resolves from the usage.
