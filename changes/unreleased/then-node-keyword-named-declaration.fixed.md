- **`then fork F;` declares the fork node F in a body that also declares a member named `fork`.** The lookahead read a control-node keyword followed by a name as a two-ended succession to the member sharing the keyword's name and rejected it; the grammar gives the keyword a declaration of its own (SysML.xtext `ForkNode`, `JoinNode`, `MergeNode`, `DecisionNode`), so the named, bodied and `then [m] fork F;` forms now declare the node, as they do in a body with no such member. Only the bare `then fork;` beside such a member still references it.
