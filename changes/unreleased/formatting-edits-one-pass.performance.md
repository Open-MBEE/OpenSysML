- The language server's Format Document and Format Selection now compute their edits in one pass over the document: the formatter's output pairs off with the original line by line, and only the runs of blank lines between can differ in length. The edits used to come from a shortest-edit-script search, whose cost grows with the square of the lines that change, so on a large file whose every line needed reindenting the search took longer than the formatter itself (1.4 times as long on eight copies of the largest standard-library file, 1.2 MB). They now cost about a quarter of the formatter's pass there and on the single file alike, which `BenchmarkFormattingEdits` in `tests/perf` reports as `diff/format`. The search remains for output that does not pair off with its input.
