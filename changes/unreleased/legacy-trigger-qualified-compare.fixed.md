- **A qualified legacy trigger beside the trigger structure reads back.** A graph carrying both a transition's `triggerAction` and an earlier mapping's `sysx:trigger` or `sysml:via` was refused when the text named the payload type or port by a different qualification than the structure writes (`sysx:trigger "T::Sig"` on `accept Sig`). Both spellings are now compared by the element they name from the transition, including quoted names with spaces, global `$::` names and standard library types, so agreeing names read and a name reaching another element is still refused.
