- **An inherited action or state machine is named by the subtype's qualified name.** `%action BigPlant::fill p`, where `BigPlant :> Plant` inherits `fill`, failed with `unresolved reference: BigPlant::fill`; only the declaring type's spelling, `Plant::fill`, was accepted, although the notation resolves the inherited name. The REPL's qualified-name lookup, and with it the gRPC `ExecuteAction`, `ExecuteState` and `ExportGraphs` symbol IDs and the symbols a session's `Perform`, `Instantiate` and `Send` name, now resolve a name the index registers no declaration under through the model's member lookup, so the inherited member — or the redefinition the subtype makes of it — is found, and runs on the object as its own feature. `%state`, `%graphs`, `%sweep` and every other command naming a behavior share the lookup. A name that resolves to nothing fails as before, with its suggestions.
