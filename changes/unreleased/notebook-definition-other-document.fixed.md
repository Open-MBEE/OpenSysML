- `sysml-lsp` answers a request on a notebook cell with the ranges of another file as that file states them: Go to Definition and Find References from a cell on a name declared in an imported `.sysml` file land on the declaration, as they do from a `.sysml` file, rather than on a position read as one of the notebook's own. A link's target and an item's selection range that name another file are kept the same way.
