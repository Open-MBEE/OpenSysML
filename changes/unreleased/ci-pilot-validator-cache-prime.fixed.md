- The pinned pilot validator's cache is now saved on `develop`, by `.github/workflows/pilot-validator-cache.yml` on every push and by the nightly oracle reproduction, and holds the Maven repository the build resolved beside `build/pilot-validator`. It was saved only by the run that built it, so a `rebaseline.yml` run, which shares no pull request's cache, missed it, built the validator from Maven Central and failed on HTTP 429 through all eight retries. Every job that needs the validator provisions it through `.github/actions/pilot-validator`, which falls back to the newest earlier entry when the pin moved, so a rebuild resolves its plugins and dependencies from the restored repository. `tests/hygiene` holds the policy in place.
