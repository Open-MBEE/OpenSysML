- A `for` loop's iteration variable is the `ReferenceUsage` the loop owns: its declared type is read, so `for component : Component in components { perform component.run; }` resolves `component.run` instead of reporting `no scope for member lookup in component`, and `GetElementProperties` returns the variable as the loop's `loopVariable`, its `nestedReference` and its first `ownedFeature`, under an `elementId` of its own. A conversion writes it as that element (`sysml:loopVariable`) with its typing rather than as the name alone, so a typed variable survives a round trip through the graph.
