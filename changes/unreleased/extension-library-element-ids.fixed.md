- A reference into one of OpenSysML's own libraries (`DocumentQueries`, `MOSA`, `OOSEM`, …) — a redefined or typing feature, a metadata or view usage's type, a feature reference's referent, an imported namespace — is written by element id (`{"@id": …}` in the API element form, an IRI with a library stub in Turtle) instead of a `{"@ref": "name"}` name reference, since every element has an `elementId` (KerML 8.3.2.1.2). The extension libraries' elements carry fixed, deterministic ids derived as the standard library's normative ids are, under the libraries' upstream URL rather than an OMG specification URL; hover reports one as `(extension, OpenSysML)`.
