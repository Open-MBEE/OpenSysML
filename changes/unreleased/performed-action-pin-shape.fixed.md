- A performed action's parameter is held in the shape its effective multiplicity gives it from the moment it is bound, on every surface alike: a `[1]` pin holds its one value bare and a pin written without a multiplicity, or `[0..*]`, holds a one-element sequence — in the action's results, `-json`, the trace, the performing object's slots and the gRPC `FeatureValue` — where before the frame side printed the value as computed (`5`) while the slots held `[5]`, and the trace's shape changed with the order the body read the pin in. Every consumer that takes one value takes the element of a one-element sequence, as KerML's sequence semantics give it: performer and start targets, called functions, vector and measurement-reference arguments, `ConvertQuantity`, binding-connector equality, a send's target, tool and solver inputs; a repeated step's pin reads are flat. Calculation results and case verdicts are still returned as computed.
