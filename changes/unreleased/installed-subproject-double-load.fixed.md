- A project installed as a sub-package of a repository (`pkg:git/<host>/<path>#packages/gears`) is read through its own installation alone: the usage's fragment names the sub-package (`gears` under the repository's owner) rather than the repository's project, and a directory below an installed project — or a member directory of an installed archive — that holds a `.project.json` of its own is a project of its own, not among the parent's files — whether the project or a file in it is named, in the language server's workspace, and in `-bundle`, which leaves the nested tree out of the parent's archive. Installing both the parent and the sub-package beside it no longer loads `Gears.sysml` twice (`note: Gears is opened by more than one loaded file`), and the sub-package's installation is the one its usage selects.
