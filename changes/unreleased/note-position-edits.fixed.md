- A `sysx:Note` edited in the graph in its position alone — its `sysx:noteToken`, `sysx:noteTrailing`, `sysx:noteOwnLine` or `sysx:noteTail` — is now written back at once when the graph is converted to notation: the source-backed element whose text states the note otherwise is rebuilt with the graph's notes put back, as an edited `sysx:noteText` already was, while an element whose notes the graph states as its text holds them is still written byte for byte. Previously the notes were compared by their text alone, so a position edit took effect only once the element was rebuilt for another reason.
