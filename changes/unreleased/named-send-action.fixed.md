- **A named send or assignment node is one element.** `action s send x to r;` was written as an `ActionUsage` named `s` owning an unnamed `SendActionUsage`, so a succession or reference to `s` reached an element that was not the send; it is now one `SendActionUsage` named `s` (SysML.xtext `SendNode`), as the unnamed `send x to r;` already was. `action a assign x := y;` is likewise one `AssignmentActionUsage` named `a`. Both convert back to the notation they were written in.
