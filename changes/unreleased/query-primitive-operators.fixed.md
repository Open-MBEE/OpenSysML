- The API & Services `Query` RPC now accepts all seven `PrimitiveConstraint` operators of §7.1.4: `<=`, `>=`, `in` (membership of the property's value in a list) and `instanceOf` (the element's metaclass conforms to a named metaclass, so a `PartUsage` is an instance of `Usage`, `Feature` and `Element`) join `=`, `<` and `>` in `sysml.proto`, the executor and every client translator, which refuse a malformed operand shape before sending.
