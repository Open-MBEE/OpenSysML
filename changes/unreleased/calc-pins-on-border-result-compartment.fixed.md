- Graphviz draws the parameter pins of an action or calculation on the node's border — squares on the top edge of the box for the inputs and the bottom edge for the outputs, as an interconnection's connected ports already were — instead of cells inside the node (SysML v2 §8.2.3.17, §8.2.3.19); an interconnection's ports under the full port display move to the border the same way. A palette's or `Style`'s fill now stops at the box rather than spreading under the pins, and a pin's name stands clear of the next pin. A calculation drawn by an action rendering is no longer noted `declares no nodes`: it shows the result expression its body states in a `result` compartment (§8.2.3.19 `result-compartment`) in the DOT, Mermaid, PlantUML, D2, draw.io and text forms; an action with an empty flow keeps the note (#1576).
