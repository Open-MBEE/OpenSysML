- A local declaring a name and a short name is one binding at run time: `attribute <s> x := 1; assign s := 5;` leaves `x` reading 5, and an assignment through either name is read through the other. This holds for an action's, calculation's or constraint body's locals and parameters, a local declared without a value, and a `for <s> i` variable; both names kept a value of their own before, so a write through one left the other stale. A nested block redeclaring the name leaves the short name writing the outer feature. A short name written in a nested action reaches its feature past an action between them that declares the long name, and an assertion still writes no feature of the action around it. A state behavior's write through the short name of an attribute of a state around it answers to that attribute's declared type and multiplicity, and one through the short name of the machine's attribute writes the machine's past a state attribute of the long name.
