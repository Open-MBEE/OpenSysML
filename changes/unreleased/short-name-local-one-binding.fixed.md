- A local declaring a name and a short name is one binding at run time: `attribute <s> x := 1; assign s := 5;` leaves `x` reading 5, and an assignment through either name is read through the other. This holds for an action's or calculation's locals and parameters, a local declared without a value, and a `for <s> i` variable; both names kept a value of their own before, so a write through one left the other stale. A nested block redeclaring the name leaves the short name writing the outer feature.
