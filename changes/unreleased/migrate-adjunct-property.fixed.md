- The SysML v1 migrator writes an «AdjunctProperty» and its `principal` — a connector, call action, object node, variable, parameter, submachine state or interaction use — as one usage, the principal's, instead of a `ref` usage for the property beside an unrelated usage for the principal. Association ends, connectors, allocations and diagram layout that named the property name that usage. A pair the collapse cannot cover (a missing or unwritten principal, one of another kind, in another owner, or typed otherwise) is written apart and the report says why; of the object nodes, a pin is collapsed on a call behavior action only. A SysML stereotype the migration gives no v2 form («ParticipantProperty», «moe», «objectiveFunction») is no longer reported as applied from a profile the document does not define.
