- A loaded file's qualified names are followed to the files beside and below it as its imports are: a file that names a root namespace only by qualified name (`view v : SYSMODViews::ProjectView`, with no import of `SYSMODViews`) now loads the file declaring that namespace too, so two library packages that import each other resolve when a model naming only one of them is loaded (`sysml -validate Consumer.sysml` with `private import SYSMOD::*;` reported `SYSMODViews::ProjectView` and three more unresolved; naming the project directory, which loads every file, did not).
