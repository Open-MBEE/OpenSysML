- **The lowered graph of an action or state machine is a public artifact.** `sysml model.sysml -graphs Pipeline::terrain [-o graphs.json]`, `%graphs <name>` in the REPL and the service's `ExportGraphs(model_hash, subject)` RPC (capability `export_graphs`) write the canonical `graphs:1` JSON an external analysis engine is sent — the subject's `ActionGraph`/`StateGraph` IR and that of every behavior it performs, with nodes, edges, flows, parameters, guards, triggers, effects and source spans — so a tool that drives a pipeline from a model, such as a workflow-DAG generator, reads the same lowered form the runtime executes rather than reparsing the notation. Every client exposes it: `Model.export_graphs(subject)` in Python, Julia and Rust, `model.exportGraphs(subject)` in Node, Java and MATLAB, `Client.ExportGraphs` in Go. An unknown subject is `NOT_FOUND`; an element that is no behavior is `INVALID_ARGUMENT`.
