- A symbol's members now include the unnamed members it inherits from the standard library (the anonymous connectors, bindings and invariants of `Occurrences::Occurrence` a part definition reaches, and the unnamed `doc` comments of its library supertypes, with `include_library_members`): each is listed under the positional id of the library type declaring it (`Occurrences::Occurrence::@47`), which `GetSymbol` resolves. They were left out because positional ids were derived for the model's own documents only. They take their place in inheritance order, so a library member may now precede one the model declares.
