- A succession written in a nested action, or in a `loop`/`while`/`for` or `if` body, is reported when an end names a feature the action does not feature — the enclosing definition's subject or part, or a node of the enclosing action (`Must be an accessible feature (use dot notation for nesting)`, KerML 1.1 §8.3.4.5.3 `checkConnectorTypeFeaturing`), as the OMG pilot reports it; such ends were silently accepted inside loop bodies and as the first end of `first x then y`. Successions written directly in the body that declares the feature are unchanged.
