- A usage that inherits a KerML type through subsetting or redefinition is judged by the same rule as one typed with it directly: a type its kind's standard-library base already specializes (such as `Base::Anything`) is redundant and no longer reported, while a KerML type of another metaclass (`attribute a : Objects::Object`) is now reported on the declaring usage as well as on the usages subsetting it. Flow usages now carry their implicit base `Flows::flows` (`Flows::messages` for a message, `Flows::successionFlows` for a succession flow).
