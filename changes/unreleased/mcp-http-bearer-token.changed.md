- **`sysml-mcp -http` on an address other machines reach** (`0.0.0.0:8765`, a host name) is refused at startup with exit status 2 and a message naming `-token-file`, `-token` and `OPENSYSML_MCP_TOKEN` unless a bearer token is configured; it was served with a warning that the server authenticates no one. A port alone or a loopback address is served as before, with no token, and enforces a token when one is given.
