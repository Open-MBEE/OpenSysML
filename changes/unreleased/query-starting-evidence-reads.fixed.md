- A projection after a filter no longer reads the excluded rows' features to collect operand evidence: evidence for a projected column is gathered only when a later filter compares that column, so an empty result cannot create lazy parts or start their behaviors in the live session. Reads of a held object's shadowing feature go through a rollback-safe runtime probe.
- Evidence for a projected column is gathered per column, so an unevaluable sibling property on an excluded row no longer discards a comparable shadow the later filter needs.
- A failed scan of the session's state activities is now reported on every read of the activity index instead of publishing an incomplete index that reports unvisited active states as inactive. Evidence from state, verdict and event rows no longer evaluates the built-in they may shadow, so an operand probe cannot start the activity scan or swallow its failure.
- A union or tree now keeps its own cells as evidence across later filters, so a projected comparable shadow removed by an earlier filter still validates the operand in either term order.
- Object-valued shadow evidence captures its value and provenance before the runtime probe rolls back, so a lazily created part can supply evidence without staying in the live session.
- Dotted operand evidence resolves every path segment inside one rollback-safe probe, so reading an excluded object's column neither materializes its lazy parts nor starts their behaviors.
