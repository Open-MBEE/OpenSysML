- An unresolved reference written as a short name, such as `[km]` in a model that imports `ISQ` but not `SI`, now offers the declaration and the import that makes the bare name visible (`did you mean SI::km? To use the bare name, import its package: private import SI::*;`) with the import as a quick fix, as a reference by primary name already did. A short name is a name of its element: `HasFQN` accepts `SI::km` for kilometre, so the suggestion table files the short-name path and `Declaring` finds it. A declaration named as written still ranks before one the name only reaches as a short name, so `min(1, 2)` offers the functions before the minute.
