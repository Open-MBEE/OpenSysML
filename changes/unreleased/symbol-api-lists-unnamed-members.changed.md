- The symbol kind of a binding connector (`bind a = b;`) is `bindingConnectorAsUsage`, after its SysML metaclass `BindingConnectorAsUsage` (SysML v2 8.3.13.2), instead of `bindingUsage`, which names no metaclass. It is what `SymbolInfo.kind`, `MemberInfo.kind` and the clients' `Symbol.kind` report; the Python client's `Symbol.bindings()` and `connections()` select by the new kind.
