- **An `ApplyEdits` batch resolves its references against the whole batch.** A succession (`first g;`, `then g;`, a guarded `then`) or a `#Tag` metadata prefix an operation writes may now name a member or metadata definition a later operation of the same batch declares, as typed members already could; the check runs once against the model the batch leaves, so operation order no longer decides it. Each reference is followed through the later operations' rewrites, so a rename of what it names, or of the declaration carrying it, is judged under the new name, and a duplicate prefix is refused whatever its target is renamed to. A reference nothing in the batch declares is refused as before, at the same operation and with the same message; a body that sequences `first g;` no longer keeps a member named `g` from being declared, nor hides a `g` the body inherits from a succession.
