- An action declared as a node — `action a accept …`, `action a assign …`, `perform action a`, `action a if …`, `action a while …`, `action a for …`, `action a terminate` — now reports the kind of that node (`acceptActionUsage`, `assignmentActionUsage`, `performActionUsage`, `ifActionUsage`, `whileLoopActionUsage`, `forLoopActionUsage`, `terminateActionUsage`; SysML v2 §8.2.2.17 ActionNode), and a `succession flow` reports `successionFlowUsage` (§8.2.2.14), on the symbol `kind`, the query `@type`, the reflective metaclass and in the API JSON and Turtle export, where a named `if`, `while` or `for` node is now written and read back as the element of its metaclass carrying the name. Before, every one of them was a plain `ActionUsage` or `FlowUsage`.
