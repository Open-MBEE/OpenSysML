- The SysML v1 XMI reader accepts XMI element serialization (XMI 2.5.1 § 9.4.4): a scalar property written as a child element with text (`<name>Vehicle</name>`, `<aggregation>composite</aggregation>`, `<body>…</body>`) reads as the attribute, a reference written as a child with `xmi:idref` or `href` (`<type xmi:idref="_6"/>`, a stereotype's `<base_Class xmi:idref="_5"/>`) as the reference, and repeated children as a multi-valued reference, the attribute winning where a document states a property both ways; a child carrying `xmi:type` or `xmi:id` stays an owned element. A document in that form migrated to `package unnamed` with anonymous, unmapped elements; it now migrates to the notation and report its attribute-form twin does.
