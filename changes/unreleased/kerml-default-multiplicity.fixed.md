- A feature that declares no multiplicity and inherits none now has the usual default `0..*` (KerML 1.1 §7.4.12, §7.4.5.2; SysML v2 §7.6.3) instead of an assumed `1..1`, so a KerML feature such as `class C { feature x : Real = (1.0, 2.0); }`, or a SysML attribute owned by a package, holds a default value of any count. The implicit `[1..1]` of an attribute, item, part or port usage owned by a definition or usage with no owned subsetting or redefinition, and of an end feature, is unchanged, and is now also inherited by a redefining usage and a requirement subject.
