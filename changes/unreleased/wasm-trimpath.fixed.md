- The documentation site's in-browser REPL module (`docs/assets/sysml-repl.wasm.gz`, built by `make docs-engine-assets`) is now linked with `-trimpath` and gzipped without a name or timestamp, as the release `sysml-prod.wasm.gz` is, so it no longer carries the build machine's checkout paths and its size no longer depends on them. The WebAssembly gate links every command with `-trimpath` too, so its size budgets measure what ships rather than what the checkout path adds.
