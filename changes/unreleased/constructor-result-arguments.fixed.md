- A constructor expression (`new T(1, "x")`, `new T(x = 1)`, `send new T(seq = 1) via link`) now has the shape KerML 8.3.4.8.3 gives it and the pilot writes: the expression owns only its `result`, which owns one `in` feature per argument, named after the feature of the instantiated type it values (through a `FeatureMembership`) and, for a named argument, redefining that feature; each argument's value is that feature's value, and `argument` lists the values in the instantiated type's declared feature order. Before, the arguments were the constructor's own parameters and a named form's `argument` was not derived. This holds in `%eval`, metaobject reads, query cells and gRPC `GetElementProperties`/`Evaluate`.
