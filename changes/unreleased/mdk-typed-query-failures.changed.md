- The Magic MDK plugin's *Run query* reads the typed outcome of a query the model has no answer for instead of a flat message: the run is `FAILED` rather than `ERROR`, with one outcome per path failure and per model finding worded as the CLI words them (`path error at Feature(mass): expected a feature named mass on the element; at Lander::lander::cabinEngine`, with the candidate members, features or kinds there and the nearest spelling), bounded lists ending `… and N more`. Each failure annotates the Cameo element its path stopped at, or the element a finding is about, and selects it from the results window; the `RunQuery` DocGen extension writes the same text into its outcome table. A refusal that carries no outcome is still one `ERROR` outcome with the service's message (`editors/mdk/README.md` § Run query).
