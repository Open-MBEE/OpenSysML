- **`include pay;` exports the `ReferenceSubsetting` SysML.ecore gives it.** The reference form of `IncludeUseCaseUsage` now owns a `ReferenceSubsetting` to the use case it includes (`ownedReferenceSubsetting`, `referencedFeature`) and states the derived `useCaseIncluded`, in Turtle and in the API element form alike, where it used to carry only the convenience `includes`. Import reads the inclusion from the `ReferenceSubsetting` alone, as the pilot's element form states it, and refuses a graph whose `includes` or `useCaseIncluded` names another use case. The declared form `include use case u : U` owns no `ReferenceSubsetting`, as before.
