- `sysml -import-diagram`, the LSP `opensysml/importDiagram` request, the MCP `import_diagram` tool and the VS Code *Import Diagram* command read three more kinds of edit back from a draw.io file: an element renamed by retyping its cell's text (applied as a rename, so its declaration and every reference move, through the path a `Layout` of the cell takes), a note whose text was edited, and a picture whose image source was changed to a file the model can name. A label edited beyond its name, a name SysML does not accept, a rename the model refuses, copies of one element renamed differently, an emptied note and a picture turned into embedded data are reported and left alone.
