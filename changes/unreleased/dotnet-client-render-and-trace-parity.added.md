- The .NET client traces an action run and posts events to its performer: `RunOptions.Trace` on `ExecuteActionAsync` returns `ActionRun.Trace` and `TraceDropped` (and keeps the partial trace on `ExecutionException`), gated on `Capabilities.ActionTrace`, and `RunOptions.Events` posts signals or items to the object `PerformerSymbolId` names, as the REPL's `%send` does. A trace or events under an exploring schedule, events with no performer, and events given to a state run through `RunOptions` are refused before anything is sent. A `DocumentEvent` carries an action record's `Token`, `Step`, assigned `Feature` and `Value`.
- The .NET client reads a rendered view's `Frame` (`ViewFrame`: name, view definition, exposes, filters and annotations), a node's `Arrow` and `Parallel`, and a `LibraryReference`'s `LibraryPath`, the positional path that names an inherited unnamed library member.
