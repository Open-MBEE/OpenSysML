- The `smt` analysis engine refuses an action whose steps are two usages of one action definition, each stating a flow of its own, the way it refuses any other nested flow: `not encoded: node one: nested flow: a node stating a flow of its own is encoded by a later stage`, an unsupported-construct refusal naming the step. Before, the same model was reported as `malformed action flow: node a: the initial node is not among the flow's nodes`, naming a node of the shared definition, because the encoder told the two steps' nodes apart by their declaration. The model is refused either way; no well-formed flow is. The `initial node is not among the flow's nodes` report no longer exists: a flow's initial node is always one of its own.
