- Packages that publicly import one another in a cycle analyse in time polynomial in their number again (issue #633): since imported memberships are read with the namespaces being read excluded, every route through such a cycle was searched and enumerated on its own, so fifteen mutually importing packages took over half a minute and thirty did not finish. Where every namespace the imports reach is a package with plain namespace imports and no name is declared twice among them, reading each namespace once finds what the routes do, and that is what is done; any other import is read route by route as before. Thirty such packages validate in under three seconds.
