- An attribute a state or action definition declares over its own occurrence features — `size(entryAction)`, `size(en)`, `size(subperformances)`, a nested `part fresh` — reads the performance's features: the exhibited machine's or performed action's own, not the exhibiting part's same-named feature nor an object of the bare declaration. A held-image copy of such a machine re-derives the attribute instead of answering `no value for feature entryAction`, a machine re-derives it after a feature it reads is written, and `size(subperformances)` and `size(enclosedPerformances)` in a state definition count the machine's performances rather than the part's.
