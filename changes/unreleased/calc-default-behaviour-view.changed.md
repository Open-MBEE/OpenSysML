- Calculation definitions and usages are drawn with the action (behaviour) rendering, as action definitions and usages are: `%viz A::add` and a view exposing a calc default to it, `#action:` accepts a calc, and its directed parameters are the node's pins, an unnamed `return` parameter the pin named `result` — where the TREE kind drew `in x` and `return : Integer` as attributes and the action kind drew nothing. An action's or calculation's parameter pins are now always drawn, in every form, as part of the node's notation (`%viz A::add` prints `in x`, `in y`, `out result` with no `show=` argument); `parameter-symbols` keeps governing a case's parameter symbols alone.
