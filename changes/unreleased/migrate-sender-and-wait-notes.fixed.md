- **The migrator's ledger counts a send action as a sender only once it is written, and a button of the tool's UI prototype as posting the signals it specializes.** An accept of a signal is noted as waiting for a message only the tool's UI posts when no written send sends it or a signal specializing it — a send left as a placeholder, which performs nothing, no longer hides the note — and a button posting a specialization of the accepted signal now raises it. A send whose port is not the sender's keeps the note on its arguments beside the one on its port, and an entry, exit or transition effect is noted as waiting for the clock only for a wait the writer writes, not for a time event or duration constraint it leaves as a placeholder, nor for one in a behavior named by a call written as a placeholder or never firing, which invokes nothing.
