- A tree rendering (`-render '#tree:…'`, `%viz`, the Jupyter kernel's default) drew the directed parameters of a calculation, action or constraint definition or usage — `in x`, `out y`, `return` — as `attribute` members with membership edges, and an anonymous `return` as a bare `attribute`. They are now parameter pins of their owner's node, direction first (`in x : Integer`), the anonymous result named `result` as the standard names it; a usage typed by a definition shows each parameter once, the definition's as inherited. The text form lists them under the node, DOT and D2 draw them as pins, Mermaid and PlantUML list them in a `parameters` compartment.
