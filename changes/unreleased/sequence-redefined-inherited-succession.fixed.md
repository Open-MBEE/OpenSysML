- A sequence rendering draws only the redefining succession on a lifeline that redefines a named
  succession it inherits (`part client :> source { succession s2 :>> s first sent then got; }`):
  the inherited `s` was drawn there as a second arrow beside `s2`. Lifelines that only inherit `s`
  still draw it, and a redefining succession that states no ends (`succession s2 :>> s;`) is drawn
  over the ends it inherits.
