- **SysML syntax highlighting in JupyterLab 4 and Notebook 7, shipped with the kernel's pip package.** `pip install jupyter-opensysml-kernel` now installs `jupyterlab-opensysml`, a prebuilt JupyterLab extension (`editors/jupyterlab`), as shared data under `share/jupyter/labextensions`, in every platform wheel and the sdist — no Node.js, no `jupyter labextension install`. It registers the `sysml` (`text/x-sysml`, `.sysml`) and `kerml` (`text/x-kerml`, `.kerml`) CodeMirror languages, so the cells of a `sysml` notebook, `.sysml`/`.kerml` files in the editor and Markdown fences tagged `sysml` are highlighted: keywords, contextual keywords, comments and `doc` bodies, strings, numbers, unrestricted and qualified names, operators, and a cell's leading `%command`. The keyword tables are generated from the lexer by the VS Code grammar generator (`make vscode-grammar`) and gated by a test, and the kernel now reports `language_info.codemirror_mode = "sysml"`.
