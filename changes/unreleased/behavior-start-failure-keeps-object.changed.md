- A behavior a type exhibits or performs that cannot start — or fails while the creation runs it to quiescence — no longer fails the object's creation: the object stands, the failure is recorded on that behavior (`%features` shows it as `failed: …`, `%instantiate` and the `-satisfy` verdicts print a `warning:` line, the Instantiate RPCs carry a `behavior-start-failed` diagnostic), and a satisfy, constraint, requirement or verification verdict that reads a feature the failed behavior may still write is reported undecided rather than pass/fail. A bound of the runtime's own (objects, steps, events) and a structural failure of the creation still roll it back (#1858).
