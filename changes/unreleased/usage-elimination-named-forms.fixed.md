- A usage that names no installed project by publisher and name is linked by elimination only when its resource spells where the project is kept rather than the project — a version-control package URL (`pkg:git/`, `pkg:svn/`, `pkg:hg/`) or a plain URL; every other `pkg:<type>/<publisher>/<name>` form is matched by name alone and stays unresolved when that project is not installed, where before it could fall back to the one unrelated installed project. The warning for a usage several unclaimed projects could answer names the candidates that left it undecided.
