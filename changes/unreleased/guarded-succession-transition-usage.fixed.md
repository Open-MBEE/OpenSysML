- **A guarded succession exports as a `TransitionUsage`.** `first a if g then b;` and `succession s first a if g then b;` (SysML.xtext `GuardedSuccession`), and a decision's `if g then b;` and `else b;` (`GuardedTargetSuccession`, `DefaultTargetSuccession`), are now `TransitionUsage`s in Turtle and in the API element form alike — with `source`, `target`, the guard through a `TransitionFeatureMembership` of kind `guard` stated as `guardExpression`, and the owned `then` succession — where they used to be `SuccessionAsUsage`s carrying the guard as an extension predicate; the unguarded `then b;` and `succession first a then b;` stay `SuccessionAsUsage`s. Import writes each form back as written, so a keyword-less succession in an action body never comes back as `transition …`, which an action body does not admit. Execution is unchanged: a guarded succession lowers as before.
