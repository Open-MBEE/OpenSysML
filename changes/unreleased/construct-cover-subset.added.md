- `OPENSYSML_CORPUS_SUBSET=construct-cover` makes every test that sweeps the models under `examples/` iterate only `tests/corpus/testdata/construct_cover.txt`, the 95 of the 880 files that between them exhibit all 814 syntactic features the whole corpus exhibits; unset, the sweeps iterate the whole corpus as before, and any other value fails them. `TestConstructCover` re-derives the features over the whole corpus on every run and fails, naming them, when the list no longer covers it (`-update-construct-cover` re-records it), and no recorder flag runs under the subset.
