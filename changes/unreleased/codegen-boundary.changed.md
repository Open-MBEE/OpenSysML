- `internal/translate/codegen`, the native compilation backend behind `sysml -compile`, is reached only from `cmd/sysml` and the black-box suite `tests/codegen`; `tests/hygiene` pins that boundary over every package's imports, tests included. The differential contract against the interpreter and its fixture moved from `internal/frontend/repl` to `tests/codegen`, and the compiler's record and `<unset>` refusal tests from `internal/exec/runtime` to the codegen package, so a build or test run of the runtime no longer compiles the backend.
