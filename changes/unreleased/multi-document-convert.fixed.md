- Convert a model of several documents into one graph: `sysml lib.sysml app.sysml -convert ttl|api-json` and the service's `Convert` over a multi-document `model_hash` now write every document of the model, resolved against each other — a reference into another document links to the element it declares — rather than refusing or silently converting one file. Each document's top-level elements are marked `sysx:sourceDocument` and wrapped under a root `Namespace` of their own, which the reader accepts and writes back as one notation. A notation target, standard input, a repository branch or a non-notation input still converts one document only. A graph that already carries one document's wrapper keeps it and wraps the remaining bare roots under their own root `Namespace`, and `-o` naming a repository branch is refused: several documents write a file or standard output, not a branch.
