- `sysml-mcp -http` runs as a service: `GET /health` (liveness, the build) and `GET /ready` (200 once the workspace is indexed and the runtime prewarmed, 503 `starting` before and `draining` while stopping) answer without a token and outside the origin policy, and a protocol request that arrives before readiness is answered 503 with `Retry-After`; `-shutdown-timeout` (30s) and `-max-body-bytes` (4 MiB, 413 over it) bound the transport; every flag is read from `OPENSYSML_MCP_<FLAG>` when the command line leaves it unset, through the flag's own validation, the flag winning, with `OPENSYSML_MCP_TOKEN_FILE` joining `OPENSYSML_MCP_TOKEN`. `sysml-mcp` ships in the `openmbee/opensysml` image; `deploy/sysml-mcp/` holds a Compose example behind a TLS-terminating proxy and a systemd unit; the guide *Running sysml-mcp as a service* covers them.
