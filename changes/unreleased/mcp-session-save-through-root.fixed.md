- A `sysml-mcp` session save (`session_save`, `%save` through `repl_command`) writes through an `os.Root` opened at the resolved workspace root, as the `lsp` tools already did, so a symlink repointed out of the root between the path check and the write can no longer carry the file outside the workspace; the write stays atomic (a temporary file renamed over the target) and keeps an existing file's mode. The bare `sysml` prompt, which has no root, writes as before.
