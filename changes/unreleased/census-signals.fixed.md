- **A migrated SysML v1 send signal action addresses the object its target pin holds.** A send whose target pin a read-self action feeds is now written `send new S() to target;` with the pin defaulted to `this`, and one whose target pin nothing fills names the pin (`to target`) instead of being written with no receiver. The transformation census records SendSignalAction and its sub-mappings, ReplyAction, UnmarshallAction and BroadcastSignalAction as faithful and AcceptCallAction as deliberate, with candidate errata for the payload's InvocationExpression, the dropped onPort and AcceptCallAction's target.
