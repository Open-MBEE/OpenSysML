- The release SBOMs now cover every asset class: the WebAssembly modules (`sysml-wasm.wasm`, `sysml-prod.wasm.gz`), written by `scripts/release-sbom.py` from the module information Go embeds in them, which `go version -m` and syft cannot read from this format; the npm tarballs `openmbee-opensysml-<x.y.z>.tgz`, `openmbee-sysml-mcp-<x.y.z>.tgz` and `openmbee-opensysml-mcp-<x.y.z>.tgz`, now packed by a `build-npm-package` job before the manifest so that tarballs and SBOMs are lines of `SHA256SUMS.txt` and `publish-npm` publishes bytes the signed manifest lists, each SBOM describing the packed manifest with its dependencies resolved through the lockfile; and the Windows installer, whose `opensysml-<x.y.z>-windows-amd64.msi.spdx.json` is derived from its inputs — the Go executables and the bundled Z3 release declared from `packaging/msi/z3.pin` with its version and digests — and listed in `SHA256SUMS-windows-msi.txt` (and, signed, in `SHA256SUMS-windows-signed.txt`).
