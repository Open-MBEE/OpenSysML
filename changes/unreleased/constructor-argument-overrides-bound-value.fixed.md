- A constructor argument that binds a feature whose value is written with `=` — `new A(x = 2)` or `new A(2)` under `item def A { attribute x : Integer = 1; }` — is now reported as overriding that binding value (KerML 8.3.4.10.2), with the same message and `default =` hint the redefinition form `attribute :>> x = 2` already draws; a `default =` value and an unvalued feature still take the argument.
