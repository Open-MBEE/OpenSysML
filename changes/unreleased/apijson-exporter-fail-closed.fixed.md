- `pilot-apijson-diff` no longer records or accepts a baseline from a pilot JSON exporter that never ran: the launcher that `scripts/download-pilot-json-exporter.sh` writes now exits 78 rather than 1 when Java 21, the pinned jar or the library is missing, the referee refuses a run that exits 78, or exits 1 with an `Error:` line or no document written, and `-check` and `-update` refuse a run in which the pilot failed on every file of a root; each error names the provisioning script. Before, such a run filed every file as `pilotFailed`, `-update` recorded it and a later `-check` on the same broken exporter passed.
