- A membership import of an alias now imports the alias `Membership` itself wherever the alias is reached (KerML 1.1 §8.2.3.4.2): `import ISQ::TemperatureValue;` states the alias membership a standard library package declares, under the id this implementation mints for it, rather than the owning membership of the element the alias names. The RDF and `api-json` forms, the notation written back from them and the reflective `importedMembership` of a `MembershipImport` agree, including for an alias named through a namespace that only imports it.
