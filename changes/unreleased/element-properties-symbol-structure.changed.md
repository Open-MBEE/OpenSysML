- **`GetElementProperties` reads the symbol-backed metamodel structure.** The RPC evaluates an element's metamodel properties over `metamodel.SymbolStructure`, the structure projected from the symbols the model resolved to, instead of the API element form converted from the whole-model RDF graph; `Convert` and the api-json writer keep their path. An element no symbol id names (an expression, a relationship) is addressed by a path from its nearest addressed owner (`Owner::x.r1` is the second relationship `Owner::x` owns, `Owner::x.r1.e0` the first element that relationship owns). A feature's bound value is read from its `FeatureValue` (`value`), which is where the metamodel declares it; standard-library elements keep answering from their library document's form.
