- RDF export writes `sysml:qualifiedName` in the spelling KerML derives it in (§8.3.2.1.2 `escapedName()`), as `api-json` and the pilot do: a part named `two words` reads `Observatory::Holder::'two words'` rather than the bare `Observatory::Holder::two words`. The mapping's own address, which the element IRI encodes and references resolve by, is stated beside it as `sysx:mappingQualifiedName` wherever the two differ, and a reader takes the address from either, so a graph written by an earlier release still reads back.
