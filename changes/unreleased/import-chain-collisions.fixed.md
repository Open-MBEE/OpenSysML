- **Resolving a name through an import no longer computes the import collisions of every namespace down the chain of imports.** Enumerating what a namespace import brings consulted the imported namespace's own collisions (the memberships KerML 7.2.5.4 hides) even when every member it reached was the namespace's own, which no collision can hide; over a workspace analyzed one document at a time that made the work quadratic in the length of the import chain. The collisions are now computed only where an import contributed a member.
