- **Relationships written as notation (`:`, `:>`, `:>>`, `::>`, `=>`, `~`, `conjugates`, `subsets`, `redefines`, `references`, `crosses`) now reflect as metaobjects.** Each written relationship on an element is reachable from `x meta` and the reflective feature layer as a `Subclassification`, `FeatureTyping`, `Subsetting`, `Redefinition`, `ReferenceSubsetting`, `CrossSubsetting`, `Conjugation`, `Specialization` or `ConjugatedPortTyping` object with its `source`/`target` ends and owner-side features (`ownedSpecialization`, `ownedSubsetting`, `ownedRedefinition`, `ownedConjugator`, …) in textual order, so the `SysMLValidation` library now states seven relationship-valued constraints that `-self-check` evaluates (48 constraints in total). Membership relationships (`ownedRelationship`, `membership`, `ownedImport`) and feature-chain targets (`crosses a.b`) are not yet derived, an extended definition (`#service def X`) classifies as Definition, and the `includes` notation of `include use case uc : UC` reflects no relationship.
