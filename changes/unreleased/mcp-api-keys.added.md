- `sysml-mcp` mints and revokes API keys for people and CI: `-mint-api-key -api-keys FILE -subject NAME -scopes a,b [-expires DUR]` prints a key `osk_<id>.<secret>` once and appends its record — the SHA-256 of the secret, the subject, scopes, expiry and whether it is disabled, one JSON object per line — and `-revoke-api-key ID` marks the record disabled. The `internal/frontend/guard/apikey` store reads such a file as an authenticator of the guard, re-reading it when it changes and on demand so a key minted or revoked takes effect without a restart (`docs/reference/sysml-mcp.md` § API keys).
