- **A JavaScript body's assignment to a name nothing declares creates it.** The v1 migrator refused the whole body when a script assigned a name no pin, parameter, property or local bore (`tdiffOld = tdiff;`), so an effect accumulating a duration ran nothing and the duration stayed 0. A JavaScript body now declares such a name a local `attribute` of the action, typed by the assigned expression, as the tool's script engine creates the variable, and reports the declaration as an approximation. A name some scope declares but the body may not read, a name read before it is assigned, and every such name in a Java body stay refused.
- **A v1 `ReadStructuralFeatureAction`'s result keeps its pin's multiplicity.** The migrator wrote every read as `out result[1]`, so reading a feature declared optional or plural was a multiplicity violation at run time whenever it held none or several; the result is now `out result[0..*]`, `[0..1]`, … as the pin declares.
