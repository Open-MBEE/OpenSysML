- **The project is named OpenSysML MDK.** The Runtime Environment and Development Kit is the second generation of OpenMBEE's Model Development Kit, and MDK now names it in the README, the documentation site, the contributor guide and the landing page where it used to be called the OpenSysML REDK. The description, the repository, the Go module path, the `opensysml` package and registry names, the binaries, the release assets, the `OPENSYSML_*` environment variables and the RE/DK build names are unchanged. The Cameo Systems Modeler plugin under `editors/mdk/`, until now itself named OpenSysML MDK, is OpenSysML MDK for Cameo; its Maven coordinates, plugin id, Java packages and the `OpenSysML MDK DocGen` profile it writes into models keep their names.
