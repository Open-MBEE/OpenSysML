- The VS Code diagram panel no longer creates model elements: the toolbar's **Add…** list and the node menu's **Add …** and **… from here…** entries are gone, since new members and connections are written in the text. The panel keeps **Go to declaration**, **Rename…**, **Move to…**, **Delete…**, dragging a node or an edge's waypoint, and <kbd>Shift</kbd>+drop to reparent. The server's `addMember` and `addConnection` operations are unchanged for the language server's `opensysml/applyModelEdit`, gRPC and MCP clients.
