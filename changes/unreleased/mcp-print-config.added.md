- **`sysml-mcp -print-config <host>`** writes the configuration block that declares the server to an agent host — `opencode`, `claude-code`, `cursor`, `codex`, `vscode`, `gemini` or `devin` — naming the binary by its absolute path, or by the command `-print-config-command` gives; alone, the flag lists the hosts. The checkout's `opencode.json` declares the server beside the language server, and `sysml-mcp` ships as its own per-platform archive (`sysml-mcp-<os>-<arch>.tar.gz`, `.zip` on Windows) that `install.sh`/`install.ps1` (`OPENSYSML_TOOLS`), Homebrew, Scoop and the Windows MSI install; the winget manifest carries the `opensysml` bundle alone.
