- **`-self-check-package <QualifiedName>` applies the constraint defs of a package the loaded files declare in the same element walk as the bundled `SysMLValidation` rules.** Repeatable and implying `-self-check`: a rule is a `constraint def` whose first `in` parameter is typed by a `SysML::…` or `KerML::…` metaclass, applied to every element the metaclass conforms to and named by its qualified name when it fails; rules that cannot apply warn, unknown packages refuse the run, and a rule package's own elements are never checked. See `examples/self-check-rules/`.
