- `GetSymbol` lists the two ends of a connection, interface or binding usage in `childIds` and `members` as symbols of kind `connectorEnd`, and resolves each: a named end under its qualified name, an end written without a name (`connect q to r`, `bind x.o = y.o`) under the element id `GetElementProperties` already answers for it (`Owner__c_pend0`). Each end's `specializations` report the feature it references, read from the same end the element properties reflect (`connectorEnd` → `ownedReferenceSubsetting` → `referencedFeature`); a reference written as a feature chain (`x.p`), on an end or on any `::>`, is one `references` entry per chaining feature in chain order where it used to be dropped. Before, an unnamed end was not listed at all and a chained end referenced nothing.
