- **A `@Tag;` metadata usage is a queryable element.** A metadata usage written in the prefix spelling, `@Tag;` or `@Tag { ... }`, was declared as no member of its namespace unless it was named, so `sysml -query` and the gRPC/Python `model.query()` omitted it (`rdf:type="MetadataUsage"` found `metadata Tag;` but not `@Tag;`) while the API JSON export listed it. It is now an anonymous member exactly as the `metadata` spelling is, identified by its position (`Q::S::@0`), and the `owner` a query reports for a member of such a body is the annotation usage (`Q::V::@0`), not the metaclass its body resolves against.
