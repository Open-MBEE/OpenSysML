- **Reject `frame`, `filter` and `accept` members written outside the bodies that own them.** A `frame` is a RequirementBodyItem — a requirement, concern or viewpoint body, never a view's; a `filter` is a PackageBodyElement and a view/view-def body item — a package or the file root admits it, a viewpoint, rendering or part-def body does not; an `accept` is an ActionBodyItem — an action, calculation or case body (and the state body that already read it), not a view or part def. Each is now reported at the member instead of parsing silently, matching the reference grammar.
- **Report `then <target>;`, `if <guard> then <target>;` and `else <target>;` written outside an action or state body.** A target succession sequences members of an action, calculation or case body, and a state body reads it as a target transition; anywhere else it is OpenSysML extension notation, warned by default and rejected under `-strict`.
- **`%view` no longer asks a view to frame the concerns its satisfied viewpoint frames.** Viewpoint conformance is evaluated over the concern the *viewpoint* frames, applied to the elements the view exposes; `frame` was never legal in a view body, so a view with a valid viewpoint now reports `conforms`/`violated` instead of a framing mismatch it could never satisfy.
