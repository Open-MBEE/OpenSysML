- Renderings mark a usage inherited by the owner it is drawn or listed under — through typing, subclassification or subsetting — with the graphical notation's `^` before its name (SysML v2.1 §8.2.3.6): node heads, compartment rows, pinned ports and folded membership-edge labels in the text, Mermaid, DOT, PlantUML and D2 forms and on the VS Code canvas; a redefinition the owner declares reads bare. The rendering data, the LSP `render` result and the gRPC `RenderView` answer carry the mark as a new `inherited` field on nodes and ports beside the unchanged bare name, which the Java, Python, Node and Rust clients expose.
