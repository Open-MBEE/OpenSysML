- The SysML v1 migrator writes a DocGen `TableExpressionColumn` written in an OCL subset — navigation chains, `->size()`, `->select`, `->exists`, `->collect`, `oclAsType`, `=`/`<>`, `and`/`or`/`not`, literals — as a `Column` computed over the row when the document's queries run: `_typedElementOfType->size()` counts the features typed by the row, a connector's `end…propertyPath` walks the ends' feature chains to the parts they pass through, their types and flow direction. An expression outside the subset is still refused with the expression quoted.
- A DocGen column whose own chain collects before it reads (`CollectOwnedElements`, `CollectTypes`, a metaclass, stereotype or name filter, then `Name`/`Documentation`) is written as a `Column` applying the chain's query operations to the row and reading the attribute of every element collected; a step with no query spelling, or whose result only the elements known at migration spell (`CollectByAssociation`), keeps refusing the column with the step quoted.
- A DocGen `StructuredQuery` or `Dynamic View` with `loop = true` is written once per element the chain collected, each pass over that element alone — one table (list, figure) per element behind its bullet, or one section per element when `createSections` is set — instead of one table over all of them.
- `DocumentQueries::Distinct` keeps each element of a collection once, in first-seen order, and the query evaluator runs the standard library's `SequenceFunctions` and `ControlFunctions` (`size`, `last`, `excluding`, `select`, `collect`, `exists`, …) over row-relative collections in a `Column` cell — a connection's `connectorEnd`, an end's `chainingFeature`, `RelatedElements(source = row, …)`.
