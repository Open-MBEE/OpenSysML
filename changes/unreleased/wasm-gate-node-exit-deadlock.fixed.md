- **The WebAssembly gate no longer hangs at random in Node's exit under `-race` on CI, and a hang it does hit is explained in the log.** The `js` target runs under `node --single-threaded`: Node exits by joining V8's worker threads, and a worker still compiling (Sparkplug earlier, Maglev now) can wait for a garbage collection the exiting main thread never runs, so `sysml -version` printed its answer and then sat until the two-minute deadline. With every compile and GC task on the main thread there is no worker for the exit to wait on. The deadline itself now reads the process's `/proc` state before killing it and reports the elapsed time, the command, the resident size and every thread's state beside the output so far, and that path has a test of its own against a runtime that never exits.
