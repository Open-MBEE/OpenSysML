- **A hidden import is not inherited.** An imported membership that KerML 7.2.5.4 hides — one colliding with another import's name or with an owned name of the importing namespace — is no membership of that namespace, so a type specializing it no longer inherits the hidden member: `view v :> Introduction;`, where `Introduction` exposes two parts' `payload`, no longer draws `Duplicate of inherited member name 'payload'` at `v`. The `Duplicate of imported member name` warning on the import itself is unchanged.
