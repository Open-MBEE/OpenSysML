- **A SysML v1 model is migrated with `-migrate`, its own verb.** `sysml Model.mdzip -migrate sysml -o Model.sysml -migration-report Model.report.txt` reads a Cameo/MagicDraw `.mdzip`, a UML XMI `.xmi` or an Eclipse UML2 `.uml` export — `-from xmi|uml|mdzip` names one whose extension does not — and writes SysML v2 notation or RDF Turtle through the same mapping as before, byte for byte. The verb says what happens: a migration is ledgered, not lossless, and every v1 element lands in the report as mapped, approximated, unmapped or skipped. The companion flags `-migration-report`, `-migration-results`, `-layout`, `-image-base-url` and `-strict` accompany `-migrate`; a v2 input is refused with a pointer at `-convert`. The help has a Migration topic of its own, and the man page follows it.
- **The service migrates with a `Migrate` RPC.** It takes a `file_path` or inline `content` bytes (so a `.mdzip` archive travels), `from_format`, `to_format` and the command's options — `report`, `results`, `layout_path`/`layout_content`, `image_base_url`, `strict` — and answers the migrated content, the canonical formats, the experimental notice and a `MigrationReport` whose summary and verdict counts always come back, with every element's `MigrationEntry` and the report text when `report` is set, the `-migration-results` sidecar when `results` is, and the image files the migration extracts. The `migrate` capability advertises it; the conformance suite covers the migration and both refusals.
- **Every client migrates.** Go `MigrateFile`/`MigrateSource` with `WithV1Format`, `WithMigrationReport`, `WithMigrationResults`, `WithLayoutFile`/`WithLayout`, `WithImageBaseURL` and `WithStrict`; Python `Connection.migrate()` and `opensysml.migrate()` answering a `Migration` with its `MigrationReport`; Java `Connection.migrate`/`migrateFile` with `MigrationOptions` answering a `Migration`; Node `connection.migrate()` answering a `Migration` whose image files `save()` writes beside the notation, with `convert()` refusing a v1 model by format or extension; the Rust and Julia generated bindings carry the RPC, and the conformance runners of every client read binary fixtures.
