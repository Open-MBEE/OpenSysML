- The API JSON element form names a feature the same way whether it reads the symbol table or the structure alone, as KerML derives Feature::effectiveName from the naming feature (§8.3.3.3.4): a `satisfy … by s` or `subject = s` parameter by the subject it redefines (`subj`, or the definition's subject), a chained connector end by the end it occupies rather than by the chain it references, an expression body's parameter (`{ in i; … }`) as an element of its own beside the body, a transition's `do` statement without a name (its action subsets `TransitionAction::effect`, SysML §8.4.11), and an `alias` Membership without one (the alias is its memberName). The structure differential is re-recorded on that footing.
