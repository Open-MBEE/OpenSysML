- Connector-end accessibility (`Must be an accessible feature (use dot notation for nesting)`) now rejects an end spelled as a definition's owned feature by qualified name (`allocate ToastBread::applyHeat to Toaster::heating` at package level, and the `connect`, `bind`, `flow`, `interface` and KerML `connector`/`binding`/`flow` forms of it), as the pilot does. A connector with no featuring type reaches only features that have none, so a feature owned by a definition was wrongly treated as package-level and exempted. Dot-notation chains, ends of the owner's own or inherited features, `interface def`/`connection def` end parameters, package-level connectors between package-level usages, variants and enumeration literals stay accepted.
