- `usage-typing` now fires on a usage typed by a feature chain that resolves to a feature (`part p : rig.wheel;`), as it does on a usage typed by a feature by name: a usage's types are classifiers, nominally definitions (SysML v2 §8.3.6.4 `Usage::definition`), so the chain's last feature is checked against the usage's kind rule and reported in the pilot's words (`A usage must be typed by definitions.`, `An occurrence, item or part must be typed by occurrence definitions.` and the per-kind siblings). A conjugated port typing is `~` followed by a qualified name (SysML v2 §8.2.2.12 `ConjugatedPortTyping`); a feature chain after `~` (`port plug : ~hub.socket;`) is now a syntax error rather than silently accepted.
