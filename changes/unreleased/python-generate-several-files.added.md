- `python -m opensysml.generate` (and `opensysml-generate`) accepts a model of several files the way `sysml` does — the `.sysml`/`.kerml` files in order, or a directory read in path order — and parses them as one model through `ParseSources`, so a part typed by a definition in another file is generated as that class instead of failing with an unresolved reference; `--package NAME` (repeatable) restricts the output to one package and its nested packages. One file still goes through `ParseFile` and generates the same module as before; a module of several files is stamped with the hash of the files' hashes in order, and `--check` names every source and `--package` in its regeneration command.
