- The MCP language tools convert positions without copying the document: turning an edit's position into a byte offset copied the rest of the text once per line before it, so the cost grew with the square of the document, and reporting a position copied the text before it or split the whole document into lines. On a 5,000-line document one edit position takes about 65 µs instead of 170 ms and allocates nothing instead of 656 MB (`BenchmarkByteOffset`); the positions and edits the tools answer do not change.
