- A feature listed through a conjugated port now reports its direction as that port sees it: `GetSymbolRequest.member_of` (capability `symbol_member_direction`, `memberOf` over JSON and MCP, `AsMemberOf` in the Go client) names the type a symbol is read as a feature of, and the Python client's `children()`, `members()`, `attributes()` and `parts()` pass the symbol that lists the member, so `out attribute cmd` reads `in` through `port pIn : ~CmdPort`. `GetElementProperties` now also reverses `input` and `output` for a port that subsets or redefines a conjugated one (#2200).
