- `sysml-mcp` confines every file a tool touches to `-root` through one shared check, `toolkit.Root`, for the workspace, runtime and session tool groups alike. The groups now agree: a dangling symlink is judged by where it points, so one leading out of the root is refused by the workspace and runtime tools too; every group reports a refused path with the same wording; and a `-root` that does not exist is refused at startup.
