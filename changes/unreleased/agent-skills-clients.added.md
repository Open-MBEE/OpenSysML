- **Agent skills for every OpenSysML client.** `packaging/agent-skills/` adds `opensysml-go`,
  `opensysml-node`, `opensysml-java`, `opensysml-rust`, `opensysml-julia` and `opensysml-matlab`
  beside `opensysml-python`, so an LLM coding agent can parse, evaluate, instantiate, run and verify
  a model from any supported language: installing the client and resolving `sysml-grpc`, requiring
  a clean model, the language's value types and integer pitfalls, and how its errors separate a
  refused call from a reported model failure.
