- Renaming a feature to its own short name is no longer refused as a capture when a reference reaches it through a feature declaring no name of its own (KerML 1.1 §8.3.3.3): with `attribute <m> mass;` redefined by `:>> mass;` in `heavy`, renaming `mass` to `m` rewrites `heavy::mass` to `heavy::m`, which still names the same feature. A feature of another name that the new name would reach is still refused as a capture.
