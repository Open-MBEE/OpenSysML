- Every release now publishes an SPDX 2.3 JSON software bill of materials per asset, `<asset>.spdx.json`, for each archive, wheel, sdist, `sysml-grpc` and `sysml-jupyter-kernel` binary. `scripts/release-sbom.py` writes them with a pinned syft before the checksum manifest, checks each against the Go build information of the binaries it describes, and lists them in `SHA256SUMS.txt`, so the existing cosign signature and SLSA provenance cover them.
