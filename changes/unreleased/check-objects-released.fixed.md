- A check no longer leaves the objects it constructs in the runtime. The value of a constructor expression a condition evaluates (`require constraint { (new P()).x > 0 }`), of a subject's binding (`subject v = new P();`), of a bound subrequirement (`requirement s[0..1] : R = new R();`) or of a calc the check invokes is released when the check ends, with the objects it holds and the behaviors it started, whatever the verdict; an object the model comes to hold through the check (a feature's value, a package-level usage's binding) stays. Before, every check left one object per constructor it evaluated, so a session checking repeatedly (the REPL, the language server, the gRPC service) grew until it reached its object bound and refused further checks.
