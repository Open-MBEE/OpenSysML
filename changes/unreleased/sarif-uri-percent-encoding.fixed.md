- **A SARIF report names a file by a URI.** `sysml -validate -format sarif` and the pilot differential's SARIF wrote a file's path into `artifactLocation.uri` as spelled, so a space, a `#`, a `?`, a `%` or a non-ASCII letter in it made a `uri` that is no URI reference (SARIF 2.1.0 §3.4.3) and that a code-scanning service could not place. The path is now percent-encoded there (`my dir/a #1.sysml` is `my%20dir/a%20%231.sysml`); the JSON report, a `-baseline` and the JUnit report keep the path as spelled.
