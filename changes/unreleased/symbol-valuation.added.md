- `SymbolInfo.valuation` and `AttributeInfo.valuation` (gRPC), `Symbol.valuation` and `AttributeFacts.valuation` (Python), and the `valueExpression`, `valueExpressionKind` and `valueExpressionReference` query properties describe the value expression a feature declares — its source text, kind, `default`/`:=` flags and the features it reads as resolvable symbol-id paths — so a binding such as `in power = powerPort.power;` or `powerPort.power * 2.0`, which has no constant value, is no longer invisible to clients. `Valuation.evaluated` is what the expression evaluates to through the features it reads (`usage_a.prop_a` with `:>> prop_a = 100.0` gives `100.0`), so a written value can be told from none and `AttributeFacts.value` stays the model-level constant. Reported under the `valuation` capability.
