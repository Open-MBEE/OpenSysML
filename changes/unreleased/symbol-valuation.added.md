- `SymbolInfo.valuation` and `AttributeInfo.valuation` (gRPC), `Symbol.valuation` and `AttributeFacts.valuation` (Python), and the `valueExpression`, `valueExpressionKind` and `valueExpressionReference` query properties describe the value expression a feature declares — its source text, kind, `default`/`:=` flags and the features it reads as resolvable symbol-id paths — so a binding such as `in power = powerPort.power;` or `powerPort.power * 2.0`, which has no constant value, is no longer invisible to clients. Reported under the `valuation` capability.
