- `sysml -bundle` archives what the project's `.meta.json` records: the two manifests plus exactly the files its `checksum` keys and `index` targets name, with a recorded file missing from the tree an error naming it; a directory without a `.meta.json` is archived as KerML 10.3 describes — the project file and the model files — so a repository's README, scripts, `__pycache__`, editor backups and version-control metadata no longer travel in the archive. On the Extensions Library tree this gives the same members, byte for byte, as its own `build-kpar.py`.
