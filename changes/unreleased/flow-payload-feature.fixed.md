- **A flow's payload is a `PayloadFeature` under a `FeatureMembership`.** `of T`, `of T[1]` and `of p : T = v` were written as the expression `sysx:payload`, and a declared payload was not written as an element at all, so `m.p` could not reach it and a graph without source text came back as `of p`. The feature now carries the payload's name, typing, multiplicity and value, and the head is rebuilt from it (#652).
