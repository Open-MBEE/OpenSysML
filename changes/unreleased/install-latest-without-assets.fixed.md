- **`install.sh`, `install.ps1` and the GitHub Action install the newest earlier release while the latest one has no assets yet.** A release is marked latest when it is published, minutes before the release pipeline uploads its assets, and in that window the installers failed with `could not download .../SHA256SUMS.txt`. `latest` now falls back to the newest earlier stable release that has a `SHA256SUMS.txt`, with a warning naming both releases; the download is verified against that release's manifest as before. A release named with `--version` is never substituted, and pre-releases are never a fallback.
