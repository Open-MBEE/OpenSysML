- **`-import` reaches features an element inherits through its parts and aliases.** A row naming `Fleet::car1::engine`, where `car1 : Car` inherits `engine`, redefines `engine` in `car1` and sets the value inside it; an alias names the element it aliases; a quoted name such as `'fill level'` is redefined as written. Each `-import-map` and `-import-format` now qualifies the `-import` before it, so files of different shapes import in one run. A JSON number or Boolean written as a string (`"180"`) imports as the feature's type reads it, a tab-separated cell keeps its quotes as text, and an enumeration value the enumeration lacks is refused by name.
