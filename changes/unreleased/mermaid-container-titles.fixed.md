- **Mermaid container titles no longer overlap what they contain.** A flowchart subgraph or a composite state now writes its keyword and name on one line (`«part def» Toolchain`), the one line of title height Mermaid reserves, so the outer title of a nested interconnection is no longer hidden behind its first child cluster and a composite state's name no longer sits under its start dot; leaf node labels keep their lines. The `subGraphTitleMargin` frontmatter is written only for a container title that still spans several lines, since Mermaid grows every cluster by it after layout and pushed stacked sibling clusters into one another.
- **The REPL's `%help` and reference now show that `mermaid` takes a drawing style.** `%render-document` is listed as `<name> [mermaid|dot|plantuml|d2 [pilot|cameo]]` as its usage line says, and the `%render` and `%render-document` rows of the REPL reference name the palette and `pilot`/`cameo` style the Mermaid form accepts.
