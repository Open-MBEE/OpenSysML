- `scripts/check-upstream-drift.sh`, run weekly by the `Upstream drift` workflow, reports when the pilot implementation or the SysML-v2-Release repository publishes a release newer than `scripts/pilot-pin.sh` pins, when the pinned tag stops resolving to the pinned commit, whether the newest release changed the specification PDFs the compliance map's clause numbers read, and when an OMG specification page lists a SysML or KerML version it has not recorded. It changes nothing; a failing run is the cue to re-pin deliberately.
