- **`library-root-name` is about the standard library alone.** The warning that a root namespace is named like a standard library package also fired on a root named like one of the bundled OpenSysML extension libraries (`DiagramLayout`, `MigrationMetadata`, `OpenSysMLRenderings`, …) — on every file the migrator writes with `-portable`, which inlines those `library package`s so the output loads in a tool that ships only the standard library. Those libraries are not standard library packages (KerML 1.0 §7.2.5.3 reserves the standard library's names alone), so a root named like one is no longer reported; a root named like `Base`, `ScalarValues` or `Requirements` still is.
