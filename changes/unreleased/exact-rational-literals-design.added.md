- **A design note on exact Rational values beside a binary64 Real** (`docs/internals/design/exact-rational-literals.md`). It maps where a number is represented today — a `LiteralReal` rounds to a `float64` in `ParseReal`, `RealArith` and `IntQuotient` compute in binary64, `FormatReal` prints the shortest round-tripping decimal — against the two references, the pinned pilot (binary64, so `0.1 + 0.2` is `0.30000000000000004`) and sysml-toolkit (exact, so `0.3`), proposes a `big.Rat` value kind for literals and `Rational`-typed features with the `Real` type as the one place rounding enters, costs it against the tree, and recommends leaving the arithmetic as it is unless the project adopts toolkit parity as a conformance goal. No evaluator behavior changes.
