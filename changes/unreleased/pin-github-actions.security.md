- **Every third-party GitHub Action the workflows use is pinned to a commit SHA.** The 98 `uses:` references that floated on a mutable tag (`actions/checkout@v4`, `actions/setup-go@v5`, `actions/upload-artifact@v4`, …) now name the full commit of a verified release with the version as a trailing comment, one pin per action across the workflows and the composite actions, so a re-pointed tag can no longer change what a build runs.
