- A state machine or performed action of an object that fails while the clock is advanced — a transition effect or entry action that indexes an empty sequence, say — is reported again: `-advance`, `%advance` and the gRPC advance fail with `advance failed: …`, and `-schedule explore` tables the run as an `error:` outcome that fails the verdict (exit status 1). Since 0.12.0 the failure was recorded on the behavior only, so the run was reported as passing with the machine in no state.
