- `SymbolInfo.metadata` carries `variation` on a variation definition or usage and on an enumeration definition, `variant` on a variant usage and on an enumerated value, and `abstract` on every variation whether or not the keyword is written (SysML v2.1 §7.6.7, §8.3), so the Python, TypeScript, Java and MATLAB clients and the MCP `symbol` tool can tell a variation point from a part and a variant from a member; the MCP `symbol` text now lists the metadata, and the wire-contract reference documents every metadata key.
