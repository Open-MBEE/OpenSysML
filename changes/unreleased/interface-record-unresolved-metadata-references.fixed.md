- A document whose annotation names an undeclared metadata type, or whose `about` metadata usage names undeclared elements, now has an interface record: the unresolved reference is the document's diagnostic, not a provisional supertype or an absent `about` usage, so the record is written and holds among its neighbours instead of being refused or written off as stale. The spec-examples root joins the incremental and interface-record differentials in `tests/model`.
