- `sysml -stdlib -convert ttl|api-json` converts the bundled standard library — every KerML and SysML file of it, as one model — to stdout, to a `-o` file, or to the Flexo MMS branch `-o` names, publishing the library as a project other projects type against by element id. Every element carries its normative id: the named ones the pilot implementation's library XMI assigns, the derived ones name-based uuids under them (`-id uuid` is the default here). A branch `-o` now takes `-convert api-json` as well as `ttl`, both replacing the branch's graph, and `FLEXO_TIMEOUT` (a Go duration, `60s` unless set) bounds each repository request, since a whole-library write takes minutes. `TestFlexoInterop` measures the published library against a live stack — elements and properties delivered through `/elements`, and a user model typing a part by `ISQ::mass` and `ScalarValues::Real` read back and re-converted to notation — and records it in `tools/referee/flexo/testdata/library_expected.txt`.
