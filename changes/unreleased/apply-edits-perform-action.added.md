- **ApplyEdits authors perform-action usages.** `add_member` accepts two new SysML member kinds (SysML v2 §7.17.6): `perform action` writes `perform action <name> : <ActionDef>;`, and `perform` writes `perform <ref>;`, a usage named by the action usage it references (`t.heat`); the reference is checked as a feature reference and resolved from the owner's scope. The Python client gains matching `add_perform_action` and `add_perform` helpers.
