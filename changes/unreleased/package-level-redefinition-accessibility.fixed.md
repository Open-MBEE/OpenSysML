- A feature owned by the root namespace of a document is package-level, so redefining it from another root feature is now the error `A package-level feature cannot be redefined`, as it already was inside a `package`; and a package-level or root feature that redefines a feature of a type (`part e2 : Engine :>> Car::engine;`, or a KerML feature `featured by` a type) now reports `Must be an accessible feature`, since it has no featuring type to reach the target through (KerML `validateSubsettingFeaturingTypes`). Both match the pinned pilot validator; redefining a package-level feature from inside a type stays legal.
