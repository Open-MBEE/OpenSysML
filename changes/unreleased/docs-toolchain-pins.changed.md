- **The documentation toolchain pins `pymdown-extensions` and moves to mkdocstrings 1.0.7.** `pymdown-extensions` 12.2 changed the `Highlight` extension's constructor, which mkdocstrings 1.0.6 called with the old signature, so `make docs` failed on `reference/python-api.md` as soon as the unpinned dependency resolved to 12.2; 1.0.7 follows the new signature, and the pin keeps a local `make docs-serve` rendering what the Pages workflow publishes.
