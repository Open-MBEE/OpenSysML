- The .NET client reads an element's metamodel properties and every path to an object. `Model.ElementPropertiesAsync` reads the properties of one element by their specification names (`inheritedFeature`, `connectorEnd`, …) as the `api-json` element form spells them, each an `ElementProperty` whose values are `ElementPropertyValue` arms, an element among them an `ElementRef` whose id the call accepts back. An instantiated `Instance` says how the traversal reached it (`ReachedBy`, `Path`, `Instantiation.FindOwner`), and `Model.InstancePathsAsync` (by id) and `InstancePathsAtAsync` (by object path) list every root-relative `InstancePath` to it, aliases through connector ends and reference usages included. A `Symbol` lists its `Members`, own and inherited, each a `SymbolMember` with its provenance, and counts the standard-library ones in `WithheldLibraryMembers` unless `SymbolOptions.IncludeLibraryMembers` asks for them; `TypeFacts.Types` are a feature's derived types, and a `Specialization` of kind `references` is reference subsetting. The typed-class generator takes a feature's type from the derived types and follows reference subsetting. The calls are refused before anything is sent without the `element_properties`, `instance_paths` and `symbol_members` capabilities (`Capabilities.ElementProperties`, `InstancePaths`, `SymbolMembers`), and the .NET conformance runner now covers `GetElementProperties` and `InstancePaths`.
