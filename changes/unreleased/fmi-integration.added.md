- **FMI models import and evaluate.** `-convert` accepts `fmu` as an input format (`sysml -convert sysml model.fmu`): the archive's `modelDescription.xml` (FMI 1.0, 2.0 or 3.0) is read and the FMU becomes a `calc def` whose parameters carry the model's variables, experiment times and outputs, annotated `ToolExecution` with `toolName = "fmi"`. Evaluating it runs the FMU through the new `tool:fmi` engine and an external FMI runner — a one-request/one-reply JSON subprocess the site grants with `OPENSYSML_FMI_RUNNER`. See `docs/reference/fmi.md`.
- **A reference FMI runner ships with the Python client.** `pip install opensysml[fmi]` installs `opensysml-fmi-runner`, an `OPENSYSML_FMI_RUNNER`-ready executable that simulates co-simulation and model-exchange FMUs through FMPy; `scripts/download-reference-fmus.sh` fetches the Modelica Reference-FMUs the `tests/fmi` gate exercises end to end (CI requires it with `OPENSYSML_REQUIRE_REFERENCE_FMUS=1`).
