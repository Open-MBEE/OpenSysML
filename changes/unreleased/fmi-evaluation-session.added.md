- **Reusable FMI evaluation sessions.** A `tool:fmi` call that binds the reserved `fmi:stepTime` input now uses a session that initializes the runner once and steps to a time before reading values, so N intermediate readings cost one runner invocation instead of N whole runs; sessions are isolated per caller and bounded in count, lifetime and steps. The existing one-shot `fmi/1` behavior is unchanged. See [FMI models](docs/reference/fmi.md#reusable-evaluation-sessions).
