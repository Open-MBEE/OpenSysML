- **The editor's Format Document, range formatting and the `sysml-syntax` `Format` RPC lay statements out one per line, as `-convert sysml` does.** The language server and the syntax service formatted with the layout-free options, which only re-indent, so `package P { part def A; }` came back without an edit and a one-line model was never broken into lines. Both now use the statement layout the converter writes — a new line after the `{` of a body and after each `;` in it, the `}` on a line of its own — while a body the layout keeps on its line (empty, a single result expression, an expression body, an end-of-line note) stays as written and no line is ever joined. A line the layout splits is one edit within that line, so range formatting and a notebook cell's formatting never touch a line outside the selection or the cell (#1840).
