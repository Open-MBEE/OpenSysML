- Creating an object in a session that already holds many — `%instantiate` in the REPL, the Instantiate RPCs and the engine, the `-satisfy` verdicts — no longer pays for every object the session holds to report the behaviors that failed to start beside the new one: the report is placed from the failures on record, so a creation costs the same in an empty session and in one holding thousands of objects (a REPL `%instantiate` had slowed about 17× and a warm gRPC Instantiate about 4× as the session grew).
