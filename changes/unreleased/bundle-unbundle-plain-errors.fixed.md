- `sysml -bundle` and `-unbundle` say what is wrong with the path they were given instead of quoting the failed system call: a directory without a project file reports `the directory holds no .project.json, so it is not a project` (it was `open <dir>/.project.json: no such file or directory`), a path that does not exist `no such directory`, a file `not a directory`, and a file that is not an archive `not a project archive: the file is not a ZIP archive` (it was `not a ZIP archive: zip: not a valid zip file`). A library archive that is not a ZIP file is reported in the same words wherever archives are read.
