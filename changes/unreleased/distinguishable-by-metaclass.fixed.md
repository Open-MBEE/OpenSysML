- **Treat same-named members of non-conforming metaclasses as distinguishable.** KerML `Membership::isDistinguishableFrom` also distinguishes two memberships whose member elements' metaclasses conform in neither direction, so `part def A; attribute def A;` or `class A; datatype A;` in one namespace no longer warns `Duplicate of other owned member name`, and an inherited `self` reached from both `Action` (an `ActionUsage`) and `Part` (a `ReferenceUsage`) no longer warns `Duplicate of inherited member name`. Same or specializing metaclasses (`part def A; item def A;`, two `part p;`) still warn, as does any pair whose metaclass is unknown or whose alias target does not resolve; which member a reference resolves to is unchanged.
