- **`RenderDocument` names its file.** `RenderDocumentResponse` gains `file_name`, the file a rendered set (`-render-documents`) writes the document to in the requested form and the name the other documents' links to it use; populated under the `render_document_file_name` capability; the Java client exposes it as `RenderedDocument.fileName()`, and the SysON plugin downloads a rendered document under that name instead of deriving one of its own.
