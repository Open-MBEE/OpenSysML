- A typing spelled `typed by` in a `.sysml` file is now an error (`typing-keyword`) with or without `-strict`, where it was a `kerml-notation` warning that only `-strict` promoted. SysML v2.1 spells a usage's typing `:` or `defined by` (§8.2.2.1.2 `DEFINED_BY`, §8.2.2.6.5 `TypedBy`, and §7.27.2 for a metadata usage); `typed by` is KerML's spelling of the same production and `typed` is not a SysML keyword, so the reference implementation refuses it too. The typing is still read as written, so the rest of the model is analyzed, the finding keeps its quick fix, which writes `defined by`, and `.kerml` files are unaffected. `sysml -convert` to SysML notation now writes the typing of an end's cross feature `defined by` rather than `typed by`, so a converted SysML file no longer carries the spelling the check rejects.
