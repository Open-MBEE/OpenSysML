- Connector routes on arm64 (Apple silicon, Linux arm64) now match the VS Code panel's point for point: a port's position along its side is rounded before it is added, where the compiler had fused the two into one multiply-add and moved some routes by a rounding step.
- `-render-document -doc-form pdf` runs each converter with `PWD` naming the directory it runs in; before, a converter inherited the caller's `PWD`, so `$PWD` and the shell's `pwd` disagreed with the converter's working directory.
- The SMT engine's sensitivity report lists the two final values in the order the check engine does (`x ends as 1 or 2`), with witness A the run reaching the first; before, the order was whichever the solver's model gave and differed between platforms.
- `-compile -target c` builds a calc using a sequence of records with compilers that refuse implicitly declared functions (clang, GCC 14): the record collection runtime now declares the argument parser the collection runtime calls, which refuses a record argument as the function-value runtime does.
