- `sysml-core`: a validation-focused WebAssembly command serving `ParseSources`, `ParseFile`, `GetDiagnostics` and `GetSymbol` without protobuf, Connect or the execution runtime. It embeds the standard library, runs validation passes for clean parses, and exposes a synchronous `globalThis.sysmlCore.call(method, paramsJSON)` surface in JavaScript; native and WASI builds use JSON-RPC over stdio. Execution remains on `sysml-engine`, and other service methods remain on `sysml-grpc`. See `docs/reference/wasm.md`.
