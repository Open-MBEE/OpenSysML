- **The client test suites accept a release that pins the Jupyter kernel binaries beside the service.** From v0.10.0 a release pins both the `sysml-grpc-*` and the `sysml-jupyter-kernel-*` assets, and the Python, Java, Node and Rust suites held every pinned release to exactly the five service assets, failing the v0.10.0 pin; they now require the service family whole in every release and the kernel family whole wherever it is present.
