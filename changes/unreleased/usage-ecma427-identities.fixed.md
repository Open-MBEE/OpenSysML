- A usage whose resource is the ECMA-427 package URL a package manager writes for a repository — `pkg:generic/<name>?vcs_url=<vcs>+<transport>://<host>/<path>[@<version>][#<subpath>]`, the qualifier percent-encoded (`pkg:generic/sysmod-sysmlv2?vcs_url=git%2Bhttps:%2F%2Fgithub.com%2FMBSE4U%2Fsysmod-sysmlv2%405.1.6`) — now links the project installed under `lib/` exactly as the `pkg:git/<host>/<path>[@<version>][#<subpath>]` spelling does: the host and path, the `@<version>` and the `#<subpath>` are read from the decoded `vcs_url`, the bare `<vcs>+<transport>://` URL is read the same way, and a `.git` suffix on the repository path is not part of the name. Before, such a usage was matched by name against `pkg:generic/<name>` alone and loaded nothing, so `private import SYSMOD::*;` was unresolved in a project a package manager had just installed. A `vcs_url` that does not decode to a `<vcs>+<transport>://<host>/<path>` URL is a `project.load` warning at the consumer's `.project.json` and the usage selects nothing.
