- **Sweeps and Monte Carlo plans are a package of their own.** `internal/exec/sweep` holds the sweep plans, ranges, rows, tables and work queue and the Monte Carlo plan that `internal/exec/runtime` held; the runtime offers them the parameters a calc or case declares (`Context.Parameters`), the classification of a value against a type (`Context.ClassifyValue`) and the scalar-type reads they type ranges by (`Context.PositiveScalar`, `Context.QuantityNumber`), and imports none of the packages layered on it, which `tests/hygiene` pins. What the CLI, REPL and gRPC service print and return is unchanged.
