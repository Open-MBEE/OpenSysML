- **`sysml-wasm` combines the execution and validation JSON-RPC surfaces in one WebAssembly module.** It routes parsing and symbol facts to the core and evaluation and execution to the engine, shares a single standard-library snapshot, and reports supported capabilities through `GetServerInfo`. JavaScript hosts call `globalThis.sysmlWasm.call(method, paramsJSON)` synchronously; native and WASI builds serve JSON-RPC over stdio. See `docs/reference/wasm.md`.
