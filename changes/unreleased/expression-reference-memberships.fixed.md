- The reflective read of an expression now owns the plain `Membership` to the element it names, as the RDF conversion already wrote it: a reference's `referent` (`attribute r = a;` owns a Membership whose `memberElement` is `a`), an invocation's or constructor's `function`, and a feature chain's `targetFeature`, in the conversion's order among the expression's parameter memberships; `referent`, `function` and `targetFeature` answer the named element, and the memberships' `elementId`s are the ones the conversion writes. A name the resolver cannot bind owns no such membership; a dotted name's chain feature is not synthesized yet.
