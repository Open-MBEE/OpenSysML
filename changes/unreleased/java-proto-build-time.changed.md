- **The Java client's protobuf message classes are generated at build time rather than committed.** `client/java/opensysml-client` generates `org.openmbee.opensysml.proto` from `api/proto/sysml.proto` during the Maven build, with `protoc` pinned to the `protobuf-java` version; the 279 generated files leave the repository, `make proto-buf` regenerates the Go stubs only, and `api/proto/buf.gen.yaml` no longer needs the Buf Schema Registry's remote Java plugin. A `.gitattributes` marks the remaining generated stubs, test fixtures, baselines and binary artifacts `linguist-generated`, so GitHub collapses them in diffs and leaves them out of the language statistics.
