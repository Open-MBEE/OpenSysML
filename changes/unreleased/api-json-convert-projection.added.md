- `Convert` can now write only the API JSON declarations and annotations a caller names, under the `convert_projection` capability. `ConvertRequest.projection` carries `qualified_names`, `metaclasses` and `annotation_types`; the selectors are unioned and an empty projection writes the whole model as before. Every emitted element is byte-identical to the same element of an unprojected conversion, and the standard element array is still streamed one element at a time, so a caller that reads only the elements it needs gets a smaller reply without the whole element array being materialized. A selector naming nothing the model carries is `INVALID_ARGUMENT`. The Go, Python, Node, Java, Rust, Julia and MATLAB clients and the MCP `convert` tool expose the projection.
