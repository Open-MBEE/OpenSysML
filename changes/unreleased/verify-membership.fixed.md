- **`verify` exports as a verification, not a satisfy.** In the Turtle and API JSON forms, an objective's `verify r;` or `verify requirement v : R;` was a `SatisfyRequirementUsage`, so a reader could not tell a verification from a satisfaction, and the declaration form came back from the graph as `satisfy requirement v : R;`. Both are now the `RequirementUsage` a `RequirementVerificationMembership` owns, as the grammar's RequirementVerificationMember says, and read back as `verify` (#651).
