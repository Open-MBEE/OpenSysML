- The constraint tier reports a variant usage whose kind is inconsistent with its owning variation (`variant-kind`, SysML v2 §7.6.7): a variant specializes the variation it is a variant of (`checkUsageVariationDefinitionSpecialization`, `checkUsageVariationUsageSpecialization`), so the variation definition, or the types of the variation usage, type the variant and the kind's typing rule judges them — `variant action a;` in `variation part def PC` or in `variation part pv : P` is `An action must be typed by action definitions.`, naming the variation and the type it gives the variant. A bare `variant x;` restating a separately declared usage declares no kind and is not judged.
