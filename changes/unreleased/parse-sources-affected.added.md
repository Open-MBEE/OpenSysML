- **`ParseSources` can name the documents an edit reached.** Under the new `parse_sources_affected` capability, a request carrying the hash of the model it was answered last (`base_model_hash`) is answered with `affected`: the documents whose results may differ from that model's. Every other document converts exactly as it did, so a client that keeps each document's `Convert` output (with `documents`) re-converts only the affected ones after an edit.
