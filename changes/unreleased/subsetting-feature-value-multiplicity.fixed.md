- Instantiating a `ShapeItems::Pyramid`, `RectangularPyramid` or `Tetrahedron` no longer fails with `feature value shape.apex: multiplicity violation: 2 value(s) bound to a feature with multiplicity upper bound 1`: a feature declaring no multiplicity that binds a value while subsetting a type-owned feature (`item apex :> vertices = wall.apex`) takes no default of one (SysML v2 §7.6.3) and is bound by the upper bound of what it subsets, so the two apex vertices of a wall are admitted under `vertices[0..*]`; a subsetting feature restating `[1]` or subsetting nothing still refuses two values.
