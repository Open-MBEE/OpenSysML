- A usage linked to an installed project by elimination — its IRI spells a repository path whose last segment is not the project's name — is now a warning on the consumer's `.project.json` naming the project taken and the publisher/name the resource should end with, judged by `-warnings-as-errors` like the ambiguity warning; before, the fallback was silent.
- A project interchange archive holding the project's folder rather than its contents, as the OMG library releases are laid out, is read as the project in that folder, and an index entry naming no member no longer refuses the archive: both are warnings on the archive's path, and the units are found by what they declare.
