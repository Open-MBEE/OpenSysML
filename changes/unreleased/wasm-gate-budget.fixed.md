- **The WebAssembly gate no longer times out on a slow CI runner.** `tests/wasm` compiles and vets the whole tree for both wasm targets, 7-11 minutes on a hosted runner, and ran under `go test`'s default ten-minute budget, so a slow run died with `test timed out after 10m0s` in whichever test was running rather than on an assertion. `make wasm-check` now gives the gate an explicit budget (`WASM_GATE_TIMEOUT`, 25 minutes), each command is linked once per run and shared between the build, run and browser-REPL tests, every link is its own timed subtest, and the GitHub Actions gate restores a build cache of its own that a push to `develop` saves, so a pull request starts from develop's compiled objects instead of compiling both targets cold.
