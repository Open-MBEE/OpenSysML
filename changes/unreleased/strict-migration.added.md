- **`-strict` makes a SysML v1 migration write conforming SysML v2 only.** `sysml Project.xmi -strict -convert sysml` refuses every construct whose only v2 form is an OpenSysML extension — a `deferrableTrigger` (`defer <event>;`), a `choice`, `junction`, `shallowHistory` or `deepHistory` pseudostate, and an entry or exit point of a composite state that would be written as a junction — reporting each **unmapped** with the extension note and refusing the transitions through it, so the output validates clean under `-strict -validate`; `fork`, `join`, default entries and machine connection points are standard and written as before.
