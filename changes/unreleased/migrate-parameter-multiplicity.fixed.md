- **The SysML v1 migrator keeps a parameter's multiplicity where it redeclares or binds it.** An operation's context body and a reception's parameter bindings wrote every parameter as `[1]`, so an optional (`[0..1]`) or plural (`[0..*]`) v1 parameter became required and single in v2, and a reception binding a plural signal attribute was refused. Both now write the source multiplicity, `ordered`/`nonunique` included. A v1 parameter or property that writes no multiplicity but is `ordered` or `nonunique` now writes `[1] ordered` rather than a bare `ordered`, which v2 reads as `[0..*]`.
