- A loop an action body reaches is a `LoopAction` performance of the run, held under the performing action's `loops` (`Actions.sysml` `loops : LoopAction[0..*] :> subactions`), and every iteration performs the loop's body as an occurrence held under the loop's `body` (`LoopAction::body`, `ControlPerformances.kerml` `LoopPerformance::body`), typed by the body action the loop declares (`loop action body { … }`) with its nested actions as the body's subperformances; both begin and end with the loop and the iteration, so `subperformances`, `suboccurrences`, `enclosedPerformances`, `timeEnclosedOccurrences` and `this` read them, `loops#(1).body` is `[]` before the first iteration and never refused, and a loop nested in a body is held under that iteration's body. A binding of the Kernel Semantic Library through a frame member the object holds no value of (`whileDecision.thenClause = body`) no longer refuses the read of the feature it binds.
