- `.github/workflows/pages.yml` now republishes the documentation site only when a push to `develop` changes something the build reads: the pages and their renderer, the files the hooks copy in, the sources of the in-browser modules and the landing diagram, and the tests and fixtures the test-suite figures are counted from. A push that changes none of these would publish the same site and no longer starts a run; the version the in-browser engine reports is then the last commit that did. `workflow_dispatch` still republishes on demand.
