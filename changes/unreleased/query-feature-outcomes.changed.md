- `Project` and `WhereFeature` reading a feature an element row lacks now fail with a `missing-feature` error naming the element and the features it does have (`Target`, `Property`, `Candidates`), instead of leaving the cell empty; a property no row carries stays `unknown-property`. The new `tolerate = true` argument on both operations keeps the empty cell for sources that mix element kinds (the cookbook's `MassTable` uses it). Metadata paths (`Tag::key`) are unaffected.
