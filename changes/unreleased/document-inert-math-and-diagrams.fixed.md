- Rendering a document to HTML, Markdown or AsciiDoc now refuses a drawn diagram's SVG, and to HTML a typeset formula, that holds markup which would run in the page — a `<script>`, `<iframe>` or similar element, an `on…` event handler, or a `javascript:` or non-image `data:` location — naming the diagram or formula and what was found. Both are written into the page as they stand, so before, a label that survived a drawing tool's escaping, or typeset HTML handed to `docrender.HTML` from untrusted LaTeX, became active content of a standalone page. What KaTeX, Graphviz, Mermaid, PlantUML and D2 write is unaffected.
