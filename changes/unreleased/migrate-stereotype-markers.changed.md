- The SysML v1 migrator no longer writes a stereotype or relationship kind as a comment beside the element (`/* «Trace» */`, `/* applied stereotype «Critical» */`, `/* «Block» tags with no v2 form: … */`), which modeling tools render as a note on every diagram. A «Trace», «Copy» or other dependency kept as a plain `dependency` is named by its kind (`dependency 'A traces B' from A to B`), as an include or refine connection is, and every stereotype the v2 form does not carry is a `@MigrationMetadata::AppliedStereotype { stereotype = …; profile = …; tags = …; }` marker in the element's body; a UML Extend kept as a dependency is named `'A extends B'` with its extension points in its `doc`. Under `-strict` the marker is a line comment and the dependency's name alone carries the kind. Documentation comments are unchanged.
