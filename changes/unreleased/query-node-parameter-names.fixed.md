- `sysml -query` and gRPC `Query` read a parameter an action's notation states with no expression of its own by its role under its action: `parameter`, `input`, `feature` and `ownedFeature` of an assignment answer `P::A::assignCount::target` instead of an empty value, and a `for` loop answers its variable (`P::A::forAct::i`) instead of dropping the property. One stated by an expression reads as that expression, as a send's payload does (`new Sig()`): a `while` or `if` test, and the occurrence of `terminate sub;`, which read the library's `terminatedOccurrence` only while the action held no parameter of its own. `qualifiedName` of a `for` loop's variable is qualified by its loop for every reader of the semantic model, where it read the bare name. A chained assignment (`assign p.q := 1;`) reads its target as the operand written (`p`), an assignment in a body no name reaches is named under its positional identity, and `oslc.where` matches such a parameter by the text the query reads it as (`sysml:parameter="new Sig()"` selects the send again). `oslc.orderBy` orders such parameters by the same text.
