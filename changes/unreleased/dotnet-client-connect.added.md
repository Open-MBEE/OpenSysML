- The .NET client speaks the Connect protocol as well as gRPC: `ConnectionOptions.Protocol = Protocol.Connect` makes each call one HTTP/1.1 POST, with a protobuf body or, with `ConnectionOptions.Encoding = MessageEncoding.Json`, a JSON one. A connection never falls back to another protocol, and JSON over gRPC is refused before anything is sent. Connect calls send their deadline as `Connect-Timeout-Ms` and enforce it themselves, accept gzip answers with `MaxResponseSize` bounding what they inflate to and their CRC-32 and length checked, and follow no redirect. A refusal is a `ServiceException` only when its body is a Connect error; any other, such as a proxy's HTML page, is a `TransportException` whose status is inferred from the HTTP status and which quotes an excerpt of the answer. Over JSON, an unknown response field is ignored and an enum value named by a name the client does not know reads as zero. A gRPC connection that reaches an HTTP/1.1-only endpoint now names `Protocol.Connect` as the remedy.
