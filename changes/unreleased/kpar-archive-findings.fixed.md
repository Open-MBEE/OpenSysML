- A `.kpar` archive named as a library root (`-library-root`, `OPENSYSML_LIBRARY_ROOTS`, sysml-lsp `libraryRoots`) is read as an installed project instead of being dropped; a model file named from inside an archive finds its imports in the archive's other members and in the installed projects the archive's own `.project.json` uses, even when the archive lies inside another project's directory; and a library path (`OPENSYSML_LIBRARY_PATH`) naming an archive, or a directory holding one, that is not a project interchange archive now fails the library load with the archive's name and reason instead of loading an empty library.
