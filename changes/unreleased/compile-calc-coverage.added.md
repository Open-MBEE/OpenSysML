- **`sysml -compile` compiles Strings, enumerations, mixed numbers, run-time function values and closures, and spends the step budget.** A compiled C or Go calc now takes, computes and prints Strings with the `StringFunctions` the interpreter implements, enumeration literals by identity, Real-typed values that hold Integers and mixed Integer/Real sequences as the interpreter promotes them, and function values that are chosen, stored, returned, compared, held in sequences or close over a body's bindings. A compiled program counts evaluation steps as the interpreter does and fails with its `evaluation step limit exceeded` error at the same count (`OPENSYSML_MAX_STEPS`). Records and calcs read off an object are still refused, as is, for C alone, a closure capturing a String, sequence or function.
