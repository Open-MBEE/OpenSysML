- A connection usage whose ends are declared in its body and attached by reference subsetting (`#multicausation connection gate { end #cause :> causes ::> a; … }`, SysML v2 §7.13.2) is a connector object like one with a `connect` clause: `-instantiate` no longer reports `gate.causes: multiplicity violation: 0 value(s)` on `CauseAndEffect::Multicausation`, since each attached end's value is a value of every feature the end subsets (KerML 1.0 §7.3.4.4), named or not, and a `#cause`/`#effect` end subsets `causes`/`effects` through its semantic metadata — whose `baseType` the library binds with an `as` cast, now read like a `meta` cast; such a connection's ends also appear in relationship and interconnection views.
