- A declaration whose value names itself by qualified name (`attribute a : Real = test::self::a;`), two declarations naming each other, or a redefinition bound to the feature it redefines (`:>> a = test::self::a`) now evaluates to the `cyclic feature value dependency` error naming the declaration the cycle closes on — in `-e` expressions, on an instantiated object, in the REPL and over the gRPC and LSP surfaces alike — where before the read recursed until the process died of a Go stack overflow; the same cycles spelled with dot notation already reported it, and the two spellings now report through one mechanism.
