A scene variant can build on another (`requires`): its toggle is offered while that one is on, and switching it off returns there.
- A rendering heads a redefining usage that declares no typing of its own with the types it inherits from the features it redefines (KerML 1.0 §7.3.4.5), each once and through a chain of untyped redefinitions, as it already did for a usage inherited unredefined: `part :>> instrumentUnit { :>> mass = 2000 [kg]; }` is drawn `instrumentUnit : InstrumentUnit`, a redefined `subcomponents` collection carries its `Component`, and `part both :>> left, right` over `left : A` and `right : B` reads `both : A, B`. Every rendering form that heads a node with a type follows — interconnection, tree, general, case, mixed, sequence, behavior and the element table — and so do the `typings` of RenderView.
