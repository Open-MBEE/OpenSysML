- **The Cameo plugin is Magic MDK and the SysON plugin is SysON MDK.** The plugin for Cameo Systems Modeler and MagicDraw is `org.openmbee.mdk.magic` (Maven `magic-mdk-*`, zip `Magic_MDK_<version>.zip`, menu group and results window *Magic MDK*, DocGen profile *Magic MDK DocGen*); the SysON integration is `org.openmbee.mdk.syson` (Maven `syson-mdk`, npm `@openmbee/syson-mdk`). Nothing published carried the old names.
- **Magic MDK declares and enforces its compatibility floor.** The plugin supports the 2024x line (2024x through 2024x Refresh3, JDK 17) as well as 2026x: `OpenApiFloorTest` checks every vendor class the compiled plugin links against the public 2024x OpenAPI class index under `editors/mdk/compat/`, exempting only the SysML v2 textual-export classes it reaches after probing for the 2026x service; `plugin.xml` declares the OpenAPI it requires, and the Resource Manager descriptor is now the vendor's `resourceDescriptor` form, generated over the staged files with an ordered internal version. Releases on JDK 11 (2022x Refresh2 and earlier) remain unsupported; the design note says what would change that.
