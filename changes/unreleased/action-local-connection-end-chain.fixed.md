- A connection usage declared in an action's body is now attached when the body's first use of it is a feature chain, read (`assign seen := link.left;`, `Connect::link.left`) or written (`assign link.weight := 3;`), instead of failing with `connector end cannot be attached: … no object owns the connector`. The chain reads and writes the performance's one connector, the same one a bare `link` names. The enclosing action can likewise read and write through a step's connection (`child.link.right`, `assign child.link.weight := 5;`), whether or not the step's own body read it; these failed with `declares no node or pin link` and `declares no result to read it as a value by`.
