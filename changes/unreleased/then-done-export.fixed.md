- **`then done;` exports as one `SuccessionAsUsage` targeting the library's `Actions::Action::done`.** The member-attached `then` no longer mints a `done` Membership whose element the succession's target end reference-subsets — a shape `ReferenceSubsetting` cannot target. The target end now reference-subsets the library's done feature directly, the same end `succession first x then done;` states, and `sysml:targetFeature` carries it. A `done;` written on its own still exports as the `done` Membership, and graphs written in the earlier shape still read back as `then done;`.
