- **The notation-text helpers moved from `internal/syntax/lexer` to `internal/syntax/source`.** `NameText`, `QualifiedNameText`, `StringValue`, `StringText`, `UnrestrictedNameText`, `CommentBody`, the keyword sets (`Keywords`, `IsKeyword`, `IsKeywordIn`) and `IsIdentifier` now live beside the source files they read and write, so the type system, the runtime and the exporter no longer import the scanner to spell a name or read a comment body; `internal/semantic/semantics` imports `lexer` in no file. A layering test in `tests/hygiene` assigns every package to a layer of the package-layering plan and permits exactly the cross-layer imports that exist today, so a removed edge cannot return unnoticed.
