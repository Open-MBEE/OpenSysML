- Python client: `Model.convert`, `Model.to_api_json`, `Model.save` and the module-level `opensysml.convert` take the `compact`, `omit_derived`, `keep_derived` and `include_check_diagnostics` options `Connection.convert` takes, gated the same way on the service's `convert_compact` and `convert_check_diagnostics` capabilities, so a loaded model writes its compact API JSON without dropping to its connection.
