- A usage that subsets or redefines a definition (`part eng : Engine :> Mass;` with `attribute def Mass`) is now an error in default mode for `.sysml` sources, reported at the target as `subsets target must be a feature, found attributeDef`, as it already was for `.kerml` sources: KerML's `Subsetting::subsettedFeature` and `Redefinition::redefinedFeature` are typed Feature, a rule SysML usages inherit and the pinned pilot validator enforces (`Couldn't resolve reference to Feature 'Mass'`). Redefinition targets are judged by the same rule; the reference form of a satisfy or verify usage (`verify RD;`) stays with the referent-kind rule, so a definition there is reported once.
