- **CI audits every dependency tree for known vulnerabilities and fails on a finding.** `make vulncheck` (govulncheck over both Go modules, reachable vulnerabilities only), `make audit-npm` (`npm audit --omit=dev --audit-level=high` in every `package-lock.json` directory), `make audit-python` (`pip-audit --strict` over the three Python packages), `make audit-rust` (`cargo audit`) and `make audit-java` (osv-scanner over the Maven trees) run in the pull-request workflow's quick and full tiers, in the CircleCI jobs that gate `develop`, `main` and release tags, and every night over `develop`; `make audit` runs all five and the release procedure requires it clean before the release branch and again before the tag, with unfixable findings checked against the CISA Known Exploited Vulnerabilities catalogue. The tools come pinned and SHA-256 verified from `scripts/download-sca-tools.sh`, and `.github/dependabot.yml` opens weekly grouped update pull requests against `develop` for every ecosystem.
