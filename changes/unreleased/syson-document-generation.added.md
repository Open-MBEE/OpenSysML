- **SysON plugin: document generation.** The `runWithOpenSysML` mutation and the "Run with OpenSysML" dialog gain `RENDER_DOCUMENT`, which renders the selected document definition as Markdown or HTML, previews it (HTML in a sandboxed frame) and offers it as a download named as a rendered set names it, so links between downloaded documents hold, and `RUN_DOCUMENT_QUERY`, which runs the selected document query with bindings given as the dialog's inputs (a qualified name binds the element, any other expression a literal) and shows its rows as a table whose project elements select on click. The exporter now leaves out a project's unextended copy of a `library package` the service bundles, such as `DocumentQueries`, so the copy SysON needs to resolve names does not shadow the service's own library; a copy adding members is exported with a warning.
