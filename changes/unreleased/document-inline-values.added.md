- Markdown and AsciiDoc document bodies read model values into the prose: `[label](sysml:value:<target>)` and `sysml:value[<target>, label]` plan a value run that resolves the feature as a `sysml:` reference does and renders it as the same feature renders in a `SpanColumn` cell — quantities with their unit, strings, booleans, enumeration literals, multi-valued features joined — reading the session's object when it holds the chain's root. A part, port, content block, definition or a `ref` to one of those as target is refused when planning (`invalid-value-target`, `unknown-value-target`); a feature without a value fails evaluation (`empty-value`) naming the feature.
