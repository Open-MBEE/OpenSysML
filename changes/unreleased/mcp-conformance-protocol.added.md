- The conformance runner (`tools/cmd/conformance`) runs the suite through `sysml-mcp` as protocol `mcp`: it builds (or takes `-mcp-binary`) the server, starts it with `-tools runtime -root <fixtures>` over stdio and calls each scenario's RPC as its runtime tool, the request as the tool's arguments and the structured result read back as the response, so the tools are judged by the scenarios the service is. `make conformance-mcp` runs it with the report and JUnit outputs, and CI runs it beside `make conformance`. `sysml-mcp` honours `OPENSYSML_TEST_WITHHOLD_CAPABILITIES` as `sysml-grpc` does, so `-withhold-capabilities` applies to it too.
