- Five productions the specification's own examples use now parse with the shape the grammar gives them: a cross feature before the `ref` of an end usage (`end a_cross[1] ref a[1] : A;`), a terminate action usage naming the occurrence it terminates (`action terminate1 terminate process;`, lowered as the bare statement is, and ending that occurrence rather than the machine when a state transition reaches it), an accept payload with a value part (`accept : ChangeSignal = TriggerWhen({ level > threshold });`, waited on as `accept when` is when the invocation resolves to the library's `Triggers` function), a keyword-less usage stating `ordered`/`nonunique` without a bracketed multiplicity (`orderedContent ordered :>> content;`), and a directed calculation parameter whose body ends in a result expression (`in calc redefines whileTest { test1 }`). A multiplicity after the feature a connector end references, which no production admits, is reported once at the multiplicity instead of cascading.
