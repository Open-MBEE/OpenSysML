- The WebAssembly modules (`sysml-wasm`, the `connectWasm()` backend of the TypeScript client, and `sysml-core`) now list unnamed members in `GetSymbol`'s `childIds` by their positional id (`P::Holder::@0`), and resolve such an id, exactly as `sysml-grpc` does; before, they listed named children only. The positional naming the export, the query API and the symbol facts share moved below the frontends into `internal/semantic/naming`, so every build that serves `SymbolInfo` names members the same way without linking the exporter.
