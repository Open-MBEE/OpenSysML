- **The gate runner now parses `GOFLAGS` the way Go does.** Quoted arguments stay whole, both `-p` and `--p` are recognized, and the last setting wins, so a quoted linker value containing `-p=` is not corrupted and a caller's package limit is no longer silently overridden.
- **A WebAssembly failure no longer suppresses the tools module's tests.** The owning shard attempts its root-module and tools-module suites independently and fails if either fails, while a local all-shards plan still runs the module once.
- **The documented shared-cache cleanup confines deletion to the approved root.** Both paths are resolved and symlinks below `HOME` are rejected before removing entries, so parent components and links cannot widen the root; the timing script checks its temporary directories for symlinks before creating them.
- **Timing warmup now sees the generated snapshot and uses the measured shards' exact flags.** The embedded-library snapshot is regenerated first and the two arms' test sets are compiled through the same make target with `-run '^$'`, preserving `-pgo=off`, the shard selections and the timeout.
- **The published environment reference links to the gate guide's source.** The engineering record stays outside the built site, so the link is to its repository source instead of a page the site does not publish.
