- `%configure`, `%check`, `%solve`, `%explain`, `%optimize` and the `smt` engine no longer refuse a definition or part with `… = a undetermined (declared by the model): value cannot be fixed for solving: a undetermined has no literal in the term language` when an attribute's declared value is an expression over features nothing gives a value to (`attribute volume : VolumeValue = height * width * length;` with `height`, `width` and `length` unset). Such a value is now read as a feature chain reaching it already was: not fixed, but reported as unreadable naming the feature with no value, which a condition reading it unconditionally refuses and a conditional read guards by its path condition. The REPL's `Left free, since their declared value could not be read` lines name only the values the query reads, so an inherited library value no condition reads (`Items::Item::isSolid`, whose `voids` nothing gives a value to at the declaration) is no longer listed.
