- A transition or succession endpoint is now resolved only by ordinary name resolution from the namespace it is written in (KerML 8.2.3.5): the fallback that matched an unqualified name against the first vertex anywhere in the machine whose name path ended in it is gone, so a state nested in another state or region is named through its owners (`transition first idle then work.right.busy;`), as the pinned grammar's `ConnectorEnd` feature chain and the pilot have it. A bare `then busy;` for such a state is an `unresolved` diagnostic, and lowering a machine with an endpoint that names nothing fails with a typed `UnresolvedEndpointError` instead of silently leaving the edge out. The one-name `then work.right.idle;` succession now parses with a chained target.
