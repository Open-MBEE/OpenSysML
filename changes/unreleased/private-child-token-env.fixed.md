- **Clients:** a private `sysml-grpc` child no longer inherits `OPENSYSML_GRPC_TOKEN` from the process that starts it. The child serves loopback for that process alone and needs no token, but with the variable in its environment it demanded one, and the Julia and MATLAB clients — which never send a token to their own child — were refused every call once `OPENSYSML_GRPC_TOKEN` was set for a remote service; the Python, Node, Java and Rust clients worked only because they happened to send the same token. All six clients now start the child without the variable.
