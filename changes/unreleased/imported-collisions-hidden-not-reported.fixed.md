- **An imported name collision is hidden, not reported.** KerML 7.2.5.4 hides an imported membership whose name another import, an owned member or (7.3.2) an inherited member repeats, and says the names left are always distinct, so the `Duplicate of imported member name` warning (`name-conflict`) marked a well-formed model; it is no longer reported, in default or strict mode. The hiding stands: a reference to a hidden name is unresolved, with the hint naming the imports and the qualified names that reach each element. An import an inherited name hides is now hidden too, so a specialization inherits the inherited member alone and `Duplicate of inherited member name` is no longer reported for the pair. The pilot differential retires 237 only-ours rows, 218 of them on the pilot's `SimpleVehicleModel`.
