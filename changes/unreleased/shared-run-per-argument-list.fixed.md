- An invocation's argument list is evaluated in one run: `%calc`, `%analysis`, `%sweep`, `%runs`, `%invoke`, `%check` and the dry run of a tool call, positional and `parameter=expression` arguments alike, bind every argument from one evaluation of the list, so a seeded `random` or `uniform` in a later argument continues the stream the earlier one drew from instead of restarting it at the seed's first value, and `%seed` reproduces the whole invocation. The MCP `session_run`, the inputs it binds to an action, and the REPL's `RunCalc`, `RunAnalysis`, `RunMonteCarlo` and `RunActionWithInputs` entry points bind through the same evaluation.
