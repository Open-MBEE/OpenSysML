- `sysml-lsp` serves Jupyter notebook cells: the VS Code extension synchronizes a notebook on the `sysml` kernel with the server as one document of its `sysml` and `kerml` code cells in notebook order, read as `%load` reads a notebook (`%` command lines and bare expressions left out), so a later cell resolves an earlier cell's declarations and the cells have diagnostics, hover, completion, navigation, references, code lenses, inlay hints, semantic highlighting and formatting, each answer in the cell's own positions. Editing, inserting, deleting or moving a cell republishes every cell; closing the notebook clears them. A reference to a declaration in a later cell is marked, since the kernel runs cells in order; the guide's Jupyter chapter documents how the editor's source order relates to the kernel's session.
