- **Instantiating a `ShapeItems::Box` — any `CuboidOrTriangularPrism` — no longer reports its edge and vertex groups as errors.** The library pins `tfe`, `tflv` and their siblings only by `binding [1] bind [0..1] tf.edges = [0..1] tfe` bindings, which link one unspecified value of each end, so the model leaves the groups open. The check `-instantiate` makes over a new object now treats such a feature as it treats an unset attribute — nothing to report — instead of printing `binding end cannot be resolved` for every group, while reading a group (`-e p.b.tfe`, `%eval`, `%features`, the gRPC and LSP evaluation requests) still answers with the typed diagnostic naming the binding and both ends rather than an empty or invented value. Everything the model does determine (`faces`, `edges`, `tf.edges`, dimensions, face-local values) evaluates as before.
