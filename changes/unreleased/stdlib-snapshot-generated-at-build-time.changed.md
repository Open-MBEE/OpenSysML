- The bundled library's snapshot (`internal/workspace/libs/stdlib.snapshot`, 4.1 MB) and the Go file embedding it are generated at build time rather than committed: every Makefile build and test target runs `make stdlib-snapshot` first, so a `make build` binary still embeds a current one and starts from it, while a tree without the file — `go install github.com/Open-MBEE/OpenSysML/cmd/sysml@latest` from the module proxy, or a plain `go build` — compiles too and loads the library files at start-up, noted at debug level only. `make stdlib-snapshot-check` and the generator's `-check` flag are retired; `TestEmbeddedSnapshotIsCurrent` checks whatever snapshot the test build embeds.
