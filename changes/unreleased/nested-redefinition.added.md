- Nested redefinition: a chain redefinition written as a member of a type or usage, `attribute :>> mid.leaf.value = 99.0;`, now applies below every composite feature the chain walks, exactly as the nested-body form `part :>> mid { part :>> leaf { attribute :>> value = 99.0; } }` does — for declared values (`=` and `default =`), declared types, multiplicities and redefining bodies, on scalar and multi-valued intermediates alike. This is an OpenSysML extension (the pinned pilot accepts the notation but applies nothing below the first segment), so each chain is reported as a `nonstandard-semantics` warning, an error in strict mode, and an error in every mode when the chain crosses a `ref`, port or subject, which owns no object below it.
