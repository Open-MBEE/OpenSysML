- A literal bound to a feature typed by a supertype of its scalar type that is not itself in the scalar lattice — `attribute n : ScalarValues::NumericalValue = 0.5;`, or one typed by `ScalarValue` — is no longer reported as `cannot bind Rational value to a feature typed by NumericalValue`: the literal is a `Rational`, which `NumericalValue` generalizes (KerML 8.3.3.3.4), and the run time already held it. A literal of an unrelated scalar type (`"hello"` to `NumericalValue`) is reported as before.
