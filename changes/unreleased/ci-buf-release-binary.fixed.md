- **The protobuf lint and wire-compatibility checks no longer fail when the Go checksum database is unreachable.** The static-checks jobs ran `go run buf@version`, which resolves buf's whole module graph against `sum.golang.org` on every run; they now run the digest-pinned release binary the stub checks already used. One script, `scripts/ci-install-buf.sh`, holds that pin for every CI job, and hygiene tests fail when it differs from the Makefile's `BUF_VERSION` or when a CI step runs a buf target without the installed binary.
