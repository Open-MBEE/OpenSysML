- **`sysml -convert api-json -api-json-form full` writes every property the metamodel declares for each element's metaclass.** An unset single-valued property is written `null`, an empty multi-valued one `[]`, and a derived property its value computed from the resolved model: ownership and relationship ends come from the exported graph, and inherited, imported and typed values (`feature`, `inheritedMembership`, `membership`, `type`, `definition`, `featuringType`, `usage`, `directedFeature`, ...) from the engine's semantics. A derived property the engine cannot compute completely is left out rather than written partially. The compact form, holding only what the RDF graph states, remains the default.
