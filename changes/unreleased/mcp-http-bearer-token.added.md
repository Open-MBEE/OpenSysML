- **`sysml-mcp -token-file FILE`**, `-token TOKEN` and `OPENSYSML_MCP_TOKEN` authenticate the Streamable HTTP transport as the Model Context Protocol's authorization specification asks of a server on a network — an OAuth 2.1 resource server in the minimal form, with one bearer token issued out of band: every request on `/mcp` must carry `Authorization: Bearer TOKEN` (RFC 6750, compared in constant time) or is refused with `401` and a `WWW-Authenticate: Bearer` challenge naming the protected resource metadata, which is served at `/.well-known/oauth-protected-resource/mcp` (RFC 9728). The token is never logged, and serving it in cleartext off loopback is warned about. `-public-url URL` names the endpoint as clients reach it behind a proxy that terminates TLS, for the challenge, the metadata and the configuration block. `-print-config HOST -http ADDR` with a token writes the host's URL block with the `Authorization` header (Codex `http_headers`).
