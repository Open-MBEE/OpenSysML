- **The release build cross-compiles `sysml-jupyter-kernel` for Windows again.** `make build-jupyter-kernel` with `GOOS=windows` stamps the kernel's `VERSIONINFO` the way the other three binaries are stamped, from a `packaging/windows/sysml-jupyter-kernel.winres.json` that was missing, so `scripts/build-release-artifacts.sh` — and with it the nightly snapshot — no longer stops at the Windows kernel with `open packaging/windows/sysml-jupyter-kernel.winres.json: no such file or directory`.
