- **A flow's `from`/`to` ends and `of` payload are features the flow owns.** The symbol table registers an anonymous end feature for each end a flow or message states (`buildConnectorEnds`, as it does for a `connect` clause's ends) and a payload feature for an `of` clause that states a type without declaring one (`buildImpliedPayload`), so the semantic model and the symbol-backed metamodel structure own them: a flow's ends are `FlowEnd`s through `EndFeatureMembership`, a message's are `EventOccurrenceUsage`s through `ParameterMembership`, the payload a `PayloadFeature`; each end reference-subsets what it attaches to and redefines the `source`/`target` end at its position (SysML v2 §7.21, §8.2.2.13.1). `GetElementProperties` answers `connectorEnd`, `flowEnd`, `relatedFeature`, `sourceFeature`/`targetFeature` and `ownedFeature` for flows and messages, where it had refused the ends as unrepresented, and the inherited `source`/`target` library ends no longer stand in for a flow's own.
