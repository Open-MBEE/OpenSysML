- **`-import` and `%import` set feature values from CSV, TSV, JSON and JSON Lines files.** Each row names an element and the values its features take, with units as `mass [kg]`; a declared value is replaced and an inherited one redefined, including a feature reached through an inherited part (`Fleet::car1::engine`) or an alias. An optional JSON mapping file maps differently named columns and nested fields, each `-import-map` and `-import-format` qualifying the `-import` before it, and `-import-dry-run`/`dry-run` previews the edit. JSON numbers and Booleans may be written as strings. The file is checked whole and applied as one edit, so a row, value or unit the model refuses leaves it unchanged; `-convert sysml -o` writes the imported model. See `docs/manual/importing-data.md`.
