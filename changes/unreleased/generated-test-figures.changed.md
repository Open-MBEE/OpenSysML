- **The test-suite figures in the README and the compliance map are generated from the tree.** The conformance-case, golden-AST, golden-trace, negative-parser, robustness, gRPC and `Test`-function counts are counted by `cmd/doc-counts` the way the gates enumerate them — the conformance cases through `internal/fixtures`, which the runtime and gRPC conformance tests read too — and checked in CI, so a fixture landing regenerates them rather than leaving them stale. The hand-typed figures they replace lagged the tree (889 conformance cases where it carries 904); the tests-and-subtests total of a run, which only a run can state, is no longer quoted.
