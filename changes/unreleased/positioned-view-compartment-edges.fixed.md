- **The positioned DOT tree no longer draws a containment edge to a child boxed inside its owner's box.** Such a child draws as a compartment row of the owner, so the edge painted a connector across the box on top of the row; children boxed outside the owner's box keep their edges, and an unpositioned tree is unchanged.
- **Quoted-name escapes decode in graphical labels.** A `\n` escape in an element's name printed literally in the DOT, Mermaid and PlantUML forms instead of breaking the label line; `\t`, `\'`, `\"` and `\\` decode the same way, and the Cameo frame header decodes too.
- **A note whose stated box encloses a node now paints behind it.** Graphviz paints in file order, so a large note box — a Cameo text box used as a group frame — covered the nodes it framed; enclosing notes are written before the nodes and captioned at their top, notes enclosing nothing stay on top.
