- The gRPC service keeps a bounded, content-addressed parse cache across processes. When the record cache is enabled, `ParseSources` and `ParseFile` restore a document set's trees from disk instead of parsing it and rebuild its symbol index from those trees, so a fresh process answering bytes another process parsed makes no parse calls; an edit to one document re-parses only that document. The cache is keyed by each document's name, language and content and by the build, and parse records are evicted under a byte bound.
