- **An accept node exports as the `AcceptActionUsage` SysML.ecore makes it.** `accept sig : Signal;` and `action a accept sig : Signal;` are now typed `AcceptActionUsage` in Turtle and in the API element form alike, where they used to be an `ActionUsage` told apart only by the payload's `isAccept`; the payload is owned through a `ParameterMembership` and named as the accept's `payloadParameter`, the shape a transition trigger's accept action already had. Import reads the accept from that structure alone — the pilot's element form states neither `isAccept` nor `payloadParameter` — and writes both forms back as written, the bare accept without an `action` keyword.
