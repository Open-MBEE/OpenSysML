- **An accept node is written as an `AcceptActionUsage`.** `action a accept p : T;` and `accept T;` in an action body were written as an `ActionUsage` owning an `isAccept` reference; they are now the `AcceptActionUsage` the grammar builds (SysML.xtext `AcceptNode`), owning the payload as its `payloadParameter` through a `ParameterMembership`, as a transition's trigger already was. Graphs written with an `ActionUsage` still import.
