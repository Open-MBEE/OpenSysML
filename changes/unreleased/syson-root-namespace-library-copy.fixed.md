- **The SysON plugin drops a project's copy of a bundled library when SysON files it under its root namespace.** SysON puts every uploaded document, a user library included, under an unnamed root `Namespace` that its serializer never prints, so the exporter saw no `library package` at the resource root and sent the project's `DocumentQueries` copy to the service, where it shadowed the bundled library: the service warned that the root namespace has a standard library's name, and `part def MassReport :> Document` was refused as "not a document" because its `Document` was the copy's. The root namespace's members are now exported one by one, so an unextended copy is left out with the run message saying so, a copy that adds members is still exported with the warning, and the run's element ranges point at the members rather than at the namespace.
