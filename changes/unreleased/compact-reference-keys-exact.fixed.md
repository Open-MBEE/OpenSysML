- The compact API JSON form (`api-json-compact/1`) lists a key in `referenceKeys` only when every value under it is a reference or a collection of references. `value`, which holds both a feature value's reference and the string or boolean of a literal, was listed, so a reader following the documented rules read the string of `attribute a = "x";` as a handle; its references are now spelled `{"@id": h}`.
