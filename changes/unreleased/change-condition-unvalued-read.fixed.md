- A state machine change condition (`accept when coilVoltage >= 19.6`) that reads a feature carrying no value is no longer a runtime error that aborts the machine and the creation of the object exhibiting it. The condition has no Boolean result, so it has not become true: the machine keeps waiting in its state, `%current` names the unvalued feature it waits on, and the write that gives the feature a value re-evaluates the condition and takes the transition when it holds. An evaluation that fails on its own terms, such as a division by zero or a non-Boolean result, is still an error: the machine fails with it, recorded on the machine beside the object that stands.
