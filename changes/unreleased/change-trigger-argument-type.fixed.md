- A change trigger's argument wrapper, the `FeatureReferenceExpression` over the condition of `accept when c`, is typed by `Performances::Evaluation` like the condition it refers to; only the trigger invocation itself is typed by `Triggers::TriggerWhen` (and a time trigger's by `TriggerAt`/`TriggerAfter`). The two share one syntax node, which alone had typed the wrapper as the trigger.
