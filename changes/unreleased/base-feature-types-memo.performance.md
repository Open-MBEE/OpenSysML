- Analysing a model no longer derives the types a library base feature supplies once for every usage of that kind, nor allocates a visited set for every specialization-cycle check: the answer is memoized per base feature, owned by its declaring document, and a walk of a declared chain keeps its first 32 declarations in place. Diagnostics do not change; loading the stress model allocates 18% fewer objects and 6% fewer bytes and takes about 10% less time (`BenchmarkLoad`), `BenchmarkValidateSplit` allocates 23–25% fewer objects and 9–10% fewer bytes, and `BenchmarkAnalyze/synthetic` 14% fewer objects.
