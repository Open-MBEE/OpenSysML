- Test-side fixes with no change to the product. `tests/testutil/gobuild` hands a coverage run's counter directory to the Go runtime once, when the package is loaded, and fails loudly if it cannot; `gobuild.Args` no longer changes the environment. Every package whose tests build a command to drive as a process builds it with `gobuild.Scratch.Build`, into one directory that the package's `TestMain` removes; an interrupted run removes it too, and what a killed run left is removed by the next run of that package, instead of staying in the temporary directory. The FMI-engine tests remove the request file their stand-in runner writes. The corpora test of `GetElementProperties` accepts `element not found` only for a name the root cannot see, and new tests cover a document excluded for colliding ids and exclusions staying with their own document set. `abstract metadata def` has a positive parser case.
