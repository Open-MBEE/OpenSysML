- **Source-preserving authoring now writes documentation.** `add_member` and every Python `Editor` helper accept `doc`, written as the new member's `doc /* ... */`, and the new `add_documentation` operation documents an existing declaration by qualified name — giving a declaration that ends in `;` a body, placing the comment first, and refusing one already documented unless `replace` is set. Both require the new `documentation_authoring` capability, and the Go, Java and Python clients expose them.
