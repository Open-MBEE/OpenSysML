- A pull-request push that changes only a composite action under `.github/actions/` or the repository metadata under `.github` (`CODEOWNERS`, `FUNDING.yml`, the issue templates) now runs the quick CI tier. No area claimed those paths, so `scripts/ci-changed-areas.sh` escalated the push to the full tier (`-race` on every shard, every client). An action is now a service path like the workflows, and its push also runs the jobs that use it: the docs, Node, Python and MATLAB jobs for `apt-install`, the Java, MDK and SysON jobs for `maven-cache`, the derived-property differential for `corpora` and `pilot-validator`. The metadata, which no job reads, runs no area.
