- An attribute of an exhibited state machine assigned through the exhibit usage by another performance of the exhibiting part (`assign g.missDistance := …` from a `perform action` beside `exhibit state g`) now reaches the running machine: the machine's data mirrors the one performance the usage names, so a change trigger on that attribute (`accept when missDistance < …`) fires on the write instead of the machine reading its initial value for the rest of the run; an attribute the exhibit usage binds to the part's (`:>> missDistance = Flight::missDistance`) behaves the same.
