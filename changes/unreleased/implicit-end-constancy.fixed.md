- **An end feature that may vary in time is now read-only, as the specification's implicit constancy requires (SysML v2 §8.4.2.2, KerML 1.0 §8.3.3.3.4).** Reflection already answered `isConstant` true for such an end, but `FeatureReadOnly` did not, so assignments, flows, accepted payloads and `SetFeatureValue` wrote them; they are now refused with `… is constant as an end feature: its value does not change over the lifetime of its featuring occurrence`, statically and at run time. Interface records persist the derivation as a new `ModMayTimeVary` modifier, so recorded symbols answer the same flags as parsed ones.
