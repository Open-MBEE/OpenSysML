- **Each declared element states where it is written.** The Turtle and API JSON forms give every declared element `sysx:sourceLine`, `sysx:sourceColumn`, `sysx:sourceEndLine` and `sysx:sourceEndColumn`: 1-based, the end exclusive, as a diagnostic's span gives them. An element sharing a line with its owner, which has no `sysx:sourceText` of its own, is placed too. Reading a graph ignores them, as it ignores source text (#654).
