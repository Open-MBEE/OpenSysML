- **`ParseSources` analyzes a model of many documents in linear time.** Each document was analyzed in a context of its own, which gathered the workspace-wide audits over every document again, so a model of 320 documents took 15 s through the service where `sysml -validate` checks it in under a second. The documents are now analyzed as one batch, as a workspace analyzes them: 320 documents take 0.6 s, with the same diagnostics.
