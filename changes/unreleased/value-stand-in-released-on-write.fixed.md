- The object materialized to stand in for the unspecified value of a value-typed feature (an unvalued `out result : Boolean[1]` of a state definition a part exhibits, read when the machine starts) is dropped once the feature holds a value — by an assignment or an outside write, a binding resolving, a collection assigned whole, or under a redefining name — instead of staying registered as an object nothing holds; a write landing on an occurrence feature now also reaches the data of the machine running over it, so a held image of the part round-trips the graph the run leaves, and `InstanceCount`/`InstanceIDs` no longer count the stand-in.
