- The object materialized to stand in for the unspecified value of a value-typed feature (an unvalued `out result : Boolean[1]` of a state definition a part exhibits, read when the machine starts) is dropped once the feature holds a value — by an assignment or an outside write, a binding resolving, a collection assigned whole, or under a redefining name — instead of staying registered as an object nothing holds (it stays while another feature or a live run's data still names it); a write landing on an occurrence feature now also reaches the data of every run over it (the state machine, a performed action or an action run directly, a snapshot restored included), and a journal rolling the write back restores that data with the stand-in, so a held image of the part round-trips the graph the run leaves, and `InstanceCount`/`InstanceIDs` no longer count the stand-in.
