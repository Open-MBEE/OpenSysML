- **A release rehearsal now tests under the tag.** The rehearsal checked out a branch, so the Go toolchain recorded `(devel)` as the module version and every unstamped test binary reported `dev`; the real tag pipeline checks out the tag and the same binaries report the release version, which is how a `v0.10.0` test failure escaped a green rehearsal. The Go suite's jobs now tag the checkout locally as the release being rehearsed before building anything, and the stand-in `CIRCLE_TAG` is derived by `scripts/rehearsal-version.sh`.
