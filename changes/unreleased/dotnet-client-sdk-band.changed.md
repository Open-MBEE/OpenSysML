- The .NET client builds with any .NET SDK that the repository-root `global.json`'s `latestPatch` roll-forward admits — the pinned 10.0.402 or a later 10.0.4xx patch — so a servicing update such as Homebrew's no longer stops it from building; `dotnet` itself refuses another feature band, or an earlier patch. The client's `AnalysisLevel` is fixed at `10.0` rather than `latest`, so a newer SDK cannot add analyzer rules that fail the warnings-as-errors build. CI still builds with exactly the pinned SDK.
