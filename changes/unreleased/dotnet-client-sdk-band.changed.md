- `make dotnet-preflight` accepts any .NET SDK that the repository-root `global.json`'s `latestPatch` roll-forward admits — the pinned 10.0.402 or a later 10.0.4xx patch — instead of only the pinned version, so a servicing update such as Homebrew's no longer stops the .NET client from building. Another feature band, or an earlier patch, is still refused. The client's `AnalysisLevel` is fixed at `10.0` rather than `latest`, so a newer SDK cannot add analyzer rules that fail the warnings-as-errors build. CI still builds with exactly the pinned SDK.
