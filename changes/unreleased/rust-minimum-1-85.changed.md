- The Rust client's minimum supported Rust version is 1.85, up from 1.83. The current releases of `prost-derive`, `ureq` and `tokio` need Rust 1.85, so the crate now depends on `prost-derive` 0.14.6, `ureq` 3.5.2 and, for its tests, `tokio` 1.54.1 instead of holding each at its last Rust 1.83 release. A project built with Rust 1.83 or 1.84 stays on the previous release of the crate or moves to Rust 1.85.
