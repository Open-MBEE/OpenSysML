- A satisfy usage's `by` clause declares its subject parameter — an unnamed `ReferenceUsage` the usage owns through a `SubjectMembership` (SysML v2 §8.3.19) — which the symbol table now registers as the usage's first member. It redefines the satisfied requirement's subject, so it takes that subject's name and types (KerML §8.3.3.3), masks it, and binds the `by` value under it; the reflective `ownedRelationship`, `ownedMembership`, `ownedMember` and `subjectParameter` list it with the elementIds the RDF export writes, and a body `subject` beside a `by` clause is reported as the extra subject (`only-one-subject`).
