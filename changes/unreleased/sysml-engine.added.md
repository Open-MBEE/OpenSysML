- `sysml-engine`: a new command that serves the execution RPCs — `ParseSources`, `Evaluate`, `Instantiate`, `ExecuteAction`, `ExecuteState` — with the same JSON the `sysml-grpc` service emits, but without the protobuf and analysis machinery, so its WebAssembly builds stay small enough to embed. On `GOOS=js` it installs `globalThis.sysmlEngine.call(method, paramsJSON)` for a page to call synchronously; natively and under WASI it speaks the service's JSON-RPC over standard input and output. Exploration, verification, document queries and tools stay on `sysml-grpc`. See [WebAssembly builds](../../docs/reference/wasm.md).
