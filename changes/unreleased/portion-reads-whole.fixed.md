- A `snapshot` or `timeslice` usage nested in an occurrence reads the whole's value of every feature its own body does not value (`part panel : Panel { attribute :>> width = 3; snapshot atReview : Panel { attribute :>> height = 5; } }` — `panel.atReview.width` is `3` and the type's `product = width * height` evaluates over the portion to `15`), so a constraint over a snapshot's derived attribute no longer fails with `width has no value in the model`: a portion is the occurrence it is a portion of (SysML v2 §7.9.3, KerML 1.0 §7.4.5), its bound value beating the type's `default`, and a write to the whole is seen by its portions.
