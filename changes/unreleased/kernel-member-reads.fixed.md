- **Every Kernel Semantic Library member of an object reads.** `p1.self`, `p1.timeSlices`, `p1.superoccurrence`, `p1.localClock`, `p1.predecessors` and the other members an object inherits from the Kernel Semantic Library failed as `object has no such feature: member <m> not found in instance`, the same text a name the type lacks produced, while the same reads on an action usage answered `<undetermined>`. The Kernel tier stays out of the object's shape; a read of one of its members is now answered by one rule, on every surface (expression chains, `self.<m>` in a definition body, action and state objects, `%eval`, the gRPC `FeatureValue` RPC): `self` is the object and every collection `self` subsets (`timeSlices`, `portions`, `spaceSlices`, …) holds it; a member the library gives a value (`localClock default universalClock`, `this default self`) evaluates it; a member declared `inverse of` a composite collection is answered through composition (`p1.pa.superoccurrence` is `p1`); a lower bound of 0 with nothing recorded is empty or null (`predecessors`, `incomingTransfers`, `middleTimeSlice`); a lower bound of 1 or more with nothing recorded is undetermined (`snapshots`). A name the type lacks is refused naming the type (`p1 has no member ownedParts`), and a name a redefinition masks names the redefinition (`p1 has no member startShot: Parts::Part::start redefines it`). Writes are unchanged.
