- **The landing page's stack diagram draws each project's subsystems inside its box, and titles the Go project "OpenSysML Runtime Environment and Development Kit".** `docs/assets/opensysml-stack.sysml` models the subsystems of all four projects as nested parts, each with a label and a role shown on its card: OpenSysML's parser and formatter, validation, standard library, language server, editor integrations, REPL, Jupyter kernel, execution runtime, constraint solver, analysis engines, gRPC service, clients and bindings, document generation, interchange, SysML v1 migration and OSLC query; sysml-toolkit's, the Pilot's and Flexo MMS's likewise. Right-clicking a nested part shows its card, and dragging a project box carries the parts drawn inside it.
- **Diagrams pack a container's unconnected children into rows.** The automatic layout stacked every nested part no edge reaches in one column, however many there were; a container of such parts now lays them out side by side, sized toward a wide aspect ratio, while connected nodes keep their layers.
- **Diagrams keep siblings in a layer in the order the model declares them.** Crossing minimization used to decide which of several boxes in one layer sat on top; the layout now seeds the layered pass with the declaration order and minimizes crossings interactively from it, so a diagram reads as its model is written. The landing stack declares OpenSysML, then the Pilot, then sysml-toolkit, and is drawn in that order.
