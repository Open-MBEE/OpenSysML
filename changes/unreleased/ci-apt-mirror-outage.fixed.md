- CI installs its apt packages (Z3, Octave, mandoc, poppler-utils, the PDF toolchain's libraries) through one action, `.github/actions/apt-install`, that keeps the `.deb` set each install fetched in the Actions cache, keyed on the package set and the runner image. A run on which no Ubuntu mirror answers `apt-get update` or the fetch installs the cached set offline, from the files, instead of failing in its setup step before a test ran; a run with neither a mirror nor a cached set fails within the step's bound as before, and the set is rewritten after every online install to exactly the archives it used, so an archive the index moved on from leaves the cache. `scripts/ci-apt-install-test.sh` plays the outage against a stand-in apt on every pull request.
