- The VS Code extension is `opensysml` (id `open-mbee.opensysml`, packaged as `opensysml.vsix`), no longer `opensysml-sysml`; VS Code treats a side-loaded install of the old id as a different extension, so uninstall it (`code --uninstall-extension open-mbee.opensysml-sysml`) before installing the new one. Tagged releases now carry `opensysml.vsix` in the signed `SHA256SUMS.txt`, checked to carry the tag's version, as the nightly snapshot does.
