- **`first a if g then b;` in an action body is a `TransitionUsage`.** The keyword-less guarded succession was read as a `SuccessionAsUsage` carrying its guard as text, while `succession first a if g then b;`, which the grammar makes the same `GuardedSuccession`, was a `TransitionUsage`; both are now the transition, with its guard owned through a `TransitionFeatureMembership` of kind `guard`. A transition in an action body converts back in the keyword-less spelling unless it was written with `succession` or declares a name, never as `transition`, which an action body does not admit.
