- `sysml -convert api-json`, the `Convert` RPC and the element-form index no longer derive every completed property of a model twice. The graph they write from used to be built as the Turtle writer needs it, with a pass that evaluated each element's derived properties only to find the standard-library members an inherited property references, and the writer then derived them all again; the element form now names those members from the elements it writes. On a 64-file model of 421,583 elements the conversion's wall time falls from 4 min 13 s to 2 min 59 s and its peak resident set from 23.1 GB to 21.9 GB (17.2 GB to 13.3 GB under `GOGC=25`), with a byte-identical element array. `-library-references` additionally names a library element the array references through a name the model left unresolved and the writer resolved in the library, which the table used to leave out.
