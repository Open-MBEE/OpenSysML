- An assignment, a `while` or `loop` action and a `for` loop own the parts of their statements as parameters, as an `if` action already did: `GetElementProperties` returns two `parameter`s and `input`s for `assign x := 1;` (the target's and the value's `ReferenceUsage`), three for `while c { … } until d;` (the two conditions and the body's `ActionUsage`, with an empty parameter standing for the condition of a `loop`), and two for `for i in c { … }` (the collection's `ReferenceUsage` and the body) after the variable it owns through a `FeatureMembership`. What a loop's braces declare is owned by the body's action rather than by the loop, and a conversion writes the same elements, so a graph carries the `ParameterMembership`s and reads back to the same notation.
