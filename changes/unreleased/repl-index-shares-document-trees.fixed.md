- The REPL and the `sysml` command index each loaded document over the scope tree the document already built, instead of a second tree built from its AST, so a declaration reached from another file's scope — a qualified enumeration literal in a `-calc` argument, a package-level default a part in another file reads — is the one symbol the runtime holds. Before, with more than one file loaded, the two trees gave one enumeration literal two identities, so `==` and `includes` compared them unequal: a calc's enum-typed parameter never matched the literal in its body unless the defining file was loaded last, a rollup over units whose modes came from a default in another file summed to zero, and a `+` of two such rollups kept only the term that happened to resolve in the right tree.
