- **Structured render nodes, ports and edges carry the element's durable id.** `element_id` on `RenderNode`, `RenderPort` and `RenderEdge` reports the effective element id the written forms link to through `{id}`, beside the render-local `id` that only names a node within one rendering. The gRPC, engine, LSP and all client surfaces expose it, so a canvas can address a declaration without resolving its identity again. Unnamed declarations with no name of their own — connectors, successions, transitions and flows alike — are named by their positional identity, so every unnamed edge under one owner gets a distinct id in both the structured field and the written anchor, and `GetElementProperties` resolves it back to its declaration. The post-render walk deduplicates shared nodes, keeping id resolution linear on folded and expanded renderings. Deriving positional identities during a render uses the renderer's already-resolved model, so it does not change what later renderings draw.
