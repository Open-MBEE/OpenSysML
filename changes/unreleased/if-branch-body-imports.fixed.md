- An import written in the body of an `if`, `else if` or `else` branch takes effect in that branch: `if n < 3 { private import Q::*; part v : T; }` types `v` by `Q::T`, where `T` was reported unresolved before. As in a plain action body, the imported name is found before the same name in an enclosing namespace, a call in the branch is matched against what the branch imports, and neither the condition nor the other branches see the import. The filter such an import states (`import Q::*[...]`) is validated where it is written, in an `if` branch and in a loop body alike; an invalid one was accepted silently before.
