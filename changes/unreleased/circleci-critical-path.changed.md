- **The CircleCI `build-test` workflow on `develop` and `main` finishes sooner and no longer queues behind the pipelines it supersedes.** A first job, `Cancel superseded pipelines`, cancels the branch's older still-running `build-test` workflows through the CircleCI API when the project environment variable `CIRCLECI_API_TOKEN` holds a CircleCI personal API token (`CIRCLE_TOKEN` is already the release jobs' GitHub token); without one, or with one the API rejects, it says so and the pipeline continues. The Go jobs require it, so it runs before they take containers. The binaries the client jobs test against are built by a new `Go binaries` job (minutes, not the 30-minute `Go gates` job, formerly `Go gates and binaries`), so the nine client and plugin jobs start as soon as it finishes instead of after the whole Go suite, and the SonarCloud scan waits only for what it reads: the coverage profile, the static checks' landing bundle and the clients' reports. The executors without a Go toolchain install Go from a tarball that is downloaded to a file, checked against its published SHA-256 and retried twice with backoff, where the orb's streamed download failed the job on one dropped connection.
