- **A lone carriage return in a comment now reads as a line break.** KerML 1.1 §8.2.2.1 counts `\r`, `\n` and `\r\n` as line terminators, but `Comment::body` processing (§8.2.3.3.2) and the documentation prose treated only `\n` and `\r\n` as line breaks. A comment written with lone `\r` line endings therefore kept each later line's `*` margin in its body, in reflective reads and in the API JSON and RDF exports. It now reads the same as its `\n` spelling.
