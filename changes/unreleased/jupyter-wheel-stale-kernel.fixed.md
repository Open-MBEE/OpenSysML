- **A `jupyter-opensysml-kernel` platform wheel bundles only its own kernel.** The release built the five wheels from one source tree, and setuptools kept the kernel staged for the previous platform in `build/lib`, so the `win_amd64` wheel carried the macOS arm64 `sysml-jupyter-kernel` beside its `sysml-jupyter-kernel.exe` (the other four wheels were unaffected, each overwriting the same file name). `setup.py` now drops a stale kernel from the build tree before every wheel, and `scripts/build-jupyter-kernel-dist.sh` refuses a wheel whose `jupyter_opensysml_kernel/bin/` holds anything but the one kernel for its platform.
