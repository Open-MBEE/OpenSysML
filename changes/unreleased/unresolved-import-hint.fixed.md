- **An unresolved name among namespaces whose imports are themselves unresolved no longer stalls analysis.** The hint explaining an unresolved name reads the imports around it, resolving each target; a target that failed to resolve on that account asked for a hint of its own, and with several unresolved imports in namespaces that import each other the hints multiplied without bound. A lookup made on behalf of another now reports nothing and so computes no hint, and a library namespace, which hides nothing, is not read for one.
