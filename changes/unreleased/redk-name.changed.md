- **The Go project is named the OpenSysML Runtime Environment and Development Kit (OpenSysML REDK).**
  "OpenSysML" alone names OpenMBEE's open source SysML v2 suite and its community; the README,
  the documentation site's title and landing page, the community page and CONTRIBUTING now call
  this repository the REDK, so the runtime and the suite it belongs to no longer share one name.
  Package, module, binary and environment-variable names are unchanged.
