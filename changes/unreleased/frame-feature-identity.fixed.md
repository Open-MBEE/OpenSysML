- **A body reads a name as the feature name resolution binds it to, not as whatever nearest frame binds that spelling.** Lowering now carries the declared feature on each `Attribute`, `Declare` and `Accept` node, every frame indexes its bindings by that feature beside the simple name, and a read resolves the name in its own scope first and reads the frame holding that feature. A short name now reads the value the performance holds (`attribute <sx> x` written through `x` and read through `sx` no longer answers the declaration's default), a body attribute shadows a same-named accept payload instead of being overwritten by it, and a transition declared in a state definition reads the definition's attribute rather than a same-named attribute of its source state or exhibiting part.
