- A `/* */` comment written where a member may appear — before a member, at the close of a body, or at either end of a file — is now the `Comment` element KerML's `Comment` production makes it (one with neither name nor `about`), owned by the namespace it is written in, so it reaches the API JSON and the RDF graph and comes back from both; before, only `comment /* */` did, and such a comment was lost in conversion. A second comment after a `doc` or `comment` body is likewise a `Comment` of its own rather than the body. A comment inside a declaration or an expression stays trivia, as the nonstandard-notation warning states.
