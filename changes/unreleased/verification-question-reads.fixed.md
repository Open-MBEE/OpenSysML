- **Verification questions read the model the way evaluation does.** A chain through a requirement's subject under `satisfy … by` reads the `by` object's values rather than an unbound feature, so `holds` and `satisfiable` pin what a check reads; a fixed value whose read fails — a declared default dividing by zero — makes a question about it undecided with that error instead of leaving the variable free; and a validation summary stamps `question` and `status` like a verify verdict.
