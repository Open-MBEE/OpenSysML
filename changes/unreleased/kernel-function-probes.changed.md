- A call of a Kernel Function Library declaration the runtime does not evaluate as a function (`BaseFunctions::'istype'`, `'hastype'`, `'@'`, `'as'`, `'meta'`, `'all'`, `'['`) is refused with the library's reason — the function is abstract and its type parameter is a type reference the operator notation evaluates — before its arguments are read, where it failed as `cannot evaluate definition <Type>` before; the conformance record pins every such declaration beside the operator notation that evaluates, `ComplexFunctions::ToString`/`ToComplex`, `NaturalFunctions::'/'` and `OccurrenceFunctions::create` on real receivers.
