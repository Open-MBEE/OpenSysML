- **Queries answer `symbolKind` and requirement `text`.** `symbolKind` is the kind `GetSymbol` reports as `SymbolInfo.kind` (`partDef`, `stateUsage`, `actionUsage`), read of every row, so a listing no longer needs one `LookupSymbol` per row and a row with a positional `@id` answers it too; OSLC text writes it `sysx:symbolKind`. `text` is `RequirementDefinition::text` / `RequirementUsage::text`, the bodies of the requirement's `doc`, absent for a requirement that states none. Both join the closed set of queryable properties the SysML v2 API `Query` lists when it refuses an unknown name.
