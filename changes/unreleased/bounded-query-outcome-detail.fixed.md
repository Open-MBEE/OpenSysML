- The `QueryOutcome` status detail a failed `Query` or `RunDocumentQuery` carries is bounded: each frontier lists at most eight members, features or kinds — the spellings nearest the step's argument first — with the whole count in the new `membersTotal`, `featuresTotal` and `kindsTotal` fields. An unknown property's frontier used to name every metamodel property, which pushed the status trailer past gRPC's 8 KiB metadata limit and made grpc-core clients fail with `RESOURCE_EXHAUSTED` instead of `INVALID_ARGUMENT`. The CLI's `-json` record and the REPL still carry the whole list.
