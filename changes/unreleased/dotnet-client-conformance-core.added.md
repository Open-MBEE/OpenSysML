- The core of a .NET runner for the language-independent conformance suite, in `client/dotnet/src/OpenMBEE.OpenSysML.Conformance`: it reads the scenarios strictly and in a stable order, resolves their placeholders and decodes each request by the schema without rounding 64-bit integers, gates scenarios by capability, normalizes and compares answers by the suite's rules as the reference runner does, and writes the reference runner's JSON and JUnit reports. Every comparison rule is pinned by a case that must hold and one that must not, and a whole run is pinned by goldens.
