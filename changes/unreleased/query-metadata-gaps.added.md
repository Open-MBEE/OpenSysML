- Document queries traverse `dependency` declarations and both `allocation` and the notation's `allocate` spelling as row-set edges; a refusal of another kind names every supported kind. `StateUsage` rows answer the Boolean `isActive` property from the session's state machines, and a new `annotations` property reads every annotated row's metadata bindings — including nested bindings — in one pass instead of one symbol lookup per element. A declared or held feature named like either property wins the bare name in document queries; `@isActive` and `@annotations` (OSLC `sysx:@isActive`, `sysx:@annotations`) always read the evaluator's property. Activity aggregates over every copy of a state declaration and stays inside the visit budget over a large population.
- The edit API gained `SetAnnotationValue`, which rewrites the value an annotation usage binds to a metadata feature without changing the metadata definition's default.
