- Magic MDK: *Export as SysML v2…* on the Magic MDK context menu writes the project as SysML v2 text. A SysML v1 project is migrated with every diagram laid out as a view (`DiagramLayout` metadata from the project's own diagram symbols, or from an MTIP export when one is chosen) and the migration report lands beside the file; a SysML v2 project's text is written as the tool exports it. The design note `docs/internals/design/mdk-mtip.md` records how MTIP's HUDS export and import fit the parity plan with OpenMBEE MDK.
