- The language server answers `textDocument/signatureHelp`, `textDocument/codeLens` and `textDocument/inlayHint`. Signature help lists the parameters a calculation, function or action call binds, with their types, the ones that have a default bracketed, and the parameter the cursor's argument binds active, whether positional or named. Code lenses count the references to each definition and offer a *Run* or *Evaluate* command, naming the element, on each executable action, state, calc, constraint and requirement declared outside another behavior. Inlay hints show the inferred type of a feature declared without one, when it is more specific than `DataValue`, and the constant a feature's value evaluates to from the model alone. All three are advertised in `initialize`.
- The VS Code extension runs a *Run* or *Evaluate* lens as a task: `sysml -action`, `-state`, `-calc`, `-constraint` or `-requirement` over the workspace folders after saving every unsaved model file, with `sysml` found beside the `sysml-lsp` in use, in the workspace's `bin/`, or on `PATH`.
