- The .NET client loads and reads models: `Connection.LoadAsync` parses a file the service reads, `LoadContentAsync` inline SysML or KerML, `ParseSourcesAsync` several documents as one model, and `ModelByHash` names a model parsed earlier. A `Model` keeps its hash, roots, parse diagnostics and errors (`RequireNoErrors`), and answers `SymbolAsync`, `FindAsync` and `LookupAsync` (by short or qualified name, the outermost first, with near-name suggestions), `GetDiagnosticsAsync` under a lint selection, `EvalAsync` and `EvaluateAsync` in a scope or against a subject, and `InstantiateAsync`, whose `Instantiation` resolves instance references. Every field the service reports is read into immutable records (`Symbol`, `TypeFacts`, `Multiplicity`, `Specialization`, `Diagnostic`, `Instance`, `FeatureValue`). An option needing a capability the service lacks is refused before anything is sent; a model the service no longer holds is a `ModelNotFoundException`, an unreadable file a `ModelFileNotFoundException`, and a failure reported inside an answer a `ModelException`. `OpenSysMLClient.LoadAsync` and `LoadContentAsync` return a model owning a connection of its own, which disposing it closes. The Vehicle sample now parses a model and evaluates it.
