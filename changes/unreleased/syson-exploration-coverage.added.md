- The SysON plugin's run results carry the coverage of every explored run: `OpenSysMLRunResult.coverage` (`OpenSysMLCoverage` of `OpenSysMLCoverageEntry`s — `path`, `declaration`, `runs`) lists the states entered and transitions taken across every run of an action or state-machine exploration, not only each outcome's witness, and the results panel shows them under **Coverage** as the `sysml` command does (`coverage over all runs: 4 states entered, 4 transitions taken`, then one line per state and transition). The backend builds against the Java client's `Exploration.coverage()` and the pull-request workflow now runs the SysON plugin job on every `client/java` change, as it already did the Magic MDK plugin's.
