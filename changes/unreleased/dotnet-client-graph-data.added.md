- The .NET client exports graphs, imports data and compares a SysML v1 tool's results. `Model.ExportGraphsAsync` answers the `Graphs` of an action or state machine: the canonical `graphs:<version>` JSON an external engine is sent, kept exactly as the service wrote it, with its version and the subject as resolved. `Model.ImportDataAsync` sets the feature values CSV, TSV, JSON or JSON Lines `DataImport`s assign, each read by its name's extension or a named format and by its own header or a JSON mapping, in order as one edit each, and answers an `ImportResult`: an `ImportedFile` per file with each `ImportedValue` assignment, the edited notation of a model of one document or each `EditedDocument` of several, and the new `Model` the service holds, leaving the model imported into as it was; `ImportOptions.DryRun` reports the assignments alone and makes no model, and a refused import raises `ModelException` with the diagnostics behind it. `Model.CompareResultsAsync` runs the configurations a results index names under `CompareOptions` (the configurations, runs, seed, draws, clock step, observables and engine) and answers a `Comparison`: per configuration its status, its runs as sweep rows, each observable's stored and computed `ComparedDistribution`, their `StatisticDifference` and the `CaseStatistics` a Monte Carlo case declares, and the engine that ran them; results nothing of which could be compared raise `CompareException`. `ImportResult.SaveAsync` writes the imported notation without ever leaving a partial file or replacing one unless asked. The conformance runner covers ExportGraphs, ImportData and CompareResults, so it now covers every RPC of the service.
