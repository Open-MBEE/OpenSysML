- **The SysML v1 migrator performs interaction uses and checks state invariants.** An interaction use is a `perform` of the referenced interaction's scenario at its place among the messages, its arguments bound to the scenario's parameters and a message through an actual gate carried by the performed scenario; an interaction holding one migrates and executes instead of being refused. A state invariant is an `assert constraint` the scenario orders among its steps, so the run checks it where the diagram places it.
- **An `assert constraint` a succession orders among an action's steps is checked when the flow reaches it.** A false condition ends the run with the assertion's violation; one no succession names is still not a step.
