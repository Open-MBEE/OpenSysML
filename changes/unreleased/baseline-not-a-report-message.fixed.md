- **A `-baseline` file that is not a JSON report is refused in plain words.** `sysml -validate -baseline` answered a file holding other JSON with the decoder's own error, Go type names included, and read any JSON object without `diagnostics` (`{}`, a SARIF log) as a baseline that knows nothing. It now says what the file holds instead of the report `-validate -json -o` writes, and refuses an object that has no `diagnostics`.
