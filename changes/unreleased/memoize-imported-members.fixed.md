- **The resolver keeps the members an import surfaces for the query that asks again.** Enumerating what a wildcard import brings into a namespace — the members of the imported namespace, those its own imports re-export, less what a colliding membership hides — was computed anew for every document a references query indexed and every occurrence a rename rewrote, and dropped when the enumeration returned; on a workspace of re-exporting packages one references query enumerated the same imports thousands of times, a gigabyte of member lists per query. The enumeration is now kept per import and namespace, journaled with the document that wrote it so an edit drops it, and kept only when nothing it read was still being computed.
