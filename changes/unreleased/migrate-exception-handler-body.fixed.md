- SysML v1 migration: a node that is a UML `ExceptionHandler`'s `handlerBody` no longer starts with the activity and runs unconditionally beside the main flow. SysML v2 has no exception handler, so each handler is reported as not migrated (its protected node, body and exception type, or that it names none and so catches nothing in UML) with a `/* not migrated: ExceptionHandler … */` note, and the body is written as a `ref action` nothing starts and the migrated action does not perform, its own steps and layout kept.
