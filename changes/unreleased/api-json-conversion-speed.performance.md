- **Converting a model to `api-json` takes about a third less time, with the same output.** The encoder's graph now vouches that its collections are stated in their annotations' order, so the writer neither re-checks them nor parses each collection's JSON annotation back; the documents' graphs are merged without testing every triple against all the others; and the ontology's class and property lookups are computed once. On a 186-document model the whole conversion takes 2.9 s instead of 4.3 s, byte for byte the same.
