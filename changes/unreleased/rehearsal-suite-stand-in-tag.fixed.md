- A release rehearsal no longer fails its Go suite jobs with "the changelog records vX.Y.Z as released, but client/release-digests.json does not pin it": the suite jobs tagged their checkout as the release but did not export the stand-in `CIRCLE_TAG` the build and publish jobs run with, so the hygiene test read the local tag as a release that was already out. The rehearsal command that tags the checkout now exports the stand-in tag first, and the suite's tag-only checks (the protobuf breaking-change baseline, the binaries' version) run as they do on the tag.
