- **A state machine declaring no substate is active in itself.** A state usage or definition whose body states no substate — `exhibit state phases : StateAction;` (the library definition contributes no content), `exhibit state idle;`, `state def Standby { entry action note { … } }` — failed at initialization with `no initial state found in state machine <name>`, so the object exhibiting it was created with a failed behavior and `sysml -state` refused the definition. SysML v2.1 §7.18.1 asks for an active substate only of a state that has substates, and the notation makes the entry transition optional, so such a machine now performs its entry action, starts its do action and stays active with no current substate, and `isActive` of its usage is true. A machine that declares substates and no `entry; then <state>;` into them is still refused with the same message.
