- The .NET client's standalone `OpenMBEE.OpenSysML.Metamodel` assembly reads exported model JSON into its metamodel types without a service, as the Python client's reader does: `MetamodelGraph.ReadJson` takes a file, a stream, a `JsonDocument` or `JsonElement`s holding the SysML v2 API's element array, DataVersions or a Commit, or sysml-toolkit JSON, and returns a complete, immutable graph that keeps none of the source's JSON. `All<IPartUsage>()` selects elements by metamodel ancestry, `Roots` returns the namespaces nothing owns, and `GetValue` reads a property untyped. With `ReadOptions.KeepExtensions`, each element's `Extensions` keeps the keys its metaclass has no property for, such as OpenSysML's `sysx:sourceText`, as written and independent of the source. `@type`s are matched with or without a `sysml:` prefix or SysML IRI; one the metamodel lacks is read through `ReadOptions.Supertypes` or as `Element`, and one naming an abstract metaclass as that metaclass. A document that is not an element graph fails with `MalformedDocumentException`; a value that does not fit its property, or a reference the document does not resolve, such as one to a standard-library element, fails only reads of that property with `MalformedValueException` or `UnresolvedReferenceException`. `ReadOptions.CheckRanges = false` keeps references outside their property's metaclass, which some exports write for derived values, readable through `GetValue`. The `MetamodelReader` sample reads an export with no client library or service.
- Every metamodel reader source rejects duplicate keys in nested objects, including ignored extensions and envelope metadata, and reports invalid UTF-8 or undecodable Unicode identities and property names as `MalformedDocumentException`. An undecodable Unicode property value or reference target fails only reads of its property with `MalformedValueException`; opaque extension values remain as written.
