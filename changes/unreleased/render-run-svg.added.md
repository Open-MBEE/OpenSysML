- `-render-run` writes a run's timeline or sequence as a self-contained SVG drawing with the `svg` form (`.svg` output, or `-render-form svg`) and as an SMIL-animated replay of the run with `svg-animated` (`-render-form svg-animated`): a timeline's lanes and state bars over a time axis with a sweeping cursor brightening the state held, a sequence's lifelines and message arrows appearing in run order with a marker travelling along each. No script, no external reference, deterministic output, one second per step of the run; a viewer without SMIL shows the complete final picture. `%render-run` and the `render_run` MCP tool take the same form names, and `-render-link` links lanes, single-state spans and participants as the PlantUML form does.
