- The PDF toolchain that `scripts/download-doc-pdf-toolchain.sh` provisions, and that CI tests `-doc-form pdf` against, pins WeasyPrint 70.0 instead of 69.0. Version 70.0 fixes CVE-2026-106443 (GHSA-r543-q48m-4c9j), in which an EPS image reached the Ghostscript interpreter and could run code. `sysml` runs whichever WeasyPrint `OPENSYSML_WEASYPRINT` or `PATH` names, so an installed 69.0 or earlier should be upgraded.
