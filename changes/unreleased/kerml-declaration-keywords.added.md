- **A declaration keyword only KerML spells — `connector`, `class`, `struct`, `datatype`, `classifier`, `subclassifier`, `feature`, `step`, `expr`, `bool`, `behavior`, `function`, `predicate`, `metaclass`, `assoc`, `assoc struct`, `interaction`, `inv`, `multiplicity` — is now reported as `kerml-notation` in a `.sysml` file**, the way `namespace` and `featured by` already were: a warning by default naming the SysML spelling where one exists (`connector c from a to b;` → `connection`/`connect`, `class` → `occurrence def`, `inv` → `constraint`), an error under `-strict`, pointed at the keyword, with no `-fix` since a keyword swap changes the declared kind. The members of a reported declaration are not reported again. The declaration stays parsed, and a `.kerml` file, or a snippet the REPL loaded from one, stays silent; the pinned pilot rejects each of these in a `.sysml` file with `no viable alternative`.
