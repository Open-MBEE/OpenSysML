- The API JSON element form now states what the OMG API JSON shape carries for three authored facts an external reader otherwise misreads: `isComposite` is written `true` or `false` on every feature and usage (`part wheel` reads back composite, `ref item cargo` keeps its `ref`), a `MetadataAccessExpression` owns the `Membership` of the element it reads and derives `referencedElement` from it, and the standard library elements a model references are bare `@id` references rather than ownerless `isLibraryElement` stubs a reader would take for new roots. Turtle still names the library elements it references; older documents with stubs, with only `referencedElement`, or with no false flags read as before.
