- A `#M` prefix on a definition, usage, parameter or package (`#FailureMode state overheated;`, `in #FailureMode pressure : Real;`) now declares a `MetadataUsage` symbol owned by the annotated element, as the body spelling `@M;` does (SysML v2 `PrefixMetadataMember` is an `OwningMembership`), so the query API, `child_ids`, `children()` and every other scope-driven surface list it; reflection (`ownedAnnotation`, `annotatedElement`, `ownedMember`) and the API JSON export are unchanged.
