- gRPC `GetElementProperties` reads a parameter an action's notation states the same by qualified name as by id: `P::A::s::payload`, `P::A::acc::receiver` or `P::A::cond::thenClause` answers its `qualifiedName`, `owner`, `owningType` and `featuringType` instead of an element with every property empty, and reading one by name no longer empties the `input` of its `if` action afterwards. A parameter the element form holds no element for (a loop's `body` and `seq`, an assignment's `replacementValues`, a terminate's `terminatedOccurrence`) answers `element not found`.
