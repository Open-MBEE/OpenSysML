- gRPC `GetElementProperties` reads a parameter an action's notation states the same by qualified name as by id: `P::A::s::payload`, `P::A::acc::receiver` or `P::A::cond::thenClause` answers its `qualifiedName`, `owner`, `owningType` and `featuringType` instead of an element with every property empty, and reading one by name no longer empties the `input` of its `if` action afterwards. A parameter the element form holds no element for (a loop's `body` and `seq`, an assignment's `target` and `replacementValues`, a terminate's `terminatedOccurrence`, bare or with its occurrence) reads by name as the feature of the action's kind it redefines (`Actions::terminateActions::terminatedOccurrence`), with the same answer by that element's id, and a `for` loop's variable reads as the parameter the loop owns (`P::A::forAct::i`). Spec target, follow-up: such a name answering the parameter its action owns, and `parameter` and `input` listing it for an assignment, a loop and a terminate, where they stay empty.
