- Binary `+` and `-` written with an empty second operand (`1 + null`, `3 - ()`, `x - y` for a `y` holding no value) now evaluate as the invocation KerML 1.1 §8.4.4.9.6 makes them, `'+'(1, null)` and `'-'(3, ())`: the library declares `y` as `[0..1]`, so the operator is the unary sign (`1`, `-3`), as the function form already answered. An empty first operand (`null + 1`) and an empty operand of `*`, `/`, `%`, `**`, `^` or a comparison stay refused, since those parameters are `[1]`.
