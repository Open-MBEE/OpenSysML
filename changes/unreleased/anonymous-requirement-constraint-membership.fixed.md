- An anonymous `assume constraint { … }` or `require constraint { … }` is now a member of its requirement's `assumptions` or `constraints` collection exactly as a named one is, the definition's inherited constraints included, so `allTrue(req.constraints())` reads a violated anonymous required constraint as `false` instead of passing over an empty sequence. An anonymous constraint usage is a feature of its owner's shape under its positional name, `Owner::@N`.
