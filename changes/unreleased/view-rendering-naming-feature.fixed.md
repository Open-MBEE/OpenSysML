- A view's `render tree;` is exported to Turtle and API JSON under the name of the rendering it references — `qualifiedName` `V::tree`, `name` `tree`, no `declaredName` — as SysML v2 `RenderingUsage::namingFeature` and the SysML v2 API name it, rather than by its position (`V::@0`). The same holds for every other member named by its naming feature instead of a declaration: `perform a;`, `exhibit s;`, `include uc;`, `frame c;`, `require r;`, `assume r;`, a variant reference and `part :>> engine;` now carry `sysml:name` and the effective qualified name; graphs that still name such a member by position read back as before.
