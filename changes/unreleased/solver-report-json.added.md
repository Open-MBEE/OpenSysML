- `%optimize <name> -json` and `%configure <name> ... -json` write the solver's answer as one JSON document rather than prose: per report its `subject`, `status`, `solver`, the `values` of the assignment with each quantity's magnitude, `unit` and `dimension` apart, the text `lines`, and for `%optimize` the `optima` per objective, for `%configure` the `selections` found and whether the enumeration was `truncated`. An `unsat`, `unknown` or `unavailable` answer keeps its status and its explanation in `lines`. Without `-json` both commands print what they printed before. See [Solver reports as JSON](docs/reference/repl-commands.md#solver-reports-as-json).
