- Renaming a feature rewrites the references that name it through a feature declaring no name of its own (KerML 1.1 §8.3.3.3): after `perform run;` in `part line`, renaming `run` rewrites `line::run` and `line::run::load` too, as it does a reference through a nameless redefinition (`:>> mass;`), rather than leaving them unresolved. The LSP rename and the reference index list those segments under the renamed feature.
