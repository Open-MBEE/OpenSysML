- **A printed String reads back as the same String.** The interpreter and compiled C and Go programs printed a String with an unprintable character as a Go escape such as `"\u200b"`, which neither a String literal nor a compiled program's argument admits. A String now prints in KerML String notation: only the quote, the backslash and `\b \t \n \f \r` are escaped, and every other character is written as it is, so a result can be given back as input.
