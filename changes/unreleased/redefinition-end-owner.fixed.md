- `redefinition-not-end` now follows KerML 1.1 Beta 2 `validateRedefinitionEndConformance`: a non-end feature redefining an end feature is reported only when its owning type is an Association or a Connector. A usage typed by a connection definition (or a KerML feature typed by an association) may redefine an inherited end without `end`; redefinitions inside connection, interface, allocation and flow definitions and usages, KerML associations and connectors are still reported.
