- The requirement a `satisfy r by v;` or an objective's `verify r;` names is now recorded as the usage's reference subsetting (`ast.RelReferences`, a `ReferenceSubsetting`), as SysML v2 §8.2.2.21.2 (`SatisfyRequirementUsage`, `RequirementVerificationUsage`: an `OwnedReferenceSubsetting`) declares it, where the parser recorded a plain subsetting that each reader had to recognize by position. A specialization written after the reference (`satisfy r :> other by v;`) stays a `Subsetting`, and the declaration form (`satisfy requirement s :> r by v;`) is unchanged. In the RDF export the satisfied requirement is the collapsed `sysml:references` of the usage where it was `sysml:subsets`, so `satisfy r :> other` and `verify r :> other` convert back with the two clauses told apart; a graph written by an earlier version has to be converted from its source again. Library interface records are re-recorded under format version 22.
