- **The Java client reads a few answers as the Python client does.** A protobuf `null` carrying an unsupported-value reason stays a `Value.NullValue` whose `unsupported()` names it instead of reading as the model's `null`; a JSON body's `-0` keeps its sign; near-name suggestions rank as `difflib` does; a `Convert`/`ApplyEdits` refusal for a model the service no longer caches is a `ModelNotFoundException`; and a failed conversion is a `ConversionException`, still a `ModelException`.
