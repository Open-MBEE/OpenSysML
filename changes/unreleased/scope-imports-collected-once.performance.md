- Looking a name up through a large package no longer rescans the package's members for its imports on every lookup: since cycles of public imports were made polynomial, each read first checked whether the imports it reaches are plain, which listed the imports of every namespace on the way by walking all of its members, so a first instantiation of a thousand parts of a package with several thousand members took about 1.6 s instead of 1.3 s. A scope now collects the imports its declaration states once, and the same instantiation takes about 1.2 s.
