- A coordinate frame the standard library declares with its axes in its own body (`ISQSpaceTime::universalCartesianSpatial3dCoordinateFrame`, `:>> mRefs default (SI::m, SI::m, SI::m)`) is now read as the frame value it describes, as a model's own `spatialCF` is: `universalCartesianSpatial3dCoordinateFrame` evaluates to `universalCartesianSpatial3dCoordinateFrame [m, m, m]` where it was `<undetermined>`, `(1.0, 2.0, 3.0) [universalCartesianSpatial3dCoordinateFrame]` is a position vector where it was refused as not a quantity expression, and `coordinateFrame` on a `SpatialItems::SpatialItem` answers its library default where the read failed with `no value for feature universalCartesianSpatial3dCoordinateFrame`. A frame-typed usage with no body of its own, and the library's frame types themselves, are value-held as before.
