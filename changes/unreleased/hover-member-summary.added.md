- `sysml-lsp` hovers summarize members: a hover on a definition or usage, or on a reference to one, lists its named members under the signature and documentation — visibility when not public, direction, kind, name, type and multiplicity (declared, or taken from a redefined or subsetted feature), as each declaration would open — in model files and notebook cells, as Markdown or plain text. The `hoverMemberLimit` setting (default 10; `0` leaves the summary out) caps the list and a closing line counts what it left out; `hoverInheritedMembers` adds the members the element inherits, grouped under the qualified name of the type each comes from, a redefined or private one not among them. The VS Code extension exposes them as `opensysml.hover.memberLimit` and `opensysml.hover.inheritedMembers`, applied without a restart. A hover on a port definition's own name now shows the port definition rather than the conjugated one it implies.
