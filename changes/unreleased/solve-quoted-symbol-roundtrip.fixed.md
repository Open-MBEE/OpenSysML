- `%configure` and `%solve` read a variant or enumeration literal back whole when the solver writes its qualified name as a `|quoted|` symbol — a package or feature name with a space, a hyphen or a quoted name, as in every OMG variability teaching model — instead of failing with `<first word> is not a value of <variation>`; a reply the driver keeps as the solver's own text now writes back exactly as the solver wrote it.
