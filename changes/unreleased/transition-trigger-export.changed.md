- **A transition's trigger is exported as metamodel structure.** The RDF and API-JSON export writes `accept`, `accept … via`, `after`, `at` and `when` transition triggers as the transition's `triggerAction`: an `AcceptActionUsage` under a `TransitionFeatureMembership` of kind `trigger`, with a typed `payloadParameter`, a `receiverArgument` for `via` and a `TriggerInvocationExpression` for time and change events, as the pilot implementation serializes it, instead of `sysx:trigger` source text. The structure alone reads back with source text stripped; graphs written with `sysx:trigger` still load, and the OpenSysML `when <name>` injected-signal trigger keeps the extension predicate.
