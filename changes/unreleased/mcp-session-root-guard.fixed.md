- **`sysml-mcp` session tools stay inside the workspace root on every path.** A `repl.Session` now takes a file guard (`SetFileGuard`) that every file it reads or writes must pass — the files `%load`, `%save` and `%import` name, those a directory or glob expands to, and the dependencies found beside them, which the dependency search now asks about before reading a candidate (files really under a library root are exempt) — and `sysml-mcp` installs the workspace-root check on each session it opens. So a `%load`, `%save` or `%import` sent through `repl_command`, or a directory load that walks to a symlink pointing out of the workspace, is refused like a typed `session_load`/`session_save` naming the file.
