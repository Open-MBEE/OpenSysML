- **A direction prefixes every usage kind a behavior body admits.** `out concern c : C;`, `out requirement r : R;`, `out use case u : U;`, `out verification v[*] : V;` and the other usage kinds the grammar reaches through `OccurrenceUsagePrefix` (SysML.xtext `RefPrefix`) were read as parameters named by the kind keyword and rejected with `"concern" is a reserved keyword` and `expected '{' or ';' after parameter`; they now parse as the directed usage they declare and lower as parameters of the owning action or calculation, as a directed `item` or `part` does. A directed `analysis` or `verification` usage is that parameter only: it is no longer also lowered as a case step the action performs.
