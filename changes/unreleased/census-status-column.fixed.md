- **The compliance census reads a row's status from its `Status` column.** `scripts/mkdocs_census.py` and `tools/census/doccounts` counted a table row only when the whole row carried exactly one status marker, so a rule row whose notes mentioned another status was silently left out of the published census, and a marker mentioned before the status cell could be attributed in its place. Both counters now take the status from the table's `Status` column, split cells as the site's renderer does (a pipe inside a code span or escaped does not split), and refuse — naming the line — a row whose status cell states no status or two, a row a blank line separates from its table, and a status marker in a table without a `Status` column. Ten rows of `docs/project/spec-compliance.md` that the census had dropped are counted again, and the rows that named two statuses in one cell or wrapped over several lines now state one.
