- **A step budget of the largest 64-bit integer still binds.** With `OPENSYSML_MAX_STEPS=9223372036854775807`, the step counter could overflow once the budget was spent, in the interpreter and in a program built by `sysml -compile`; in C that overflow is undefined behaviour. Each charge is now checked against the steps left before it is spent, so the run fails with `evaluation step limit exceeded` and the counter saturates instead of wrapping.
