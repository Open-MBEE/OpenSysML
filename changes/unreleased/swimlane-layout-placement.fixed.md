- **A swimlane of an action flow can be placed.** Dragging a swimlane in the VS Code diagram panel was refused with `<view> does not expose <part>, so a Layout in its body would place nothing`, because the view exposes the action and not the part performing it. A `Layout` about the performer in the view now places the lane drawn for it, with the nodes it holds inside, in the panel and in every rendering. The panel also says why a node does not move when it is dragged: `start` and `done`, which a behavior inherits from the standard library, and a performer listed in a `performed by` compartment, which no longer offers a drag that was refused.
