- **A swimlane of an action flow can be placed.** Dragging a swimlane in the VS Code diagram panel was refused with `<view> does not expose <part>, so a Layout in its body would place nothing`, because the view exposes the action and not the part performing it. A `Layout` about the performer in the view now places the lane drawn for it, with the nodes it holds inside, in the panel and in every rendering. The panel also says why a node does not move when it is dragged: `start` and `done`, which a behavior inherits from the standard library, and a performer listed in a `performed by` compartment, which no longer offers a drag that was refused. Of a performer's lanes in one flow and the flows nested in it, the panel offers a drag only for the outermost, the one the `Layout` places, and says so on the others. An edited draw.io file imports a placed lane the same way: moving it writes the `Layout` about its performer, and resizing a flow no `Layout` places keeps the lane and the nodes placed in it where the file shows them.
