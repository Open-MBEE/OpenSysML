- **OpenSysML MDK runs inside MDK's DocGen documents.** The distribution now drops a bridge jar into MDK's `plugins/org.openmbee.mdk/extensions/` directory with one «JavaExtension» query per operation (Instantiate, Execute action, Execute state, Verify, Evaluate calc, Run analysis); a viewpoint method that applies the matching stereotype gets, per target element, a summary line, an outcome table, a diagnostics table and the state schedule rendered as DocBook. *OpenSysML ▸ Add MDK DocGen extension stereotypes* on the model root creates and applies the profile holding the stereotypes a project needs. Targets may be UML or SysML v2 elements. The bridge finds the plugin through Cameo's plugin registry and exchanges only JDK types with it, so the plugin keeps its own classloader and nothing loads when MDK is absent.
