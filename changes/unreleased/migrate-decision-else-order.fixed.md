- **SysML v1 migration writes a decision's `else` branch right after the `decide` node.** It was written after the decision's named guarded successions, where the SysML v2 grammar admits no `else <target>;` (a target succession sequences from the member written right before it); the pinned pilot implementation rejected it with `no viable alternative at input 'else'` and lost the rest of the file.
- **`then <target>;`, `if <guard> then <target>;` and `else <target>;` after a member that is not an action node are reported as OpenSysML notation** (`nonstandard-notation`, an error under `-strict`): after a `succession`, a comment, a two-ended `first a then b;` or a structural usage the grammar has no production for them and their source is unstated.
