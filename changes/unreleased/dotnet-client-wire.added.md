- The .NET client's protocol layer: C# message classes and a gRPC client stub generated from `api/proto/sysml.proto` into `OpenMBEE.OpenSysML.Wire` by `make proto-csharp` and committed, an internal method registry read from the schema's descriptor, and a parity inventory that classifies every RPC, request and response field, `Value` arm and `EditOperation` arm with the capability gates each request is subject to, so a schema change fails the client's tests until it is accounted for. The committed code is held to the schema: CI regenerates it with the pinned buf and fails on any difference, and a test that builds the schema with buf names the first message, field, enum value or RPC where the two part. The library still has no public API.
