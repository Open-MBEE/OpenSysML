- **Satisfying requirements allocates less than 0.9.0 did and is within 11% of its time.** Sharing derived defaults and verdicts across occurrences records what each check reads; the record copied every path of a nested shared value per read, deduplicated reads through a key string built per read, spelled a dotted path at every ancestor to ask whether a binding governs a read, and every transaction cloned the simulation clock's list of waiting executors. It now records a nested value once, compares paths in place, asks about bindings only where a type declares one starting at that feature, and the clock's list is replaced rather than edited so a transaction keeps the one it saw. On the stress constellation (`BenchmarkSatisfy`), 96 assertions run in 4.2 ms and 1.66 MiB instead of 4.8 ms and 3.1 MiB, and 1 536 assertions allocate 27 MiB instead of 125 MiB.
- **The migration writer is twice as fast.** It allocated a fresh buffer for every block and re-spelled the indent for every line; it now reuses the buffers it closes and indents from a table. `BenchmarkWriterSiblingBlocks` runs in 1.8 ms and 20 k allocations instead of 4.2 ms and 80 k, with the same output.
- **Serializing a verified instance graph over gRPC allocates 6% less.** The implicit nested-usage subsetting recomputed each collection's declared subsettings per read and made its deduplication and reachability sets before knowing they were needed; those are now memoized on the runtime model and made on first use.
- **Analyzing a resolved document is 13% faster.** The undeclared-signal lint walked the document by reflection once to gather the signals it sends and again to check its triggers; the walk is now made once per analysis and read by both.
