- **An association that only backs a value property is not a `connection def`.** MagicDraw backs each «ConstraintParameter» port, and a value property, with an anonymous association between the property and an end the association owns, typed by the property's owner. Such an association was written as a `connection def` named after the end types (`GainToReal`), approximated, one per parameter; it links nothing, since a value is not a referent, so it is now skipped as notation only with the reason "the association only backs `Block::prop`, which is written as a feature", its owned end with it. The same shape backing a `part` property is a composition and is still written as a `connection def`. A block definition diagram line from the block to the value type is drawn by the tree rendering as the attribute's edge, and the line's `DiagramLayout::Route` is written about the attribute.
