- `ci/` holds the tools that coordinate GitHub Actions capacity across concurrent pull requests: `ci/watcher.py` caps concurrent pull-request runs and admits none while a merge-queue build waits for runners, `ci/starve_sweep.py` frees runners for a starved merge queue, `ci/infra_rerun.py` re-runs runs that failed on infrastructure, and `ci/drycheck.sh` dry-merges ready pull requests. Every repository, path and pull-request list is configuration or a control file (`ci/config.example.json`, `ci/tiers.example.json`); `ci/README.md` documents them, and `ci/tests/test_ci_tools.py` tests the tools offline against a stub `gh`.
