- **`%load` reads Jupyter notebooks.** A path ending in `.ipynb` — named at the prompt, on the `sysml` command line, or found under a directory or pattern beside `.sysml` and `.kerml` files — loads the notebook's code cells in order, each a source of its own, so a diagnostic names `<notebook>.ipynb cell 3` and its line in the cell, and re-loading the notebook redeclares it. A cell is loaded for what it declares: its `%` command lines and its expressions are skipped and the report says how many, so a loaded notebook runs no one's `%sweep` or `%save`. `--cells 1,3-5` or `--cells tag:<tag>` picks cells; a cell tagged `skip-load` is never loaded; a notebook written for another kernel language, or in a format other than nbformat 4, is refused with the reason.
