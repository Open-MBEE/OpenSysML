- Converting Turtle or API JSON to notation no longer panics (`slice bounds out of range` in the note writer) when an element rebuilt from the graph, such as one whose `sysx:sourceText` is gone, has two or more `sysx:Note` nodes after one code token and the rebuilt line continues past that token — two `//` notes between `=` and a value, or in an otherwise empty body. The notes after one token are now written together, in order, and the rest of the line moves below them once, so the notation comes back as written. Notes ahead of an element's first token keep the order the graph states as well: an inline note followed by one on its own line is no longer written after it.
