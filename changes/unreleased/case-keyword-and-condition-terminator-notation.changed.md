- `analysis case def`, `verification case def`, `analysis case <name>` and `verification case <name>` are reported as `nonstandard-notation` (an error under `-strict`): the SysML v2 productions spell `analysis def`, `analysis`, `verification def` and `verification` alone. The declaration is read as the analysis or verification case it names — an `analysis case def` no longer types its usages as a plain case definition — and a quick fix drops `case`.
- A `;` after the closing bare condition of a constraint, predicate or invariant body is reported as `nonstandard-notation`: that condition is the body's result expression, which no production terminates. The terminator stays in the syntax tree and a quick fix deletes it.
