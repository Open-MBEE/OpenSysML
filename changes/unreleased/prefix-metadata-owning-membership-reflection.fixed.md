- Reflection now owns a `#M` prefix the way the grammar does (`PrefixMetadataMember : OwningMembership`): the prefix's metadata usage is listed first in the annotated element's `ownedMembership`, `ownedMember`, `member`, `ownedElement` and `ownedRelationship`, its `owningMembership` is that membership, and its `annotatedElement` is its owning namespace. `ownedAnnotation` no longer reports an Annotation for it. A dependency, which is no namespace, keeps owning its prefix through an `Annotation` (`PrefixMetadataAnnotation`). Queries that read `ownedAnnotation` to find prefix metadata should read `ownedMember` instead. A metadata usage, prefix or body, in SysML and KerML alike, is owned through an `OwningMembership` and so is no longer listed in its owner's `ownedFeature`, `feature` or `ownedFeatureMembership`, and has no `owningType`. The `nested*`/`owned*` usage collections follow the same derivations: `nestedMetadata` and `ownedMetadata` select from `ownedMember` and so list the prefix, and every other one selects from `ownedFeature`, so it lists neither a metadata usage nor a variant.
