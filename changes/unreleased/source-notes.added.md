- The `//` and `//* */` notes of a document, and the `/* */` comments written where the grammar admits no `Comment` element (inside a declaration head or an expression, after a result expression), are now kept in the RDF graph and the API JSON as `sysx:Note` nodes of the element whose lines hold them — `sysx:noteText` as written, `sysx:noteToken` placing it among the element's tokens (or `sysx:noteTrailing` after the last), `sysx:noteOwnLine`, and `sysx:noteTail` for one closing a body — each addressed by its position (`expr:P__x_pnote0`) so a provenance record can cite it. Before, such a note survived a conversion only inside `sysx:sourceText`, and was lost when the element was rebuilt from the graph or the text stripped; now the conversion back to notation puts each note back after the token it followed, and a note edited in the graph is written in place of the text's. A sync diff against a SysML v2 API repository leaves the notes out of the comparison, as it leaves every `sysx:` property, and reports them as not carried. See `docs/reference/rdf-mapping.md` § Notes.
