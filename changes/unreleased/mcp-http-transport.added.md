- **`sysml-mcp -http ADDR`** serves the Model Context Protocol over the Streamable HTTP transport at `/mcp` of that address, as one long-lived server for remote agents or several agents over one workspace: every client shares the workspace, the runtime cache and the REPL sessions, so `session_*` names are shared. A port alone binds loopback; any other address is served with a warning that the server authenticates no one. `-tls-cert`/`-tls-key` serve `https`; a request's `Origin` header is answered when absent, loopback or listed in `-allow-origin` (only a listed origin is granted the CORS headers a browser needs) and refused with 403 otherwise; SIGINT and SIGTERM close the sessions and drain the connections. `-print-config HOST -http ADDR` writes every host's block in its URL form (OpenCode `"type": "remote"`, Claude Code/VS Code/Devin `"type": "http"`, Cursor `url`, Codex `url`, Gemini `httpUrl`).
