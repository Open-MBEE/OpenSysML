- A `DiagramLayout::Layout` binding only `collapsed` or `show…` switches no longer needs `x` and `y`: `metadata Layout about vehicle::engine { collapsed = true; }` folds the element in every form and leaves its place to the form, so a fold-only annotation no longer turns the drawing into a positioned one that leaves unplaced nodes undrawn. The LSP rendering reports such a node `collapsed` with no `x`, `y`; the gRPC and engine renderings report its geometry `collapsed` with the new `unplaced` flag set (`RenderGeometry.unplaced`), its coordinates meaning nothing. `opensysml/applyModelEdit`'s `setLayout` writes such a `Layout` for a `layout` given `collapsed` and no `x`, `y`. A `Layout` binding a size, one coordinate, or nothing without `x` and `y` is still the `diagram-layout-value` error.
