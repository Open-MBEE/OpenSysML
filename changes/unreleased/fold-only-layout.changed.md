- A `DiagramLayout::Layout` binding only `collapsed` or `show…` switches no longer needs `x` and `y`: `metadata Layout about vehicle::engine { collapsed = true; }` folds the element in every form and leaves its place to the form, so a fold-only annotation no longer turns the drawing into a positioned one that leaves unplaced nodes undrawn. The LSP rendering reports such a node `collapsed` with no `x`, `y`; the gRPC and engine renderings report no geometry for it. A `Layout` binding a size, or nothing, without `x` and `y` is still the `diagram-layout-value` error.
