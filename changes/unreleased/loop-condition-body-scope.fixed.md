- **A loop's `while` and `until` conditions no longer read what the loop's body declares.** The loop owns its conditions beside its body (SysML 8.3.17.19 `WhileLoopActionUsage`), so by KerML 8.2.3.5.4 a name in a condition is looked up in the loop and the namespaces around it, never inside the body: `loop { attribute x : Boolean; } until x;`, `while x { attribute x : Boolean; }` and `loop { action charging { … } } until charging.done;` now report `x` and `charging` unresolved, where they resolved to the body's declarations, and a body's `attribute flag` no longer hides an enclosing `flag` the condition names. A body written as an action is still reached by its name (`loop action body1 { attribute x : Boolean; } until body1.x;`). A compiled calc (`-compile`, both targets) reads the feature the condition resolves to, where its `until` read a body's declaration of the same name.
