- **Convert only some documents of a model over the service.** `ConvertRequest.documents` names documents of a `model_hash` parsed from several, and only the elements they declare are written; a reference into another document of the model links the `@id` that document's own conversion writes, and an element both declare is still refused. A client that edits one document of a large model, such as a project over the libraries it imports, converts that document again rather than the whole model, and replaces its elements by `@id`. Reported as the `convert_documents` capability.
