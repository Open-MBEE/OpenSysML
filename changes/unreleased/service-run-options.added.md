- The service and `sysml-mcp` take the run options the CLI already had: `DiagnosticsRequest` selects lints (`disable_lint`, `enable_lint`, as `-disable-lint`/`-enable-lint`), `ExecuteActionRequest` and `ExecuteStateRequest` carry `advance`, `seed`, `draws` and `clock_step` (as `-advance`, `-seed`, `-draws`, `-clock-step`), `RunAnalysisRequest.tool_dry_run` previews the first external tool call as a typed `ToolDryRun` instead of running it (as `-tool-dry-run`), and `ListEnginesRequest.probe` starts each external engine and checks its handshake (as `-probe`); a malformed option is an `invalid_argument`. The Python, Node, Java and Rust clients expose the same options, the gRPC conformance cases cover them, and the catalog's unserved list shrinks by those flags and `-samples`, which `RunSweepRequest` already carried.
