- The reference validators' pilot kernel jar and its standard library are pinned by SHA-256 in `scripts/pilot-pin.sh`. They come from a release asset that only a tag and a version string selected, so a replaced asset, or an altered copy restored from a CI cache, would have changed the reference verdicts the baselines record. `scripts/download-pilot-validator.sh` now refuses a download that differs from the pin before building with it, and rebuilds an installed copy that no longer matches.
