- **The MATLAB client's `opensysml.symbol(model, id)` is now `opensysml.getSymbol(model, id)`.** Its file `symbol.m` differed only in case from `Symbol.m`, the class file, so a checkout on a case-insensitive file system (the macOS and Windows defaults) kept one of the two, broke `Model`, and left `git status` permanently dirty. `model.symbol(id)` is unchanged. A hygiene test now fails when any two tracked paths differ only in case.
