- **The `OpenSysML Libraries/StateMachines.sysml` library re-expresses the state-machine notation extensions through standard metadata.** A model importing `StateMachines::*` spells a choice, junction, shallow-history or deep-history pseudostate as an annotated state usage (`#choice state pick;`, `#junction state j;`, `#shallowHistory state h;`, `#deepHistory state h;`) and a deferred event as an annotated reference usage (`#deferred ref : Ping;`, optionally named `#deferred ref p : Ping;`), so the file is grammar-conforming SysML v2. Both forms lower to the same graph as the `choice`/`junction`/`history`/`defer` keywords, which remain accepted for now.
