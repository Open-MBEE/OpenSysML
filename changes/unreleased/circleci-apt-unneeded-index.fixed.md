- The CircleCI jobs install their apt packages (Z3, poppler-utils, mandoc, Octave, make, python3-venv, and python3 and gnupg in the release jobs) through `scripts/ci-apt-install.sh` instead of a bare `apt-get update && apt-get install`, so a mirror that stalls or answers 503 is retried within a bound. The script no longer fails when the only indexes `apt-get update` could not fetch belong to a repository the requested packages are not installed from, such as the git-core PPA the CircleCI images list: it names that repository and installs from the mirrors that answered. A failed index of a repository the packages do come from, a failure it cannot attribute, and a failed fetch still fail the step. It also runs as root on an image without `sudo`.
