- A run in which some behavior holds work no longer asks every attached behavior whether it does at each feature read and write: the behaviors a scan finds holding work are kept, like the all-idle answer, until a message is posted, the clock moves, an executor runs or a behavior is attached or dropped, and until a write where the scan read the objects' data. Outcomes do not change; under `-schedule explore`, a model of about ten communicating state machines with messages in flight runs about a third faster.
