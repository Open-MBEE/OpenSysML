- **A cast and an extent type their result by the type they name.** `x as T`, `x meta T`, `(as T)` and `all T` were given the shape of a classification test: the type typed an extra `in` parameter (`all T` also took it as an argument) and the result kept the library's `Anything` or `Object`. The type now types the expression's result and is no parameter or argument, in the reflective model and in the RDF and API JSON exports alike; `istype`, `hastype` and `@` keep their type parameter.
