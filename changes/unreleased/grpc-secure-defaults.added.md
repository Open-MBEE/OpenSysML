- `sysml-grpc` flags `-host`, `-token-file`, `-token`, `-allow-unauthenticated`, `-allow-insecure-token-transport` and the `OPENSYSML_GRPC_TOKEN` variable, with the same meanings the first four have on `sysml-mcp`; the bearer-token and loopback rules the two commands share live in one package, `internal/frontend/guard`.
- The Python (`token=`, `AuthenticationError`), Node and browser (`token`), Java (`ConnectionOptions.token`), Rust (`Connection::external_with_token`), Go (`opensysml.WithToken`), Julia (`external(…; token)`) and MATLAB (`external(…, 'token', …)`) clients send a bearer token on every call, defaulting to `$OPENSYSML_GRPC_TOKEN`; each is tested against a token-protected service.
