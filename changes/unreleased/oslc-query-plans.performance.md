- OSLC Query text and the API Query no longer walk every metaclass of the library's metamodel, resolving each one's inherited features and classifying their types, before a query is translated and again before it is executed; the ~15 ms that cost every `sysml -query`, REPL `%query`, gRPC `oslc_query` and MCP `query` call regardless of the model is gone. A query on a small model answers in well under a millisecond again, and `oslc.select=sysml:self`, which named a feature of the library's own `Metaobjects::Metaobject` rather than a property of the metamodel, is rejected as unknown as it was before.
