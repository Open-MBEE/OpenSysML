- Every GitHub Actions job that sets up Go now uses `actions/setup-go` v6 with `go-version-file: go.mod`, which installs the release `go.mod`'s `toolchain` line names and sets `GOTOOLCHAIN=local`. v5 installed the `go` line's release (1.26.0), whose first `go env` downloaded `go1.27.4` into the module cache; the cache restore then failed on those files ("Cannot open: File exists"), so no job restored its Go module and build cache, each pull request saved its own entry of up to 880 MB, the downloaded toolchain among them, and a merge-queue Documentation site job ran past its 15-minute limit building cold. `tests/hygiene` holds the policy in place.
