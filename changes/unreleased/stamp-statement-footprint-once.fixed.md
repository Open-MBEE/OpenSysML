- **The execution runtime stamps a statement's footprint for a performance once, not on every pass.** An assignment in an action body records what it writes through the statement's footprint with the performance's own places stamped as its; that stamping cloned the statement's read and write places on every execution, two allocations per executed statement, so a `for` loop of a thousand passes allocated two thousand more objects than before. The stamped footprint is now computed once per statement and performed node, and a footprint with nothing to stamp is used as it is.
