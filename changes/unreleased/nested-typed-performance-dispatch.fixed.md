- A nested action usage typed by state-space dynamics or by a tool-performed action, binding the action's features on the usage (`action fall : FreeFall { :>> stateSpace = …; :>> timeStep = …; }` in an analysis or action body), is now performed as the same usage is standalone — stepped by the integrator, or run by the tool — instead of its merged body running as an empty flow that left the bound initial values in place and reported them as the result; a shape the run cannot perform (no initial state, an integrator the runtime does not provide, a tool nobody registers) is now refused where it was silently completed.
