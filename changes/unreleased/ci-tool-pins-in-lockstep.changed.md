- CircleCI builds in `cimg/go:1.27.4`, the toolchain `go.mod` pins, instead of the `1.27` tag that follows each patch release, so a release is compiled by the Go the container image and local builds use. Hygiene tests now fail when CircleCI's image and `go.mod`'s toolchain differ, when a CI file downloads a buf other than the Makefile's `BUF_VERSION`, or when one installs a grpcio-tools other than the version that generated the committed Python stubs.
