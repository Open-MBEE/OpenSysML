- **An action's pins are drawn on its border, and object flows run pin to pin.** A migrated action's `in`/`out` parameters were each written as a detached `shape=note` node at the pin's bounds, too small for its name, and the flow ended beside the action in mid-air. A directed parameter, a bound result and a pin a flow names are the node's ports now — in the rendering as `Node.Ports` and `Edge.FromPort`/`ToPort`, and in DOT as 12 px squares set on the action's border where the route meets it with the pin's name in small type beside them — and the flow edge is attached to the pins, so its `out to in` text is no longer needed there. An unplaced action draws its pins as cells of its label instead. The `opensysml/render` reply and the text form carry the ports and the flow's ends.
- **An action whose name the model did not give heads with what it does.** A migrated UML value specification action (`action value3 { out result : Boolean = true; }`) read **action** over the detail `own flow`; a call read the same over `own flow`. Such a node is headed now by the literal its result is bound to (`true`, `"SH-0"`), an accept's trigger, a send's message, the one assignment its body makes, or `: Type` for what it calls, and `own flow` is shown only when the nested flow draws nodes of its own.
- **Forks, joins, decisions, merges, choices, junctions and history pseudo-states are drawn as Cameo draws them.** A fork or join was a filled box at a fixed size with its synthesized name inside it, over the neighbouring action; it takes its `DiagramLayout::Layout` bounds now, standing or lying as the box is longer, with no text inside and a name the model gave beside it. Every pseudo-state the lowered state graph knows is drawn as its symbol at its stated bounds — the initial dot and its outgoing transition, a junction's dot, a choice's diamond, the final bull's-eye, a terminate, and a shallow or deep history as a ring lettered `H` or `H*` — where an initial pseudo-state and a junction were dropped from a placed rendering before.
- **A routed edge is drawn to both of its stated ends.** The spline kept its `e,x,y` end alone and its curve ran to the head's tip, so Graphviz clipped the last segment and the head landed short; a tail arrow lost its end altogether. The spline now carries `s,x,y` and `e,x,y` as its arrows call for, its curve stopping an arrow's length short of each, and a node's routed box never grows past its stated one, so the drawn ends are the stated ends (a test runs Graphviz when `OPENSYSML_DOT` names it and asserts every drawn endpoint within 3 px of its route's).
- **A transition is labelled once, in Cameo's form, beside its route.** Every routed transition carried two labels — a fitted `label` at the midpoint and the full text as an `xlabel` beside it — and the Cameo style kept the `accept` keyword. One `label` is written now, `trigger [guard] / effect` with `accept` and quotes off under `-render-style cameo`, and it is placed beside the segment of the route where it covers the fewest state boxes and notes.
- **A state's compartment names its behaviours in every style.** A state's line read `entry`, `do`, `defers` when the behaviour was an anonymous usage typed by an action; it reads `entry / prime`, `do / Initialize`, `exit / Settle` now — the behaviour's name, else its type's, else what its body does — and `«state»` is not written in the Cameo style, which shows a keyword only for a stereotyped state.
- **A migrated diagram's comment notes reach the view, anchored to the states they annotate.** The migration took a `Note` symbol naming an element that is no Comment — Cameo's note showing a state's documentation — for the element's own symbol, so the note was never written and its anchor was dropped, while every name and stereotype label nested in a symbol was counted as a note, so the report's note count was inflated. A `Note` symbol whatever it names, a comment's symbol and a free text box are the notes now, a label nested in an element's symbol is not, a note anchored to several elements is one `Note about` them all — drawn as one box with an anchor to each, while notes stated apart stay apart even when their text and box coincide — and a region's initial transition is written as a named `transition … first start then s;` when a diagram routes it, so the route is drawn from the initial dot.
- **A route of a control flow the migration split at a made-up join is drawn where Cameo drew it.** The route was pinned to every member the flow was written as, including the succession into the join no symbol stands for; it is pinned now to the members whose both ends the diagram draws. The migration marks such a member `MigrationMetadata::StandIn` besides its synthesized name, and in a positioned rendering a fork, join or merge so marked, which no diagram positions, is elided and the edges through it joined pairwise along their routes, the notice counting the nodes elided and the routeless pairs left undrawn; a control node the source had but left unnamed keeps its symbol.
- **A layout stated for a body's `start` or `done` positions that body's alone.** Every action and state body inherits the one library `start`, so `metadata Layout about Acquire::start` positioned the `start` of every body a view drew, the first stated winning. A `LayoutSite` now records the namespace an `about` clause named the member through (`Via`), and a synthetic member's layout is looked up under the body it is drawn in (`MemberLayoutOf`).
