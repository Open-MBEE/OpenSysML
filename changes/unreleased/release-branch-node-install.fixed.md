- A release build no longer fails at the landing-page diagram and the Node client jobs between the release's version bump and its tag. The bump pins the client's five platform packages at a version the tag has not published yet, so the lockfile cannot lock them, and npm 11.6 and later make `npm ci` refuse such a lockfile. The Makefile and every CI job now install `client/node` from its lockfile with `npm install --ignore-scripts`, which skips the optional packages it cannot resolve and installs everything else exactly as locked; each job asserts the lockfile is unchanged by the install, and a hygiene test keeps every consumer of the client and of the `sysml-mcp` package off `npm ci`.
