- A plain `lib/` directory beside a project's `.project.json` is now a well-known library directory, read like `.sysand/lib`: OpenSysML reads what any package manager that follows KerML 10.3 project interchange installs (sysand today) under `lib/` or `.sysand/lib` beside `.project.json`; it does not fetch. A version written after `@` in a usage's resource IRI (`pkg:registry/acme/gears@1.0.0`) now selects that installed version when the usage carries no `versionConstraint`; before, it was discarded and the latest taken.
