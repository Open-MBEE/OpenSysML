- **Directed parameters added by `add_member`/`add_parameter` no longer write the redundant `ref` keyword.** A direction already marks the usage's parameter nature, so `add_parameter("C", "in", "x", type="T")` now writes `in x : T;` (matching the canonical writer) instead of `in ref x : T;`. Undirected (`ref x : T;`) and abstract (`in abstract ref x : T;`) spellings are unchanged.
