- **The Cameo plugin is now OpenSysML MDK.** It is positioned as the successor to OpenMBEE's Model Development Kit for SysML v2 work: the source moved from `editors/cameo/` to `editors/mdk/`, the plugin id is `org.openmbee.opensysml.mdk`, the Java packages are `org.openmbee.opensysml.mdk.*`, and the Resource Manager archive is `OpenSysML_MDK_<version>.zip`. The context-menu operations, results window and annotations are unchanged. The capability-by-capability comparison with MDK, and the order the gaps are being closed in, is `docs/project/mdk-parity.md`.
