- **Pull-request CI runs in two tiers.** A draft pull request runs the quick tier: the binaries, the Go suite without `-race` in three shards (`make test-quick`), the download-free static checks, the WebAssembly, Xpect and conformance gates, and only the clients and docs whose own paths changed (`CI_TIER=quick scripts/ci-changed-areas.sh`). Every push to a non-draft pull request, marking one ready for review, or the label `ci:full` runs the full tier, the whole suite as before. Both tiers report through the one `Build and test` check.
