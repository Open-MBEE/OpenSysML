- **A model piped into `sysml` no longer panics on a TAB.** The prompt read a pipe or redirected file through its line editor, which took a literal TAB as the completion key and crashed redrawing candidates for a screen it did not have (`panic: bytes: negative Repeat count`). Input that is not a terminal is now read plainly, byte for byte, so tab-indented models, a TAB inside a string literal and a TAB in a comment reach the parser intact and the session exits 0; at a terminal, TAB still completes.
