- The `api-json` element form now derives `Namespace::importedMembership`, and with it `membership` and `member` of an importing namespace, from the graph alone (KerML 1.1 §8.3.2.4): namespace, membership, recursive, `all` and filtered imports, import visibility, import cycles, library namespaces the graph only references, and the hiding of imported memberships that collide with owned, inherited or other imported ones. A type also inherits the public and protected imports of its general types (§8.3.3.1.10). `importedMembership` is one of the lists `-inherited-members` writes, beside `membership` and `member`. These properties were previously withheld for every namespace that owns an import.
