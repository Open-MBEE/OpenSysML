- **`sysml -compile` compiles records.** A compiled C or Go calc now constructs `attribute def` values (positionally, by label, with defaults), reads their scalar, sequence and nested features, compares them by identity as the interpreter does, and invokes, passes, stores and compares calcs read off a record (`s.scale`). A record as the program's result or command-line parameter is refused with a typed error naming it, since the interpreter prints a record by a session instance number; a feature read off one (`p.x`) is returned normally. The C target refuses a record holding a String or a collection.
