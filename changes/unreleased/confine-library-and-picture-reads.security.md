- **A library directory and a view's pictures are read only from inside their directory.** A library file under `OPENSYSML_LIBRARY_PATH` that is a symbolic link out of that directory is no longer read. A `@Picture` whose file is outside the directory of the model stating it — by an absolute path, a `..` path or a symbolic link — is no longer drawn in the DOT and Mermaid forms or read into a PDF: the forms state it in a `not represented` notice, and `-render-document -doc-form pdf` writes that notice to stderr. Links and absolute paths that stay inside the directory work as before, wherever the command is run from.
