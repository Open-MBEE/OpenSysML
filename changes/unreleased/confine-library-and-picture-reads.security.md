- **A library directory and a PDF diagram's pictures are read only from inside their directory.** A library file under `OPENSYSML_LIBRARY_PATH` that is a symbolic link out of that directory is no longer read, and a picture a Graphviz diagram names by an absolute path, a `..` path or a symbolic link that leads outside the working directory is no longer read into the PDF: the picture is dropped with a `not represented` comment in the drawn SVG. Links and absolute paths that stay inside the directory work as before.
