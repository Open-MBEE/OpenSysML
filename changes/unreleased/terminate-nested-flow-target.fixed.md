- **A `terminate` inside a loop body names its own loop performance's node only.** `terminate slow;` in a loop body reached by several tokens ended the paused `slow` performances of the other loop performances too, and ran on as if it had ended its own. Each step of a statement node now owns what its body performs, so the terminate ends that body's `slow`; one that has already ended is reported as `performance already ended`, since `TerminateAction` ends an occurrence during its own performance.
