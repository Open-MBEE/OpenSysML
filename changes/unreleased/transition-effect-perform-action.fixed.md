- A transition's effect now has the metaclass its declaration gives it (SysML v2.1 §8.2.2.18.3 `EffectBehaviorUsage`): `do action e` is a `PerformActionUsage` and `do assign x := 1` an `AssignmentActionUsage`, where both were a plain `ActionUsage`, on the symbol kind, the query `@type` and the reflective metaclass, so `effectAction istype SysML::PerformActionUsage` holds. `TransitionUsage::source` and `target` are now derived (§8.3.18.9 `deriveTransitionUsageSource`, `deriveTransitionUsageTarget`) instead of reporting `reflective feature is not derived`, a chained `first a.b` giving the chain's last feature. The RDF and API JSON export of such an effect accordingly writes `isVariable` and `mayTimeVary` true, as a referential `PerformActionUsage` has them.
