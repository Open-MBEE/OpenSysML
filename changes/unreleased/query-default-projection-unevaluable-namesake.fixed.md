- **A query that selects nothing no longer fails on a feature it did not ask for.** The default projection reads `text`, `body`, `locale` and `language` as a feature of the model when an element declares one of that name, and a value that could not be evaluated (`attribute locale = 1 / 0;`) failed the whole listing. It now leaves that cell empty and reports the row's other properties; selecting the property by name still reports the feature that cannot be evaluated.
