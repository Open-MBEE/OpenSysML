- Every release tag lists `sysml-mcp` in the official MCP Registry as `org.opensysml/sysml-mcp`: `packaging/mcp/server.json` describes the npm package `@openmbee/sysml-mcp` (stdio transport, the `-root` argument with its default), the `MCP Registry` workflow waits for the npm version, installs the pinned `mcp-publisher`, logs in through the `opensysml.org` DNS record and publishes, `scripts/mcp-registry-txt-record.sh` prints that record from the maintainer's key, and `make mcp-registry-check` validates the listing without credentials.
