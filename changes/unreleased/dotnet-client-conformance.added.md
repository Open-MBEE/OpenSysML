- The .NET client runs the language-independent conformance suite through its public API: `make conformance-dotnet` runs every scenario over gRPC, Connect with protobuf and Connect with JSON, then against a service withholding `strict_conformance` and `oslc_query`, and writes the reference runner's JSON and JUnit reports. Each covered RPC's scenario is made as the typed call its request states and the answer is rendered from the public result types; nothing is sent raw. Skips are accounted exactly against `client/dotnet/test/testdata/expected-skips.json`, which lists the RPCs the client does not cover yet and the one request its API cannot express, so an unlisted skip, a listed skip that ran, or a withheld capability whose fallback did not run fails the run. `-mutate perturb-reals`, `truncate-lists` and `rewrite-strings` corrupt every answer and fail the run on every protocol, and `make conformance-dotnet-check` compares the run with the reference runner's, scenario by scenario, down to each normalized response.
