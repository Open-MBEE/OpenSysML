- The Java dependency audit no longer fails a pull request or a merge group when Maven Central refuses the CycloneDX plugin, which no build resolves and the Maven cache therefore lacks. `make audit-java` writes each SBOM through `scripts/maven-sbom.sh`, which retries an unresolved artifact up to four times and asks Google's mirror of Maven Central (`scripts/maven-central-mirror-settings.xml`) on every second attempt; a Maven failure of any other kind still fails at once, and a finding still fails the audit.
