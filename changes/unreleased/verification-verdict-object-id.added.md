- gRPC `VerificationVerdict` carries `instance_id` and `instance_type_id`, the object the case ran on as its owner, so the verdicts a case a part definition owns answers once per object are told apart by a client. The Go, Python, TypeScript, Rust, Java, Julia and MATLAB clients expose both (`VerificationVerdict.instance_id`/`instanceId`), and the Python and Rust explanations name the object as a requirement verdict's does.
