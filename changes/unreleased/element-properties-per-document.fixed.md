- **`GetElementProperties` reads a model one document at a time.** A document the parser could not read whole, or one declaring a top-level name an earlier document already declares, is left out of the model instead of refusing every element of every document: a request for an element of such a document answers that document's error, any other element is answered, and the response lists the excluded documents and why (`excluded_documents`; `ElementProperties.ExcludedDocuments` in the Go client, `excluded_documents` in the Python client, `excludedDocuments` in the TypeScript client, the generated `ExcludedDocument` message in the Java client). A validation error alone still excludes nothing. Python's `ConversionError` is raised only when the requested element's own document is excluded, and carries the `excluded_documents`. `Convert` keeps refusing a model it cannot write whole.
