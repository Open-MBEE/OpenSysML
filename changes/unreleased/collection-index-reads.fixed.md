- `col#(i)` over an object of an `OrderedCollection` (`attribute os : OrderedSet { :>> elements : Integer = (3, 5, 7); }`) now answers the element at `i` of `col.elements`, as `CollectionFunctions::'#'` declares and the qualified call `CollectionFunctions::'#'(os, 1)` already did: `os#(1)` is `3` where it was the `os` object itself (the one-element sequence the object is under `BaseFunctions::'#'`). A position past the elements is an index-out-of-range error; an `Array` keeps its `'array#'` positions and an unordered collection, which the function does not take, is still positioned as the one value it is.
