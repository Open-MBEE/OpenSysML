- **Arithmetic over a Boolean is a type mismatch when evaluated.** `sysml -e '(1 > 0) * 5'` answered `0.0` and `true + 1` answered `1.0`, because `+`, `-`, `*`, `/` and `%` converted a Boolean operand to a number where the type check rejects the same expression in a model. They now report `operator '*' is not defined for a Boolean and an Integer`, and `**` and an infinity beside a Boolean report it in the same words.
