- A document query's `Named` now tells a name no element carries from one several elements carry, instead of refusing both as `names no single element`. A name nothing carries is still an `unknown-element` error, and it says where the path stopped resolving — the namespace that did resolve has no member of the next segment — and offers the nearest spellings (`names no element Cookbook::telescop: Cookbook has no member telescop — did you mean telescope?`); an alias that denotes no element says so. A name several elements carry is a new `ambiguous-element` error listing them by qualified name: a finding about the model rather than about the query.
