- The .NET client gains the SysML v2 metamodel as C# types, in the standalone `OpenMBEE.OpenSysML.Metamodel` assembly, which references neither the client library nor any package: one interface per metaclass extending its superclasses' interfaces, so `is IFeature` and `OfType<IPartUsage>()` select by metamodel ancestry, with a read-only PascalCased property per metamodel property; one sealed class per concrete metaclass; one enum per enumeration; and `Metaclasses`, describing every metaclass and property (JSON key, C# name, range, multiplicity, derivation, redefinitions, subsets, opposite) and the metamodel release they were generated from. Metadata collections are immutable snapshots. A property a document does not supply throws `NotSuppliedException` rather than reading as a default. `make dotnet-metamodel` regenerates the types from the metamodel table and `make dotnet-metamodel-check` fails when they are stale; generation rejects runtime and framework name collisions and incompatible property kinds and ranges.
