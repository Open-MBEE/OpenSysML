- **The SysML v1 migration renames a top-level package named like a standard library root.** A qualified name starting with `Requirements`, `Views` or another library root resolved to the library package rather than the migrated one, so references into it broke under the OMG pilot validator; the migration now writes such a package as `<name>Model`, records the source name in a `MigrationMetadata::LibraryNameAvoided` annotation, and reports the rename as approximated.
- **The checker warns about a root package named like a standard library package.** The new `library-root-name` name-resolution warning marks the portability hazard on any model, not only migrated ones.
