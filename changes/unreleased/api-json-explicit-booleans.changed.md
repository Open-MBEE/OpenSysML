- `sysml -convert api-json` writes the OMG API JSON element shape for booleans: every non-derived boolean attribute of an element's metaclass is stated explicitly (`true` or `false`) instead of only when true; the reader tells an external API-JSON document from this mapping's own by an explicit criterion rather than by the presence of `isImpliedIncluded`, and documents that omit false flags still read as before.
