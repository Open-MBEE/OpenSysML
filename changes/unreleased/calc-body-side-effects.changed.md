- A calculation body may now have side effects, as KerML 1.1 §7.4.8.1 allows a function ("like all behaviors, functions can change things") and SysML v2.1 §7.19.1 only recommends against: a `send` posts its message, and an assignment to a feature the calculation does not declare — a feature of the performing object, a chained target (`assign s.reading := v`) or a qualified one — is written under the same type, mutability and multiplicity rules as in an action body, where each was refused before. The static error `assignment-chain-in-calc` is withdrawn with them; a chained target in a calculation is held to the rules of any other (`assignment-chain-step-not-one-object` still applies).
