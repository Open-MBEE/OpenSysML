- The release's `opensysml` and `jupyter-opensysml-kernel` packages are uploaded to PyPI by a GitHub Actions workflow, `release-pypi.yml`, with trusted publishing, so every file carries a PEP 740 attestation like the nightly snapshots' do. CircleCI still builds the distributions, signs the manifest listing them and publishes them on the GitHub release; the workflow waits for that release, verifies the files against the signed manifest, runs the wheel against the release it names, and publishes them under its own identity. The CircleCI token upload jobs are gone (`PYPI_API_TOKEN` is read only by the one-off `pysysml` placeholder), and a dispatch with `dry_run` rehearses the publication against an existing release.
