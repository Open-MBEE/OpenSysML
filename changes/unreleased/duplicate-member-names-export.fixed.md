- **RDF conversion no longer refuses two members of one namespace sharing a name.** `sysml -convert ttl` and `sysml -convert json` used to fail on `part def A; part def A;` because a qualified name was the element's identity in the graph. The first member keeps the qualified name now and each later one is identified by its position among the owner's members, as an element declared unnamed already is, so both export as separate elements and `model.to_api_json()` returns them with distinct ids. The duplicate is still reported as a warning when the model is analyzed — SysML has no reopening of a declaration within a namespace, so merge the declarations (or rename) rather than rely on the position. What remains refused is a member named the positional name another member takes.
