- **A `keepLineBreaks` option restores the line-preserving formatter.** The language server reads a boolean `keepLineBreaks` setting (any of the three shapes `strictConformance` accepts, from `initialize` and `workspace/didChangeConfiguration`) and takes a `-keep-line-breaks` flag; while on, Format Document, range formatting and notebook-cell formatting fix indentation and spacing only, so a one-line body such as `enum def Color { red; green; blue; }` stays on its line. The `sysml-syntax` `Format` request takes the same `keepLineBreaks` field, `sysml -convert sysml -keep-line-breaks` writes the one-line form from the command line (refused with any other conversion), and the VS Code extension's `opensysml.format.keepLineBreaks` setting sends the server the setting at start and on every change without a restart.
