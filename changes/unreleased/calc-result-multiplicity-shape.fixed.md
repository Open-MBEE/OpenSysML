- A calculation's result parameter is held in the shape its declared multiplicity gives it, as an action parameter is: `return : Real[0..*] = x` and `return : Real[2]` hold a sequence on every surface (REPL, `-json`, trace, gRPC and the clients, analysis and verification cases), an explicit `[1]` or `[0..1]` the bare value, and a result stating no multiplicity what the body computed, as before. A verdict, selected alternative or vector a case reads from such a result is read from the sequence's one element, so a `VerdictKind[0..*]` result no longer leaves the case inconclusive. The compiled calc tier declines a parameter or result declared to hold more than one value, so both tiers answer alike.
