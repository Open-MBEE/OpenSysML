- A calculation's result parameter is held in the shape its declared multiplicity gives it, as an action parameter is: `return : Real[0..*] = x` and `return : Real[2]` hold a sequence on every surface (REPL, `-json`, trace, gRPC and the clients, analysis and verification cases), an explicit `[1]` or `[0..1]` the bare value, and a result stating no multiplicity what the body computed, as before. A verdict, selected alternative or vector a case reads from such a result is read from the sequence's one element, so a `VerdictKind[0..*]` result no longer leaves the case inconclusive. A parameter declared `[0..*]` holds one bound value as a one-element sequence, which a condition (`if`, `while`), `==` and `===` read as the value it holds, as the other operators already did. The compiled tiers follow: the scalar fast path declines a parameter or result declared to hold more than one value, and a generated Go or C program holds its collection parameters and result in the same shape and reads a one-element collection the same way, so every tier answers alike.
