- CI's Emacs package job no longer downloads the Emacs 29.1 source from `ftp.gnu.org` on every run. The job installs Nix with the flakes feature, and with it Nix fetches each source the `nix-emacs-ci` expressions evaluate over (nixpkgs, the Emacs snapshot, the release tarball) from its origin, although the `emacs-ci` binary cache holds all three beside the built Emacs; when `ftp.gnu.org` stopped answering, the job failed in its setup step, three merge-queue groups in a row. The job now installs Nix without flakes, so evaluation takes the sources from the binary cache by hash and contacts `ftp.gnu.org` only if the cache lacks one.
