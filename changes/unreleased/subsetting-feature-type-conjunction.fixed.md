- Instantiating a part whose `shape` is a `ShapeItems::Cylinder` or `Cone` no longer reports `binding end cannot be resolved "cf.edges": feature edges not found` and `Surface has no member vertices`: an object held by a feature typed by one definition that subsets a feature typed by another has both types (KerML 1.0 §7.3.4.3–§7.3.4.4), so `cf : Surface :> faces` carries `StructuredSurface`'s `edges` and `vertices`, a member both types declare is one feature, a redefinition inherited through either type names one feature under both names (chains of the two types that share a name being one chain), a feature stating several types (`part both : A, B`) holds values of every one, and a Kernel member the model binds through any of the object's types is a slot of the object. A subsetter typed by an unrelated definition now contributes an object of both types to the feature it subsets rather than failing as a type mismatch.
