- Instantiating a part whose `shape` is a `ShapeItems::Cylinder` or `Cone` no longer reports `binding end cannot be resolved "cf.edges": feature edges not found` and `Surface has no member vertices`: an object held by a feature typed by one definition that subsets a feature typed by another has both types (KerML 1.0 §7.3.4.3–§7.3.4.4), so `cf : Surface :> faces` carries `StructuredSurface`'s `edges` and `vertices`, a member both types declare is one feature, and a Kernel member the model binds is a slot of the object. A subsetter typed by an unrelated definition now contributes an object of both types to the feature it subsets rather than failing as a type mismatch.
