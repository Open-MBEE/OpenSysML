- Indexed connector ends, an OpenSysML extension: `connect s.y#(1) to k.u` attaches one element of the collection-valued feature `s.y` (1-based, as `#(` indexes everywhere) at an end of multiplicity one typed by the element's type, on the last segment of the end's feature chain, in `connect`, `connection … connect`, `interface`, `allocate`/`allocation`, `bind`/`binding`, structural `flow` and the KerML `connector`/`binding` forms. The index must be an Integer and a constant index must lie within the feature's declared multiplicity; at run time a connector or binding over the end addresses only the selected element, and an out-of-range or non-Integer index is a typed connector-end error. The end is reported as `nonstandard-notation` (an error under `-strict`), is written back by the formatter and the notation converters, and the RDF and API JSON mappings carry the index as `sysx:endElement` beside the standard reference subsetting of the whole feature.
