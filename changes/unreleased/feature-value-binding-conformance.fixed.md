- A feature value whose type is unrelated to the feature's own type is now reported as the `bound-feature-types` warning at the feature, as the pilot reports it: `attribute def R :> Real; attribute a : R = 5;` warns, since Integer and `R` specialize neither the other, where the value was judged against `Real` and passed. A `default` value, a value the type checker already refuses, a collection value, and a feature typed by a `Collection` or `Element` are left as they were.
