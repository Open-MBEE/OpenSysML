- A feature typed by a standard-library type (`attribute seq : Integer;`, `accept at new Time::Iso8601DateTime(...)`) now answers the members it inherits through that type (`inheritedFeature`, `feature`, `member`, `input`, …) in `GetElementProperties`, metaobject reads and query cells. Before, a library type reached only through such a typing was held without its symbol, so every member query over it, and over whatever inherited from it, reported `Type::inheritedFeature is not derived for this element`; a constructor of such a type could not bind its arguments either.
