- The RDF mapping states the address of an element the metamodel derives no `qualifiedName` for — an unnamed element, or one owned under an unnamed element, named by its position (`P::@2`, `P::@2::x`) — as `sysx:positionalName` rather than `sysml:qualifiedName`, which is now stated only for a qualified name the metamodel derives (KerML §8.3.2.1). The reader takes either predicate for the address, so a graph an earlier release wrote still reads back; the api-json element form carries the address as its `sysx:positionalName` key and leaves `qualifiedName` unstated for such an element, as the pilot implementation's API leaves it null.
