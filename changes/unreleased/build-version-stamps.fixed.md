- **Report the build's version, commit and time even when the linker stamped none.** `sysml -version`, `sysml-lsp -version`, `sysml-grpc -version` and the other commands used to print `dev` and `unknown` unless built with the Makefile's `-X` flags, so a `go install github.com/Open-MBEE/OpenSysML/cmd/sysml@latest` binary could not say which release it was. Every command now resolves its build through one shared resolver: the linker's stamps when set, otherwise the module version and VCS metadata the Go toolchain embeds — the release tag for a `go install` of a tagged version, the commit and its time (`-dirty` for a modified tree) for a build from a checkout — and `dev`/`unknown` only when neither is recorded. Stamped builds report exactly what they did before.
- **`sysml-lsp` names its real version in the `initialize` response.** `serverInfo.version` was a fixed `0.1.0`; it is now the version the binary prints for `-version`.
