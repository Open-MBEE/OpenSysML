- **A «Probability» naming a property of an enclosing block now migrates to a valid read.** An action def nested in a behavior of a block nested in the block holding the property takes its owner as its context, like any def acting on its owner, and its `@Stochastic::Probability { p = … }` reads the property through it (`context.pr`, `context.mission.pr`, and the `1.0 - …` complement alike) when the object it acts on holds the property, by inheritance or in its one part that is exactly one object; when no object in reach holds it, or the part that does may be several objects or none, the branch is weighted by the property's finite default with an `Approximated` ledger note, as `-strict` already wrote it. Previously the name was written bare and `-validate` refused it as not an accessible feature.
- **`Stochastic::Probability::p` is checked for accessibility where its succession is.** The value is read when the decision is reached, so its feature reads are judged from the succession's action, as its guards are, in both spellings (`@Probability { p = … }` and `metadata Probability { p = … }`) — a named succession's read of the action's own feature no longer errors, and an anonymous succession's read of an unreachable feature is no longer let through.
