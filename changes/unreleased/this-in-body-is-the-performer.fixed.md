- `this` written in a behavior body now denotes the context occurrence the member read `.this` answers: the object owning the performance for an action, state, calc or constraint a part owns (`Objects.kerml` `ownedPerformances::this default that`, `Parts.sysml` "the `this` reference of an ownedAction is always its owning Part"), the owner's `this` for a subaction (`Performances.kerml` `subperformances::this default (that as Performance).this`), and the performance itself only when no object owns it. A typed action usage a part owns no longer answers its own occurrence for `this` or `self.this` in its definition's body; a package-level action nothing performs still reads `this` as undetermined.
- `this.<feature>` written in a behavior definition resolves `<feature>` against the declared type of `this` (`Occurrences.kerml` `Occurrence::this : Occurrence[1] default self`), as the pilot does: a definition reading its own feature, or its enclosing part's, through `this.` is refused at analysis as an unresolved member — read the definition's own feature by name. `this.<feature>` in a behavior usage's body still resolves against the owning object.
- A behavior run reads by name what another performance wrote to a feature of its occurrence, and a feature a definition's body assigns after `this` materialized the occurrence keeps the assigned value when read by name (the read re-derived the declared default).
- A definition that redefines `this` with a type (`ref part :>> this : H;`, the pilot-clean way to read a performer's features in a definition) is valued from the same context occurrence the member read answers, so `this.level` reads the performer's `level`; an object performing it that is no `H` is refused as "an object of Q" written to a feature typed by `H`. Binding `this` to a parameter typed by the enclosing behavior definition itself (`in ref :>> context = this` with `context : Life`) still runs for a machine no object exhibits, where `this` is the machine, and is refused at run time when a part exhibits it, where `this` is the part; bind the machine's occurrence to the parameter instead.
