- The Go client's `EngineInfo` carries an engine's origin as `ListEngines` reports it: `Kind` (`built-in`, `tool`, `engine`, `policy`, `sampler`), `Protocol` (`-`, `object`, `argv+<stdin>`, `<transport>/<protocol>`), and the manifest entry's `Source`, `Command` and `Version` with whether the service runs it (`Served`). The service filled all six and the package dropped them, so a Go program could not tell a built-in engine from a manifest one, or a served one from a listed one, without running `sysml -engines`.
