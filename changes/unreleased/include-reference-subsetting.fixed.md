- **`include <ref>;` is written with the `ReferenceSubsetting` the metamodel gives it.** The `IncludeUseCaseUsage` of `include pay;` now owns a `ReferenceSubsetting` to `pay` in Turtle and `api-json`, as `IncludeUseCaseUsage` and its derived `useCaseIncluded` require, instead of a `sysml:includes` property the metamodel does not have; `include use case u : T`, which includes itself, no longer states one either. Graphs written with `sysml:includes` still import.
