- A calculation body that states a token flow of its own now runs it, as an action body does (`CalculationBodyItem : ActionBodyItem`, SysML v2 8.2.2.19): successions between its action nodes (a guarded `first a if g then b;` included, which used to report `not-a-vertex`), `first start`, forks, joins, merges and decisions order the nodes, in the body itself, in a loop or branch body of it, and in an action declared in one, and a flow or binding between the pins of a loop or branch body's nodes carries its value, where each used to be refused as not executable. A `then` between a calculation's plain statements remains a statement order.
