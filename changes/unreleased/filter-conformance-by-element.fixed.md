- An element filter (`filter @T;`, `import P::*[@T]`, `expose X::**[@T]`) and a classification (`@T`, `@@T`) now test conformance against the Type element the name resolves to, through its specialization closure, rather than against the qualified name: a type named through an `alias` or a re-exporting import selects what the aliased Type annotates, and a distinct Type that shares the qualified name (the same package opened in another document) selects nothing it does not annotate. The name alone decides only when it resolves to no element, or across copies of a library document.
