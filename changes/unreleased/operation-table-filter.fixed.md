- **A generic table over UML `Operation` lists the block operations again.** Since a block-owned operation migrates as its block's `action` usage, a `sysml -migrate` table whose `rowElementType` is `Operation` — or `Namespace`, which holds operations in UML — selected only the `action def` an operation a state runs keeps; it now also lists the operations written as usages, by name, as an `Actor` or `UseCase` table lists its usages.
- **A table over UML `Operation`, `Interaction`, `Activity` or `OpaqueBehavior` no longer lists state machines.** A `state def` conforms to `ActionDefinition` (as a `calc def` does), so these tables listed every state machine, and `Operation` and `Interaction` tables every calculation; the query now excludes the definitions those metaclasses never migrate to.
