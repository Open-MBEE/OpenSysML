- Operand evidence reads now preview on a fresh step and element budget capped by the configured limits, independent of a spent caller budget: a document query still finds a comparable value behind a lazily evaluated held attribute after an earlier session evaluation spent its budget, instead of rejecting a valid comparison. Bulk compiled charges and lazy listings stay within that budget and fail with a typed budget error that names the fixed evidence cap rather than an environment variable that cannot lift it; interrupts and rollback still apply, and an evidence read continues the caller's seeded draw stream rather than restarting it.
- An exhausted evidence preview now reports its step or element budget instead of blaming the comparison on the values it could not read; a preview uses the draw seed and policy in force when it starts, while one nested in a run continues that run's draws, and nested reads of a dotted path stay charged to the whole preview so the same step allowance cannot be spent twice.
- A runtime probe that took no identity now skips the full held-identity scan on rollback, so a filter collecting evidence over a large held population no longer does quadratic work under the runtime lock.
