- Structured renders now report each node's notation shape on `RenderNode.shape`, derived from the element's metaclass and rendering kind: `rectangle`, `rounded`, `stadium`, `actor`, `note`, `diamond`, `circle`, `ring`, `cross`, `bar`, `history` or `item`. A canvas can draw a case as a stadium, a requirement as its box and an actor as its stick figure without parsing a written form. The field is additive — every written form stays byte-identical — and gated by the `render_node_shape` capability, so a client that does not have it sees no shapes. The JSON-RPC engine and the language server carry the same field; the Go, Python, Node, Java and Rust clients decode it, Julia and MATLAB declare the capability, and the VS Code canvas draws the stadium and actor glyphs.
