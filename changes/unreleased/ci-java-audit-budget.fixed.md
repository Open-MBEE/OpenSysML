- A Maven Central stall during the Java dependency audit no longer cancels the Java client's conformance run. `scripts/maven-sbom.sh` cuts each attempt at 90 seconds (`MAVEN_SBOM_TIMEOUT_SECONDS`, under GNU `timeout`) and retries it as it retries a refused artifact, alternating the mirror, so the resolver's minutes of backoff from an HTTP 429 fail over instead of spending the job; in `pr.yml` each `make audit-java` step has `timeout-minutes: 10`, and the Java client's runs after its tests and conformance suite. The audit still fails the job when no SBOM is written or a finding is reported.
