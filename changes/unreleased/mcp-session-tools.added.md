- **`sysml-mcp` session tools.** The session group drives a persistent REPL session as typed tools with structured results: `session_load`, `session_submit`, `session_eval`, `session_print`, `session_save` (writes only with `apply`), `session_clear`; `session_run` for an action, state machine, calc or analysis case; the action and state machine debugger (`debug_start`, `debug_step`, `debug_continue`, `debug_current`, `debug_breakpoints`, `debug_stop`, `send`, `advance`); `features` and `instances` over the instance graph; the solver (`check`, `explain`, `solve`, `configure`, `optimize`); `sweep`, `runs` and `render_run`; and `repl_command` for every other `%` command. Calls on one session are served one at a time, and a call the client abandons interrupts the run.
