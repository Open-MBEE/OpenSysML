- `expose` in a `view def` body is now a syntax error, `expose-owning-namespace`, as it already was in every other body that is not a view usage's. Only a view usage owns an `Expose` (SysML v2 8.3.26.2 `validateExposeOwningNamespace`), and the textual notation offers it in a view usage body alone (8.2.2.26.2 `ViewBodyItem`; `ViewDefinitionBodyItem` has a filter and a rendering, and no `Expose`). Before, OpenSysML resolved the member and reported a `nonstandard-notation` warning, an error under strict conformance only. Move the `expose` into the view usage that shows the elements — `view v : V { expose Model::**; }` — and keep the definition for its `filter` and `render` members; a view usage that specializes another still inherits what that one exposes.
