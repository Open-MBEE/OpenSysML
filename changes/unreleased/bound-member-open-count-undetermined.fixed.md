- A bound member that reads a feature chain through a package-level usage whose member's count the model leaves open (`attribute boundLimit : Real = req.some.limit;` over `part some : Sub[1..*];`) is `<undetermined>` on an instantiated holder, as the chain read directly is, instead of the value of a lower-bound element nothing in the model picked; so is a derived feature of such a usage read at model level (`req.own` over `own = some.limit`). A count a binding (`= (a, b)`), a redefinition (`:>> some[2]`) or a fixed multiplicity closes still evaluates, and an instantiated object keeps the lower bound it materializes.
