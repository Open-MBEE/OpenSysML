- The solver translates `P->forAll { in ref w; w == P::V }` and `P->exists { … }` over a variation point `P` that holds at least one object as the point's selection, `P == P::V` (`P != P::V` for `w != P::V`): a configuration holds only the variant it selects (SysML v2.1 §8.3.6, §7.6.7), so `%configure`, `%solve`, `%check`, `%explain` and the MCP `configure` tool now put such a constraint in the query instead of refusing it. A point that may hold no object, a body comparing the iterate with anything but a variant of the point, and every other invocation stay refused, each with its reason.
