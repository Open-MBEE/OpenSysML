- `ImportData` and `CompareResults` RPCs with the `import_data` and `compare_results` MCP tools: the tabular and JSON data import that sets the feature values a CSV, TSV, JSON or JSON Lines file assigns, one row per element, answering every assignment made and the edited model as a new model the service holds (`sysml -import`, `-import-as`, `-import-map`, `-import-format`, `-import-dry-run`), and the comparison that runs the configurations a SysML v1 tool's results index names and tables the tool's distributions of their observables beside the runs' (`-compare-results`, with `-runs`, `-seed`, `-draws`, `-clock-step` and `-observe` as request fields). Both call the lowering and comparison the REPL calls, now in `internal/workspace/dataimport` and `internal/exec/simresults`. The service advertises the `import_data` and `compare_results` capabilities; the Go, Python, Node, Java, Rust, Julia and MATLAB clients expose them as `ImportData`/`import_data`/`importData` and `CompareResults`/`compare_results`/`compareResults`.
