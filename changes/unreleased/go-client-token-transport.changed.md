- The Go client's `opensysml.Dial` now refuses, with `CodeInvalidArgument`, to send a bearer token (`WithToken` or `$OPENSYSML_GRPC_TOKEN`) over plain `http` to an address other machines reach, where it used to send it in clear; an address without a scheme is still dialed as `http`. Dial an `https` address, or pass the new `WithInsecureTokenTransport()` when a proxy or tunnel encrypts the connection. Loopback addresses and calls without a token are unaffected.
