- `%viz [--view=<VIEW>] [--style=<STYLE>...] [<form>] <name> [<name>...]` draws named elements on demand in the `sysml` REPL and the Jupyter kernel with the OMG pilot kernel's grammar: `VIEW` is `DEFAULT`, `TREE`, `INTERCONNECTION`, `STATE`, `ACTION`, `SEQUENCE`, `MIXED` or `CASE` in any letter case, `DEFAULT` choosing the rendering kind from what the names resolve to; several names draw in one diagram; `--style` maps the pilot's directions to the rendering direction and takes the `pilot`/`cameo` drawing styles, palettes and port displays, while a pilot style no form here draws (`ORTHOLINE`, `POLYLINE`, `COMPTREE`, …) is accepted and noted as not drawn. In the kernel a `%viz` cell with no form shows the diagram as Mermaid and, where Graphviz is installed, as SVG drawn from DOT.
