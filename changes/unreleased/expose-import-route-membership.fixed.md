- An imported membership has the visibility of the import that admitted it, and each import applies its own `all` (KerML 8.3.2.4.5 `importedMemberships` / `visibilityOf`, SysML 8.3.26.2): `expose Mid::*` and `import all Mid::*` take every membership of `Mid` — its private members and what it imported privately — but no longer the private members of the namespaces `Mid` imported with an ordinary import, and no longer what an intermediate ordinary import never took; a private member re-exported by a `public import all` is now reachable through that import; a recursive import or expose (`::**`) descends the namespaces its target owns, not the ones imported there. A view's privately imported members are now listed in the imported namespace's own order.
