- **A migrated comment's cross-references are resolved, not printed as markup.** Cameo stores documentation as HTML, and the SysML v1 migration reduced it to text, so a View Editor cross-reference (`<mms-cf mms-cf-type="name" mms-element-id="…">[cf:APS Location.name]</mms-cf>`) printed its `[cf:…]` fallback and an element hyperlink (`<a href="mdel://…">`) kept only its text between doubled spaces. Both are now resolved through the export by id: in a document paragraph each becomes a `Ref` run to the section, figure or table the target became in the same document — rendered `Section N.N - Title`, `Figure N`, `Table N` and linked, as a native reference is — or to the element by name, between `Span` runs of the prose; elsewhere (`doc` comments, requirement text, stereotype tags) the reference reads as the target's current name. A `val` reference reads the slot's value and a `com` one the target's documentation, each noted as approximated. A reference to an element the export does not contain prints nothing (an `<mms-cf>`) or keeps its text (a hyperlink), and the comment's report row says which id is missing; a hyperlink whose text is stale is written with the current name and noted. The spaces dropped tags left are collapsed. A `Ref` may now also target a model element outside every document — a usage by name, any element as `E.metadata` — and renders as its name.
