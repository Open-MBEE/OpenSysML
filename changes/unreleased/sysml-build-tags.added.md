- **A production `sysml` build, without the optional features.** `-tags sysml_prod` (`make build-prod`, `make build-wasm-prod`) builds `sysml` without SysML v1 migration, repository sync, native compilation, the HTML and PDF document forms with the Graphviz drawer, FMU import, profiling, and the REPL's `%print`, `%save`, `%query`; one `sysml_no<group>` tag leaves out one group. Such a build refuses a left-out flag with status 2, as `sysml: -compile is not available in this build (built without codegen)`, and leaves it out of `-help` and `-man`. The default build is unchanged.
