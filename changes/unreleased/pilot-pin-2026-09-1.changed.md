- The OMG pilot implementation pin (`scripts/pilot-pin.sh`) moves from release `2026-09` (`jupyter-sysml-kernel 0.63.0`) to `2026-09.1` (`0.63.1`), the supplemental release that corrects the reference-link resolution regression of `2026-09`; the standard library, the specification documents and the Xpect suites are unchanged between the two, and every pin-stamped baseline is re-recorded at the new release. The pilot no longer warns `Bound features should have conforming types` on enumeration literals bound inside its own metadata examples, so the ten only-pilot rows the `2026-09` round added to `sysml-examples` are gone and the three files agree fully again.
- The weekly `Upstream drift` workflow now files its report: a run that finds the pilot or specification moved past the pin opens one issue labelled `upstream-drift` (`scripts/upstream-drift-issue.sh`), later runs refresh it and comment only when the report changes, and the run that finds the pin current closes it. `scripts/check-upstream-drift.sh` exits 1 for movement and 2 when a source could not be read, and the job fails only in the second case, so a red run means the check did not happen rather than that upstream moved.
