- A KerML classifier written with `def` (`class def X`, `struct def X`, `assoc def X`, `behavior def X`, `predicate def X`, `classifier def X`) converts back from RDF or the API's JSON element form with its `def` when the graph carries no source text, instead of as the def-less declaration: the `def` form now records `sysx:declaredKeyword` with it (`"class def"`). A `datatype` or `function` whose graph states no `sysx:declaredKeyword`, as one another tool wrote, reads back under that keyword from its `DataType` or `Function` metaclass rather than as an `attribute` or a `calc`. A graph typed with the `ClassUsage`, `StructureUsage`, `AssociationUsage`, `BehaviorUsage`, `PredicateUsage` or `InteractionUsage` names earlier releases wrote converts to the API's JSON under the KerML metaclass it meant, not under a name the metamodel does not declare.
