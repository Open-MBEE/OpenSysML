- An `Instance` the service answers (`Instantiate`, the `Verify*` subjects, the engine and wasm builds) now says how the graph reached it — `reached_by`: the holding instance, the feature it is a value of and that feature's qualified name, its 1-based index in a multi-valued feature and the path from the root — as the runtime's traversal reached it, which is depth-first from the root over the features in name order (the model's own before the standard library's) and reaches each object once. One object is a value of several features (a port and the connector end referencing it are one object), so the new `InstancePaths` RPC (capability `instance_paths`, MCP tool `instance_paths`) lists every root-relative path to an object, aliases through connector ends and reference usages included. The Python `Instance` exposes `owner`, `feature`, `path` and `paths()`, `Model.instance_paths()` names an object by id or path, and the Go client types `InstancePaths`.
