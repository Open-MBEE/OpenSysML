- **An opt-in `rounded-real-literal` lint.** A decimal literal written to a feature typed by `Real` that no binary64 value equals can now be reported where it is written, naming the double the feature holds: `attribute x : Real = 0.1;` warns that `0.1` is rounded to `0.10000000000000001`, while `0.25` and `1.5e3`, which a double holds exactly, are silent. It covers a feature's value, a parameter's default, a redefinition of a `Real` feature, an `assign` and each element of a sequence written out, but not a computed value. Since most decimals written to a `Real` round, it is off by default: switch it on with `-enable-lint rounded-real-literal`, `%lint rounded-real-literal on` or the new `enabledLints` editor setting (`model.WithEnabledLints` in Go). Like every lint it is a warning in every mode, and `-disable-lint` wins over `-enable-lint`.
