- A requirement rendering of a `GeneralView` draws each requirement's subject, actors and stakeholders: the definition typing the feature is drawn beside the requirement, joined by an edge named `«subject»`, `«actor»` or `«stakeholder»` and the feature (`MassRequirement o-- SystemDefinition: «subject» sys`). A role redeclared without a type (`subject :>> sys;`) goes to the type of the feature it redefines. A filter selecting requirements together with definitions or usages (`@SysML::RequirementDefinition or @SysML::PartDefinition`) now draws those elements in the requirement graph instead of reporting them as not drawn.
