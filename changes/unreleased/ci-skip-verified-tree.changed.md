- CircleCI no longer re-runs the test suite over a tree GitHub Actions has already proven: the `build-test` workflow on `develop` and `main`, and the `release` workflow on a tag, start with `verify-tree` (`scripts/ci-verified-tree.py`), which looks for a green full-tier `Build and test` check run on the commit — or, for a tag, a green `build-test` workflow of `main` — and the suite jobs halt green with that evidence when it is found; the coverage shards, the SonarCloud scan and the artifacts downstream jobs read still run, and an unverified commit, a rehearsal or an error reading the evidence runs everything as before.
