- **A migrated tree view exposes only what a symbol of its own stands for.** MagicDraw lists a class box's compartment rows — attributes, constraint properties, enumeration literals, ports listed in a compartment — among a diagram's used elements, and keeps an association end's role name as a symbol on the line. The SysML v1 migrator exposed each of them, so a tool opening the view drew every attribute, and every part usage whose only appearance was a role name, as a node of its own: an internal block diagram on a block definition diagram. A view rendered `asTreeDiagram` now exposes the definitions, usages, ports and lines that have a symbol, and leaves a listed element no symbol stands for, or whose symbols all lie on a line, to the exposed element that draws it; the diagram's ledger entry counts them as "compartment rows or end labels of exposed elements, not exposed". Hidden symbols and listings (`visible` false) are off the diagram as before. The `DiagramLayout::Layout` and `Route` annotations are unchanged, with shorter qualified names where a same-named end usage is no longer exposed. Interconnection, use case, state and activity views are not affected.
- **The line backing an attribute's type on a block definition diagram keeps its route.** An anonymous association that only backs a value or enumeration attribute is skipped as notation, and the tree rendering draws the attribute's typing edge from its owner's box to its type's box; the Cameo line's `DiagramLayout::Route` is now written about that attribute, run from the owner's box whichever end the tool drew first, so the rendering follows it instead of reporting the route `not written`. A private attribute, which the view cannot name, takes no route (reported `not exposed`).
