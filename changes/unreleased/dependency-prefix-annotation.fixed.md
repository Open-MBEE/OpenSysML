- **A dependency's prefix metadata is an Annotation.** `#Tag dependency a to b;` wrote the metadata usage under an `OwningMembership` of the dependency; the grammar's PrefixMetadataAnnotation makes it the annotating element of an `Annotation` the dependency owns, which the Turtle and API JSON forms now write and read back (#652). A usage's prefix metadata stays an `OwningMembership` (PrefixMetadataMember).
