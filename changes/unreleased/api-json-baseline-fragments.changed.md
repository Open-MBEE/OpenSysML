- The committed api-json differential baseline is a directory, `docs/project/api-json-differential/`: one fragment per compared source file (`<root>/<relative path>.json`, the file's summary and its scorecard rows in key order) beside an `index.json` that carries the provenance, the recorded file lists and the aggregate figures, which are a fold over the fragments. Two branches re-recording the baseline now conflict only on a fragment whose verdicts they both moved, and a conflicting `index.json` is rebuilt from the merged fragments without the pilot (`pilot-apijson-diff -reindex`); `-update -roots <roots>` re-records named roots' fragments alone. The storage and comparison are the shared `tools/referee/baseline` package, which the other referee baselines can migrate onto; each referee keeps its own rows and ratchet policy. The monolithic `docs/project/api-json-differential-baseline.json` is gone.
