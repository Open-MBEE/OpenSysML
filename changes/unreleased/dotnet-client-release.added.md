- The .NET client is released as the checkout of the core `v<version>` tag, published to no registry. The release workflow refuses a tag before building anything when `client/dotnet/Directory.Build.props` declares another version, or when the client's public API has entries not yet promoted to `PublicAPI.Shipped.txt`; `python3 client/dotnet/scripts/dotnet-gates.py promote-api` promotes them on the release branch, and [Releasing OpenSysML](docs/project/releasing.md#releasing-the-net-client-as-the-tags-checkout) documents the procedure. The client's README lists every RPC with the public methods that call it, held to the parity inventory by a test.
