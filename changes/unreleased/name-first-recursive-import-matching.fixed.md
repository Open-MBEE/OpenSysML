- **A name looked up through a recursive import no longer lists the whole subtree.** Resolving one name through `import X::**` enumerated every element below `X` and ran the hiding checks of KerML 7.2.5.4 on each of them, which made name resolution on models built from recursive imports about sixty percent slower. The lookup now finds the candidates bound to the name first, in each namespace's own members and in the index, and applies the visibility, re-export and hiding checks only to those and to the namespaces it descends into. Listings that need every member (completion, the imported-member audits) are unchanged, as are the names a lookup resolves to.
