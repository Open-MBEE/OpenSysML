- A `namespace` declaration in a `.sysml` file is now an error in the default mode, not only under `-strict`: SysML v2 has no namespace declaration (8.2.2.5.1 `RootNamespace`, 8.2.2.5.2 package body elements; KerML 8.2.3.4.1 declares it), and the pilot rejects it too. The `kerml-notation` error points at the keyword past a visibility or prefix metadata, the members of the namespace are still resolved and checked, and a `.kerml` file is unaffected. Write `package`, or move the declaration to a `.kerml` file.
