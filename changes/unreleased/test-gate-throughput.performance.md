- **Added a bounded, shard-aware local test-gate runner.** `go run -C tools ./cmd/gate-runner` discovers every CI shard from `scripts/race-shard.sh --all`, runs at most a configurable number at a time (four by default) over one warm build cache, and exits non-zero naming every failing shard. A hygiene test enumerates every declared shard at every tier so a new shard cannot miss the local gate.
- **Documented a shared-cache recipe and an opt-in deadline scale for contended hosts.** `OPENSYSML_TEST_BUDGET_SCALE` stretches wall-clock deadlines only; unset and in CI it is exactly `1`, and no expected value, model budget or assertion changes.
