- `sysml -self-check` evaluates `validatePortDefinitionOwnedUsagesNotComposite` on the conjugated port definition a `port def` implies (`~Bus`) as it does on the definition itself, instead of reporting the check unevaluated with `reflective feature is not derived: SysML::Systems::ConjugatedPortDefinition::ownedUsage`.
