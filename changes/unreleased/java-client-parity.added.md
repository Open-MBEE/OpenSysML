- **The Java client gains the Python client's newer surface.** `Model.edit()` returns a fluent `Editor` (with `Editor.Body` for action-body statements) over the existing `Edit` records; `Model.renderDocument` renders HTML as well as Markdown (`DocumentForm`, gated on `render_document_html`); `ConversionOptions.withIdForm` forwards `id_form`; `Conversion.write`/`EditResult.save` write files; `Model.find`/`get`/`lookup`/`contains`, `documents`, `ok`, `errors` and `requireNoErrors` match the Python model; `ConnectionOptions.requireCapabilities` and a release check at open throw `CapabilityException` (now carrying a `remedy()`) or `StaleServiceException`; and `NOT_FOUND` refusals for a model or file arrive as `ModelNotFoundException`/`ModelFileNotFoundException`, a missing symbol as `SymbolNotFoundException` with near-name suggestions.
