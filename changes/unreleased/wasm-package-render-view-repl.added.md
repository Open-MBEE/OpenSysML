- `sysml-wasm` (and the `@openmbee/opensysml-wasm` package) now serves `RenderView`, answering with the engine's drawing shape; the release and nightly wasm assets and the npm package also carry `sysml-prod.wasm.gz`, the gzip-compressed browser build of the `sysml` REPL, so a page can load both the landing-page engine and the REPL from the published package. The site's engine and REPL loaders accept a plain `.wasm` URL (compressed in transit by a CDN) as well as a local `.wasm.gz`.
