- A `connection`, `interface` or `allocation` usage a package declares (`connection outer : Link connect sys.x to sys.y;`) now counts in `all Link` and reads as one Link with its ends attached (`outer.a == sys.x`), as the same usage nested in a part already did; a usage stating `[0..*]` denotes none. It was omitted from the extent and read as an undetermined value, so a requirement counting `all Link` was violated by one (#1543).
