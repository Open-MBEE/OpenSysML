- A query's `elementId` is now stated for the collection a `for` loop iterates, the conditions a
  `while` or `loop … until` tests, and an assignment's target and value, each with its owning
  membership and the parts the expression owns; each read blank before, though the RDF conversion
  writes the element. A named `for` node (`action n for i in …`) no longer reflects its iteration
  variable as a member owning a second copy of the collection.
