- The compliance map states the representative-object policy for a feature that states and inherits no multiplicity: the specification bounds the number of values a feature may hold (KerML 1.1 §7.4.12, §7.4.5.2; SysML v2 §7.6.3) and leaves open what a representative instance materializes for a valueless feature, so OpenSysML materializes one representative object for such a feature, none for a declared `[0..*]`, and judges no count against the defaulted feature; recorded as a tool decision.
