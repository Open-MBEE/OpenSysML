- A flow owns its two FlowEnds on the native walk — an `EndFeatureMembership` each after its payload, the end reference-subsetting the feature before the last it names and owning the `ReferenceUsage` that redefines that last feature, named by it — as the RDF conversion writes them and the pilot exports `Connector::connectorEnd`; the query leg reads the conversion's ids (`_pend0`, `_pend0_prs`, `_pend0_pff`, `_pend0_pff_rd0`).
