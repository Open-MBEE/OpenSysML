- `sysml -compile` for the C target now computes Integers exactly at any size, as the interpreter and the Go target do: a value is an `int64` while it fits and an arbitrary-precision integer beyond it, bounded by `OPENSYSML_MAX_INTEGER_BITS`. Calcs with Integer arithmetic that the C target refused now compile, an Integer argument beyond `int64` is read, and a Real parameter reads an argument in Integer notation and keeps it an Integer.
