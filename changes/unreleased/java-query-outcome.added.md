- The Java client decodes the `QueryOutcome` status detail a failed `RunDocumentQuery` or `Query` carries: `Model.runDocumentQuery`, `query` and `queryOslc` throw a `QueryOutcomeException`, a `ServiceException` whose `outcome()` is the structured record — the outcome kind and step, each path failure's step, expectation and frontier (the element the path stopped at, the candidate members, features or relationship kinds there and the nearest spelling), and each model finding's element, constraint and observation — so a caller can show and annotate the failure instead of parsing the status message.
