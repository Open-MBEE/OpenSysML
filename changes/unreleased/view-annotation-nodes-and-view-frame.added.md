View renderings draw the SysML v2.1 §8.2.3.4 annotation nodes and links and the §8.2.3.26 view frame. Comments, documentation and textual representations are drawn as note-shaped nodes (`«comment»`, `«doc»`, `«rep»` headers, the comment's name, locale and language where declared) joined by a dashed annotation link to each element they annotate, and a positioned node's documentation becomes its `doc` compartment; they are on by default and the new optional element `annotations` (`showAnnotations`, `-render-show`) turns them off. Every view is drawn inside a view frame with the `«view»` name compartment at its top-left corner and the exposes, filters and view documentation in the top-right, bottom-left and bottom-right information compartments — exactly in DOT, draw.io and the VS Code canvas, as PlantUML's `mainframe`, Mermaid's frontmatter title and D2's corner texts elsewhere. The default DOT, PlantUML, Mermaid, D2 and draw.io output of every view changes accordingly; the Cameo style keeps its own frame. The rendering data of `-json`, the language server's render result and the gRPC `RenderViewResponse` carry the frame as a new optional `frame` field (`RenderFrame`, also on the typed `RenderedView` of the Go, Node, Python and Rust clients), the `shown` list names `annotations`, and the committed document and landing fixtures were regenerated for the framed output.
