- A collection operation's body may be a function the argument names rather than a body expression, as KerML's function reference expression allows and the library's own `NumericalFunctions::sum0` (`collection->reduce '+' ?? zero`) relies on: `(1, 2, 3)->reduce '+'` is `6`, `->reduce max` the largest, `->collect Neg` applies a model's `calc def` to each element, where every such form was refused with `requires a body expression, got function`. A function declaring a different number of parameters than the operation passes is a body-arity error, and a value that is no function is still refused.
