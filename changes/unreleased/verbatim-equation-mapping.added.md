- A constraint body can carry an equation that has no SysML expression form verbatim as a user-defined metadata annotation whose `body` String holds the text. A Modelica medium-state call, stream value or event-regularising conditional is then carried unchanged through parsing, evaluation (`.metadata#(i).body`) and both export forms (`"value"` in the API element form, `sysml:value` in the graph), including quotes, backslashes, newlines and non-ASCII; the names in the text are never resolved, and a body whose only members are annotations still states no condition. The convention is documented in `docs/reference/rdf-mapping.md` under "Verbatim equation mapping annotations". The direct expression spelling of those Modelica forms remains a known limitation with a skipped test; generating a class body from the annotations and the `omc` differential belong to the consuming generator.
