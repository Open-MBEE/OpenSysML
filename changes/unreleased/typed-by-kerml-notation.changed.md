- **A typing spelled `typed by` in a `.sysml` file is reported as `kerml-notation`.** The SysML v2 grammar spells a usage's typing `:` or `defined by` (`SysML.xtext` `DefinedByKeyword`); `typed by` is KerML's spelling (`KerML.xtext` `TypedBy`), which the pinned pilot rejects in a SysML file and OpenSysML accepted silently. The parser still reads it, so the model analyses as before; the default mode warns at the two keywords with a fix that writes `defined by`, `-strict` reports an error, and `.kerml` files are untouched. A metadata usage's typing (`@ m typed by Tag;`) is reported the same way.
