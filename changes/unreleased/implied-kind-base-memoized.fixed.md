- The base feature a declaration's kind implies — the library usage it subsets, the `Base::things` fallback, and whether a declared specialization chain already reaches it — is looked up once per symbol and memoized with its other implied generals; every implied-generals and direct-supertype query re-walked the declared chain and re-resolved the library name, which made semantics-heavy workloads (editing a large model, validating a stress model) about 25 % slower than before usages subset their kind's base usage.
