- **A named send node exports as one `SendActionUsage`.** `action sendReceipt send receipt to target;` is now a single `SendActionUsage` named `sendReceipt` in Turtle and in the API element form alike (SysML.xtext `SendNode`: an optional `ActionNodeUsageDeclaration` before `send`), where it used to be an `ActionUsage` owning a nameless `SendActionUsage`; the bare `send receipt to target;` is the unnamed `SendActionUsage` it always was. Import writes a named send back as `action <name> send … to …;` from its name alone.
