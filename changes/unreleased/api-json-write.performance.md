- **Writing the API's JSON element form takes about half the time.** The writer copied the whole triple graph twice before writing, once to add the root namespace and once to reconcile collections that were already in order, and had the JSON encoder re-parse and re-indent every element. It now reconciles in place when nothing needs reordering, assembles the wrapped graph without rebuilding its duplicate check, and writes compact JSON indented once. The output is byte-identical. On the 32-satellite stress network (`BenchmarkConvertAPIJSON`), a conversion drops from 19.1 s to 9.7 s and allocates 5.6 GB instead of 8.6 GB.
