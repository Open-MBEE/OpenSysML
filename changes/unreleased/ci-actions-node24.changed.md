- Every GitHub Action the workflows and composite actions pin runs on Node 24. The pins that still ran on Node 20 moved to their current release — `actions/checkout` 7.0.1, `actions/cache` 6.1.0, `actions/download-artifact` 8.0.2, `actions/setup-python` 7.1.0, `actions/configure-pages` 6.0.0, `actions/deploy-pages` 5.0.1, `actions/upload-pages-artifact` 5.0.0, `julia-actions/setup-julia` 3.0.3, `softprops/action-gh-release` 3.0.4 — and `actions/setup-java` moved from 4.9.1 to 5.7.0, so a run no longer warns that Node 20 actions are deprecated or that `setup-java` v4 receives no updates. Each action is now pinned at one release throughout, and Dependabot's weekly minor and patch updates cover the composite actions under `.github/actions/` as well as the workflows.
