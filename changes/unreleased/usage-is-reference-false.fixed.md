- A composite usage answers `isReference = false` wherever the element form is read — `GetElementProperties`, `sysml -convert api-json` and the clients over them — instead of answering nothing: `Usage::isReference` is a required Boolean derived as `not isComposite` (SysML v2.1 Beta 2 §8.3.6.4 `deriveUsageIsReference`), and the element form now completes it on every usage the graph does not state it on, as the negation of the `isComposite` the same element states. A feature whose declaration states `isComposite` keeps that value under its metaclass's rule — a KerML `composite feature` is composite and not referential.
