- **A semantic metadata definition inherits its supertype's `baseType`.** `metadata def <k> K :> M;` where `M` is a `SemanticMetadata` binding `baseType` now classifies a `#k` element as `M` does — the annotated usage subsets `M`'s base and a `#k` definition specializes its type — where before only a definition's own binding was read and `#k` added nothing. An own `:>> baseType = …` still takes precedence.
