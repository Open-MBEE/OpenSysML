- The escape sequence `\r` in a string or an unrestricted name (`"a\rb"`, `'a\rb'`) is now reported as `nonstandard-notation`, a warning by default and an error under `-strict`: KerML §8.2.2.3 Table 4 lists `\'`, `\"`, `\b`, `\f`, `\t`, `\n` and `\\` only, and `\r` is an escape the pilot's grammar adds. It is still read as a carriage return, and the escapes the lexer admits, decodes and classifies now come from one table. `sysml -migrate` no longer spells `\r`: a carriage return in a v1 name or string value is written as the character itself, which reads back the same, so a migrated model still passes a strict check.
