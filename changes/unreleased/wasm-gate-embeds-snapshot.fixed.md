- The WebAssembly gate (`tests/wasm`, `make wasm-check`) generates the bundled library's snapshot for its own run and links every command through a `go build -overlay` embedding it, so its gzipped size budgets bound the with-snapshot artifact every Makefile build target and `make build-release-wasm` produce, whether or not the tree holds `internal/workspace/libs/stdlib.snapshot`. Before, the gate measured whichever build the tree gave it: without the snapshot (what `go test ./tests/wasm` in a fresh clone, and the CircleCI gate, built) the artifacts are about 1.6 MB smaller gzipped and passed any budget, while a tree that had run `make build` measured the embedding build and could fail a budget CI passed. The CircleCI gate now runs the same `make wasm-check` as the GitHub workflow, and each budget constant's comment states the toolchain, date, artifact and measured size it was calibrated against.
