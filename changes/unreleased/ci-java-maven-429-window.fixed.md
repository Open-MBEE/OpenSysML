- **A Maven Central rate limit no longer runs a warm Java job out of its time.** Maven 3.10 asks every remote repository for its prefix file (`.meta/prefixes.txt`) in each run, whatever the cache holds, and an HTTP 429 to that cost each `mvn` call about three minutes of backoff per repository, which cancelled the Java client's job in the merge queue at its 15 minutes. Each tree's `.mvn/maven.config` now passes `-Daether.remoteRepositoryFilter.prefixes.resolvePrefixFiles=false`, so a job whose dependencies are cached sends Maven Central nothing, and `scripts/maven-sbom.sh` asks Google's mirror for the CycloneDX plugin on its first attempt and Maven Central only when the mirror refuses.
