- An action rendering draws the perform-actions swimlanes of the graphical notation (SysML v2 §8.2.3.17 `perform-actions-swimlanes`, `swimlane`): each node of a flow that one element performs — the owner of a `perform` action usage whose reference ends at the node — sits in a dashed lane headed «performer», the performer's feature chain (`part0.part1`) and `perform actions`, the nodes nothing performs staying outside the lanes. Exposing a `perform a;` usage of a part draws the flow it performs under «perform action» with the performers declared in that part; an action several elements perform, and the action a rendering is drawn for, name their performers in a `performed by` compartment. Every form draws the lanes; the draw.io grid sets them side by side, attached and aligned.
