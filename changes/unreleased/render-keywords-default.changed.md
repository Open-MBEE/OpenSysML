- A rendering now draws the `«keyword»` line over each node's name by default (`«part def» GUI`, not `GUI`), the way the SysML v2 notation's examples, the pilot visualizer and SysON draw their nodes; `view.DefaultShown` is port symbols, compartments and keywords. `-render-show`, `show` and a document diagram's `show` attribute still add to that default, `all` still names every element, and a rendering specializing a standard `Views` rendering with `attribute showKeywords : Boolean = false;` still leaves the keywords out. The VS Code diagram panel stacks the line the way the notation and the other forms do, the `«keyword»` over the name rather than under it, and styles each label line by what it is rather than by its position, so a detail line under a node drawn without keywords is no longer styled as one.
