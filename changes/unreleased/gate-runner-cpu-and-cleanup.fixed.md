- **The local gate runner no longer multiplies a shard's CPU allowance by Go's package concurrency.** It passes `-p=1` by default, divides the shard's `GOMAXPROCS` by an explicit `-p` or a `GOFLAGS` `-p`, and preserves an explicit caller `GOMAXPROCS`, so concurrent package test binaries share one budget rather than each taking the whole one.
- **The runner keeps Go flags saved with `go env -w`.** `GOFLAGS` is read through `go env` before adding the runner's `-p`, so a saved build tag such as `sysml_re` still selects its test variant when the variable is not exported.
- **Cancelling the gate now stops engines that start their own process group.** Each shard runs in its own session and cancellation signals every process group still in it, not just the direct group, so a stand-in engine left handling an ignored cancellation no longer survives the interrupted run.
