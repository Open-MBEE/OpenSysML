- **`install.sh --tools all` and `install.ps1 -Tools all` install every tool the chosen release published.** `all` stood for the four tools of the current release, so on a release that predates one of them (`sysml-jupyter-kernel` before v0.10.0, `sysml-grpc` before v0.9.0) it failed to download the missing asset instead of installing the rest. Both scripts now resolve `all` against the release's `SHA256SUMS.txt`, install the tools it lists for the platform, and say which it lacks; a tool named explicitly on a release without it still fails.
