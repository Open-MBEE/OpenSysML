- The SysML v1 migrator writes a plain UML class (one with no SysML stereotype) as an `occurrence def` rather than a `part def`, a property typed by one as an `occurrence` (`ref occurrence` unless composite), and a plain class realizing an interface as a specialization of the interface's port def. Link actions are written as actions with their pins, an association end's qualifiers as features of the end, and a link between instances as an individual connection def.
