- **The release browser REPL module is the RE build again.** `make build-release-wasm` still named the retired `sysml_prod` tag, which Go treats as unset, so the module it wrote for the release, nightly and npm assets was the full DK build; it now uses `-tags sysml_re`, and a hygiene test checks that every `-tags` name in the Makefile, CI and scripts is a build constraint the tree declares.
