- **`SequenceFunctions::excludingAt` follows its library body.** The body, `(seq->subsequence(1, startIndex - 1), seq->subsequence(endIndex + 1))`, collects over an empty range for a start one past the end, an end past the end or an inverted range, so no `seq#(i)` is evaluated and nothing is removed: `(1, 2, 3)->excludingAt(4)` and `(1, 2, 3)->excludingAt(3, 2)` are `[1, 2, 3]`, `(1, 2, 3)->excludingAt(2, 9)` is `[1]` and `()->excludingAt(1)` is `()`, where the interpreter and the compiled Go and C programs reported `ErrIndexOutOfRange`. A wider inversion repeats the overlap of the two subsequences, `(1, 2, 3)->excludingAt(3, 1)` being `[1, 2, 2, 3]`. A start beyond size + 1 still reaches `seq#(size + 1)` and is that index error, an index `0` is still no `Positive`, and `subsequence` with an end past the end still evaluates the missing `seq#(i)` and fails.
