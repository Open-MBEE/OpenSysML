- A `while` loop body takes an `import`, an `alias` and a visibility-prefixed member, and a `loop`, `for`, `if` and `else` body an unprefixed `alias`, as a plain action body does: `while (n < 3) { private import Q::*; alias TT for Q::T; }` parses. The parser reported `unknown action keyword` for each before. An unprefixed `import` in these bodies is now reported for its missing visibility, as it is elsewhere.
