- The Go race suite runs its heavy, independent tests in parallel: the settled-collections sweep of `tests/export` runs one subtest per model, the slow top-level tests of `internal/exec/runtime` and `tests/export` call `t.Parallel()`, and the conformance snapshot and held-image round trips run their cases in parallel. The same tests run under the same race detector and coverage; a 4-CPU CI shard that used one CPU now uses all of them (the `export-settled` shard measured 1985 s → 551 s).
