- `x @@ T` now classifies the metadata of `x` as `x meta T` reads it, an annotation stated about the element as well as its own metaclass (KerML 1.0 §7.4.9.2: the operand of a metaclassification is `x.metadata`), so `Belt @@ Safety` over `#Safety part def Belt;` is `true` in an expression and `[@@Safety]` selects `Belt` in an element filter, where both previously held for the metaclass alone; `Belt @@ SysML::PartDefinition` and `belt @@ SysML::PartUsage` answer as before.
