- The .NET client generates typed C# interfaces and classes over a SysML model's definitions: `dotnet run --project client/dotnet/src/OpenMBEE.OpenSysML.Generate -- model.sysml -o ModelTypes.cs --namespace Acme.Model` (or `make dotnet-generate`) writes one interface per definition, extending every generated base, and a class inheriting the first, with a read-only property per feature typed from the model's type facts and multiplicity, or `Value` where no C# type is sound. An inherited property reads the feature that redefines it, whatever its name; a model that cannot be typed soundly (unrelated features meeting under one property name, a redefinition its property cannot read, two elements generating one C# name, a reference outside the documents) is refused naming the elements behind it. The file is deterministic and stamped with the generator's emission schema and a hash of the documents' names and exact bytes, and `--check` fails when it is out of date. Views are read through the new `OpenMBEE.OpenSysML.Typed` namespace, with `FeatureValueException`, `TypeMismatchException` and `InstanceTypeException` for what a view cannot read.
