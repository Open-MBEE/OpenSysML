- **A CI step that installs packages with apt fails within minutes when the Ubuntu mirror stalls, instead of hanging until the job's limit.** `apt-get update` against `archive.ubuntu.com` sat without a byte for an hour on the `Go race tests (model)` shard and for close to four hours on `MATLAB/Octave client tests`, so no test ran and the pull request showed red. Every workflow step that runs apt now goes through `scripts/ci-apt-install.sh`, which bounds each fetch (`Acquire::http::Timeout=30`, `Acquire::Retries=3`), makes a failed index fetch fail `apt-get update` (`APT::Update::Error-Mode=any`) rather than fall back to stale lists, bounds each `apt-get` command to three minutes and retries it three times; each such step also carries a ten-minute `timeout-minutes`, so the script reports its own failure before the step is cancelled. What the jobs install and test is unchanged.
