- **A CI step that installs packages with apt fails within minutes when the Ubuntu mirror stalls, instead of hanging until the job's limit.** `apt-get update` against `archive.ubuntu.com` sat without a byte for an hour on the `Go race tests (model)` shard and for close to four hours on `MATLAB/Octave client tests`, so no test ran and the pull request showed red. Every workflow step that runs apt now goes through `scripts/ci-apt-install.sh`, which bounds each fetch (`Acquire::http::Timeout=30`, `Acquire::Retries=3`), makes a failed index fetch fail `apt-get update` (`APT::Update::Error-Mode=any`) rather than fall back to stale lists, bounds `apt-get update` to three minutes and the whole fetch to eight, retrying three times, and downloads the archives before `dpkg` runs so an interrupted attempt only ever interrupts a download, which the next attempt resumes; each such step also carries a ten-minute `timeout-minutes`, so the script reports its own failure before the step is cancelled. The Octave job, whose 195 MB of archives a trickling mirror held for twelve minutes even so, additionally keeps the archives it installed from in the Actions cache and seeds apt from them on the next run, so the mirror is only asked for what changed. What the jobs install and test is unchanged.
