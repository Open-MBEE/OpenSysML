- **`GetElementProperties` spells a library member's membership by the id its library document writes.** An inherited membership of a standard-library member — named (`Parts::Part::...`) or unnamed (an `Occurrences::Occurrence` invariant or connector, a multiplicity range) — carries the owning-membership id the library's own form writes for it (the identity catalog's fixed id, `identity.AnonymousMemberOf` for an unnamed member) and its membership metaclass, and an unnamed library member its minted id, so every id an answer carries reads back through the RPC; such memberships had come back without an id on the symbol-backed path.
