- An accept action lists its payload among its outputs again (`accept r : Sig via p;` answers `output` = `r` on `sysml -query`, gRPC `Query` and an evaluation): the payload is `inout` as the `Actions::AcceptAction::payload` it redefines is (SysML v2 §8.3.17.2 `validateAcceptActionUsageParameters`), so an output as well as an input. The library `payload` it redefines is not listed beside it (KerML 1.1 §8.3.3.1.10 `inheritedMemberships`, `removeRedefinedFeatures`).
