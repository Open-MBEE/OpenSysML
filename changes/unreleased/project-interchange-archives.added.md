- **Project interchange archives (`.kpar`).** The zipped form of a project directory (KerML 1.0 §10.3) is read wherever a project directory is: named on the command line beside a model, under `-library-root` / `OPENSYSML_LIBRARY_ROOTS` / the language server's `libraryRoots` as an installed project a `.project.json` usage selects, and as `OPENSYSML_LIBRARY_PATH` in place of the bundled standard library (a `.kpar` or a directory of them, as the OMG publishes the library). Archives are read from memory, their `.project.json` and `.meta.json` checked (both at the top level, mandatory fields, usage resources, index and checksum members, checksums verified) before a member is read, and a malformed one is a diagnostic on the archive's path. `sysml -bundle <dir> [-o name.kpar]` writes a directory as an archive — sorted members and fixed timestamps, so two runs are byte-identical; a missing `.meta.json` is generated — and `sysml -unbundle <file.kpar> [-o dir]` writes one back into a new or empty directory.
