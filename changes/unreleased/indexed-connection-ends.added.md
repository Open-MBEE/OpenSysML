- An indexed connector end's element selector now survives the connect lowering, the RDF/API-JSON element form and the analysis model form. A lowered connection's ends keep the port path routing addresses beside the index expression and the node it was written from, so a quoted `'a.b'` stays distinct from the nested `a.b`. The connector's derived `sourceFeature`, `targetFeature`, `relatedFeature`, `source` and `target` still name the feature the end reference-subsets, as reflection derives them; the index is reachable from the ordered `connectorEnd` links, whose end elements carry `sysx:endElement`. The analysis model form writes each selector from its source extent in the declaration scope, so an index with local declarations or a quoted port reaches an engine intact. Routing still addresses the port, and the notation is unchanged.
