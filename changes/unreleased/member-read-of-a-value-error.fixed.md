- **A member read from a value says what it could not read, and from what.** `"a".b`, `(1, 2).x`, `null.x` or `n.isActive` on an Integer failed with `cannot chain through non-instance member  (string)`: no member, an empty name where the chain started at an expression, and the evaluator's own word for the value. The error now reads `cannot read member b: a String has no members`, or `cannot read member isActive of n: an Integer has no members` when the value was read from a feature.
