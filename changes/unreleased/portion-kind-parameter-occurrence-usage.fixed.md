- A usage whose prefix states `individual` or a portion kind (`snapshot`, `timeslice`) and no name — `in snapshot ;`, `out timeslice ;`, `individual : Vehicle1;` — now exports as `sysml:OccurrenceUsage` (api-json `"@type": "OccurrenceUsage"`) instead of `sysml:ReferenceUsage`, as the grammar's `IndividualUsage` and `PortionUsage` rules make it, and an unnamed enumerated value (`= 60.0;` in an `enum def`) exports as `sysml:EnumerationUsage`. A parameter also accepts both prefixes together (`in individual snapshot s : Vehicle1;`), which was a syntax error.
