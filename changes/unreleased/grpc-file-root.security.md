- **`sysml-grpc -file-root <dir>` confines the files a request names by path.** The service read whatever `file_path` or `layout_path` a caller named, with no way to restrict it. Started with `-file-root`, it reads those files only under that directory, takes a relative path from it, and refuses a path elsewhere, a `..` out of it or a symbolic link that leads out of it with `PERMISSION_DENIED`. Without the flag nothing changes, so a client's own private service still reads any local model.
