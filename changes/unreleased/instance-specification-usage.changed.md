- The SysML v1 migrator writes an InstanceSpecification as one usage typed by its classifiers — `part myCar : Vehicle { attribute :>> mass = 1350.5; }` — with the usage kind following the classifier (`item`, `occurrence`, `constraint`, `port`, `attribute`), an instance of an actor, use case or requirement subsetting the classifier's usage, and an instance link as a `connection` usage between the instance usages typed by the association's `connection def`, as the OMG v1-to-v2 transformation does, in place of an `individual part def` specializing the classifiers. Slots holding instances are bound to the instance usages (`part :>> mcs = 'mcs 1';`), a property default naming an instance is written as its `default`, a simulation configuration's `target` subsets the target instance, and instance tables list the package-owned usages of the classifier.
