- A name in a declaration's header now resolves in the local namespace KerML 1.1 §8.2.3.5.2 gives the relationship that owns it. A `disjoint from`, `inverse of`, `unions`, `intersects` or `differences` name, like a `featured by` one, is found among the members the declaration inherits (`classifier C specializes Base disjoint from D;` with `D` declared in `Base`), and a feature chain there is placed by the name it opens with. A reference subsetting (`references`) or cross subsetting (`crosses`) is a Specialization and resolves from the namespace that owns the declaration: it no longer reaches a member of the declaration's own body, and a chain such as `crosses b.p` reads the sibling `b` rather than a namesake declared in that body.
