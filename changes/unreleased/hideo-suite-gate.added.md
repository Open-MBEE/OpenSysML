- The cross-MDK conformance suite [hideo67/sysmlv2-tests](https://github.com/hideo67/sysmlv2-tests) is run daily as an advisory ratchet: `./scripts/download-hideo-suite.sh` checks it out at a pinned commit, and `go run -C tools ./cmd/hideo-suite -check` runs its element-properties and Symbol readers from Python and Go against the tree and holds every case to its outcome in `docs/project/hideo-suite-baseline.tsv`, naming each case that got worse or better and reporting a reader that could not run as a provisioning failure rather than as regressions. It runs in the oracle-reproduction workflow, never on a pull request. See `docs/project/hideo-suite.md`.
