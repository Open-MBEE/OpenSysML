- **Queries answer a case's `boundSubject`.** A verification, analysis or use-case usage reports the qualified name of the declaration its subject binds — the target written by `subject :>> s = Structure::boilerAsMaintained;`, `subject s = Structure::spareBoiler;`, or a feature chain — on its query row. The answer is the bound declaration, not the subject parameter and not the case's run-time object; a case that binds nothing leaves the property absent. OSLC query text writes it `sysx:boundSubject`, and it joins the closed set of queryable properties. The declaration is resolved once per element and memoized, so listing every case's bound subject takes one Query and no per-row symbol lookup.
