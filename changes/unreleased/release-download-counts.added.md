- `scripts/release-downloads.py` prints the download counts of every GitHub release at once — per release with its date and asset count, per asset under each release (`--assets`), or totalled per asset name across all releases (`--by-asset`) — with `--stable` to leave out the nightlies, `--json` for another tool, and `--traffic` for the clones and views of the last fourteen days that GitHub's traffic API reports to a token with push access.
