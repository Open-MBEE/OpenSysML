- A graph stored before a bare `/* … */` at a member position was a `Comment` element carries the comment only in the next member's source text; converting such a graph back to notation now keeps the comment instead of silently dropping it. Repository sync no longer mints an id for an anonymous `Comment`, `Documentation` or `TextualRepresentation` (a bare comment, a `doc` body): the notation has no place to declare one, so it could not survive write-back.
