- `sysml-syntax`: a new command that serves the purely syntactic RPCs — `Parse` for a document's syntax diagnostics, `Format` for a `sysml`→`sysml` re-indent of inline content, and `Tokens` for LSP-encoded lexical semantic tokens — with no name resolution and no standard library, so its WebAssembly builds stay small enough to embed. On `GOOS=js` it installs `globalThis.sysmlSyntax.call(method, paramsJSON)` for a page to call synchronously; natively and under WASI it speaks the same `Content-Length`-framed JSON-RPC over standard input and output as `sysml-engine`. See `docs/reference/wasm.md`.
