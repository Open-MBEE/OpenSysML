- `SymbolInfo.child_ids` lists an unnamed member (`bind a = b;`, `connect a to b;`, `part : P;`, `@M { … }`) under the positional id the query API and the export give it (`Owner::@3`) instead of the owner's name with an empty last segment, `GetSymbol`, `Evaluate` and `Instantiate` resolve such an id, and the Python client's `Symbol.children()` raises `UnresolvedChildError` for a listed child the service cannot resolve instead of dropping it silently, so `children()`, `parts()` and `attributes()` agree with `model.query(scope=[owner])`. A `@M`/`#M` metadata usage now reports its metadata definition as its `type`.
