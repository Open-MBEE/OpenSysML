- **A send's `to` clause accepts any expression and addresses the object it yields.** `send m to cars#(2)`, `send m to garage.cars#(2)` or `send m to new Car()` now deliver to the objects the expression evaluates to — one copy per live object — where previously any receiver that was not a plain name or feature chain silently reverted to the sender itself. The same applies to a routed send's `to` clause: `send m via p to cars#(2)` keeps only the deliveries reaching those objects, and a name that is no receiving node of the sender is read as an object expression too. A receiver evaluating to no object, to a non-object value or to a destroyed object is a typed error, as is a routed send whose receiver object no connection reaches.
