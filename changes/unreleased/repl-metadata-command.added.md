- `%metadata <element-or-object>` lists, in the REPL and the Jupyter kernel, the metadata annotating a definition or usage — `about` annotations included — with each annotation's type and the values it binds or defaults. For an object (named, `#<id>`, or a path such as `car.fl`) it lists the annotations of the usage and types the object is made from, each under the element it annotates; an element with no annotations is told apart from an unresolved target, and a value that cannot be evaluated is reported in place.
