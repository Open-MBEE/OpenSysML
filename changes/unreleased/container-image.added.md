- Every release publishes the `openmbee/opensysml` container image to Docker Hub for `linux/amd64` and `linux/arm64`, tagged with the version and, for the newest stable release, `latest`: `sysml-grpc` is the entrypoint, on port 50051 with `/health` on 8081, and `sysml` and `sysml-lsp` are in `/usr/local/bin` beside it, all three stamped with the release's version. `make docker` builds the same image locally as `openmbee/opensysml:dev`.
