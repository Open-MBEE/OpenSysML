- **The workspace model no longer links the execution runtime or the document evaluator.** Building a runtime over a workspace's documents moved from `internal/workspace/model` to the new `internal/workspace/modelrt`, and rendering a workspace's document definitions (`RenderDocumentMarkdown`, `DocumentFiles`) to the new `internal/workspace/modeldoc`; the workspace model keeps the runtime-free half as `Workspace.Detach`. A product that only parses, resolves and validates no longer carries `internal/exec/runtime`, `internal/doc/*` or `internal/translate/filename`. No user-visible behaviour changes.
