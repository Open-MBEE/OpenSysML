- The Rust client refuses a value nested deeper than 128 levels with `Error::UnsupportedValue` on a default 2 MiB thread stack under every supported compiler, in a debug build too. The recursive `encode` frame carried the wire construction of every value kind, so it took 12 KiB a level under Rust 1.83 and 14.6 KiB under Rust 1.99, where the frames of a refused value overflowed the stack and aborted the process before the guard answered. The nesting kinds and the scalar kinds are now encoded off the recursive frame, which takes about 2.7 KiB a level.
