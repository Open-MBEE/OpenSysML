- The REPL session resolves an import or qualified reference whose first segment nothing declares against a workspace root: the `.sysml`/`.kerml` file under it declaring that root namespace loads as `%load` would, in the same submission, and `%eval`/`%calc` do the same for the names they are given. `sysml` roots the prompt at the directory it was started in, the Jupyter kernel at the notebook's directory, and `session_open` over MCP takes an optional `root`; `%workspace` shows the root. A file loaded this way is listed, replaced by redeclaring its package and dropped by `%clear` like a loaded file, and left out of `%save`; two files declaring the same name load neither and are both named.
