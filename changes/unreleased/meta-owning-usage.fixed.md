- `Usage::owningUsage`, `Usage::owningDefinition`, `usage` and `directedUsage` are derived on reflective `meta` values, so `(occ1 meta SysML::OccurrenceUsage).owningUsage->size()` evaluates instead of failing with `reflective feature is not derived`: a usage a definition owns answers `owningDefinition`, one nested in a usage `owningUsage`, one a package owns neither; `usage` and `directedUsage` are the usages among a type's `feature` and `directedFeature`.
