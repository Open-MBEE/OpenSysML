- Every query surface can write its answer as a `QVTS::QueryResult` view: `sysml -run-query`, `-run-inline-query` and `-query` take `-as-view <file|->`, the REPL's `%run-query` and `%query` a leading `-as-view`, and the `RunDocumentQuery` and `Query` RPCs an `as_view` request field that fills `result_view` (capability `query_result_view`; Go, Python and Java clients). The view exposes the selected elements and states the query, source, outcome and provenance; a path or model error — an OSLC query's unknown property included — writes a view of that outcome exposing the elements the failure is about. The `QVTS` library ships with the OpenSysML Libraries.
