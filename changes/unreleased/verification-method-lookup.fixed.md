- **An unresolved library name now names the import that makes the bare name visible.** When exactly one importable candidate matches, an unqualified name's message ends `To use the bare name, import its package: private import <pkg>::*;`, and a qualified name with an unresolvable first segment reports `"<first>" is not visible here; did you mean <candidate>?` with the same sentence plus fixes to rewrite the segment or add the import.
- **A metadata body's `kind = …` exports as a MetadataBodyUsage.** The member carries no `sysml:declaredName`, owns a Redefinition of the metadata definition's feature via `sysml:redefines`, and is flagged `sysx:isRedefinitionImplicit` (SysML.xtext MetadataBodyUsage); the graph reads back as the bare form.
