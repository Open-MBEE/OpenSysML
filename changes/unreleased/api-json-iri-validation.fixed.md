- `sysml -convert` from `api-json` now refuses an `@id`, `@type`, member key or reference id holding a character an IRI cannot (a space, a control, or one of `<>"{}|^`, a backtick or a backslash), naming the text and the character, where it used to write Turtle that did not parse or that read back with statements the document never made. The Turtle writer also writes such a character in any IRI as its `\u` escape and the reader reads the `\u` and `\U` escapes of an IRI reference (RDF 1.1 Turtle § 6.5), so a graph built from unchecked text still round-trips as the triples it held.
