- An unrestricted name is the characters its escape sequences denote (KerML 1.1 §8.2.2.3): `part 'it\'s' : Pt;` declares `it's`, where the parser kept the backslash and every surface derived from the name carried it or escaped it a second time. The API-JSON and Turtle `declaredName` now read `it's`, the API-JSON `qualifiedName` and the `-run-query -json` table `Observatory::Holder::'it\'s'` (was `'it\\\'s'`), and the elementId `Observatory__Holder__it_27s` (was `…it_5c_27s`), so **the elementId and IRI of an element whose name, or an owner's, is written with an escape sequence change**. The same holds for `\\`, `\"`, `\b`, `\t`, `\n`, `\f` and `\r`; notation written from a model escapes the name again, so `-convert sysml` round-trips.
