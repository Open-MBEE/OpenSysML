- **Two positional allowances are parse errors rather than `nonstandard-notation` warnings.** An `assume`/`require` member outside a requirement or case body, and a one-ended `first <node>;` outside an action body, now produce a syntax diagnostic with an `ErrorNode` in the tree, matching how the other removed extension spellings report.
- **The `nonstandard-notation` warning for the state-machine keywords names the standard replacement.** `choice pick;`, `junction j;` and `history`/`shallow history`/`deep history h;` each report the `StateMachines` metadata spelling to write instead — `#choice state pick;`, `#junction state j;`, `#shallowHistory state h;`, `#deepHistory state h;` — and carry a quick-fix that rewrites the member and adds `private import StateMachines::*;` where it is missing.
- **The SysML v1 migrator writes the `StateMachines` pseudostate spellings.** A migration emits `#StateMachines::choice state`, `#StateMachines::junction state`, `#StateMachines::shallowHistory state`, `#StateMachines::deepHistory state` — qualified so a member named like the metadata cannot shadow it — and adds `private import StateMachines::*;` to each package holding one, under `-strict` the same as by default.
