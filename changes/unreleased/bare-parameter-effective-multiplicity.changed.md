- **A parameter that writes no multiplicity takes its §7.6.3 effective multiplicity.** A bare `in x : T;` no longer requires an argument: it takes the effective multiplicity of what it redefines or subsets, else the implicit `[1..1]` where it qualifies (a type-owned `attribute`/`item`/`part`/`port` that subsets or redefines no feature a type owns), else `[0..*]` — which invocation treats as optional exactly as an explicit `[0..*]`. Parameters that write `[1]`, `[1..1]` or `[1..*]`, and `in attribute x : T;` under the implicit rule, stay required and still raise `unbound parameter` when bound by nothing.
