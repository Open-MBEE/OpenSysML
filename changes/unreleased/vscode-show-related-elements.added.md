- The VS Code diagram panel shows a drawn node's related elements without editing the view: "Show related elements…" on a node's context menu lists what relates to it by relationship kind with counts, and the elements chosen are drawn and marked as included, until "Hide from diagram" leaves them out again; nothing is written to the `.sysml` file. Behind it, `opensysml/render` takes an `include` parameter (capability `openSysmlRenderInclude`) drawing elements as if the view exposed them and marking each node `included`, and the new `opensysml/relatedElements` request (capability `openSysmlRelatedElements`) groups an element's generalizations, specializations, types, typed usages, owner, owned members, connections, flows, bindings and successions.
