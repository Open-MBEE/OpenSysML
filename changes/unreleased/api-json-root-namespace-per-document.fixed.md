- **Give each document of a model its own root Namespace in the API element form.** A model of several documents converted to `api-json` wrapped every document's top-level elements in one unnamed Namespace, named after the first document's root, so a package declared in `app.sysml` was owned by the namespace of `lib.sysml`. Each document is a `RootNamespace` of its own in the textual grammar, and the pilot serializes one per document; the element form now writes one per document (`sysx:sourceDocument`), and reading it back drops each.
