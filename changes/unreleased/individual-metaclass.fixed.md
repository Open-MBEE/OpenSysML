- An `individual def` is exported as the `OccurrenceDefinition` it is, and an `individual` usage as an `OccurrenceUsage`, each with `isIndividual` (SysML.xtext `IndividualDefinition returns SysML::OccurrenceDefinition`, `IndividualUsage returns SysML::OccurrenceUsage`), in place of the `IndividualDefinition`/`IndividualUsage` names the metamodel does not declare — so the API-JSON writer, which reads a property's cardinality from the metaclass, lists their `ownedRelationship` and the other collection-valued properties as lists. The keyword reads back verbatim (`individual def X`, not `individual occurrence def X`), and a Turtle typed the old way still converts.
