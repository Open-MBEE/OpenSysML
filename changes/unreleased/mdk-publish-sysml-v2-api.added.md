- The Magic MDK plugin can publish a Cameo project to a SysML v2 API server such as Flexo MMS: *Publish to SysML v2 API…* on the context menu converts the model (a v1 project is migrated first) to the API's JSON and commits what the chosen project branch lacks or holds differently, creating the project when no id is given and deleting elements the model dropped only on request. The server defaults to `FLEXO_SYSMLV2_URL` and the bearer token to `FLEXO_INTEROP_TOKEN`; the token is never stored, is refused over plain `http://` to another machine unless `FLEXO_ALLOW_PLAIN_HTTP=1`, and does not follow a redirect off the server. A branch that moved since the last publication is reported before anything is written. Publication is one-way; reading a branch back into Cameo is not part of it (`editors/mdk/README.md` § Publish to a SysML v2 API server).
