- `CheckBehavior` RPC and `check_behavior` MCP tool: search every schedule of an action or state machine for violated properties, deadlocks, failures and divergent values, as `sysml -check-property` does. The request carries the CLI's `-check-property`, `-check-diverge`, `-check-input`, `-check-assume`, `-check-witness`, `-check-depth`, `-check-states`, `-check-unroll` and `-check-timeout` as typed fields; the answer carries the verdict, the report lines, the search statistics, each violation, divergence and final outcome with the schedule that replays it, the witness files when asked for, and the engine's standing. The service advertises the `check` capability; the Go, Python, Node, Java, Rust, Julia and MATLAB clients expose it as `CheckAction`/`check_action` and `CheckStateMachine`/`check_state_machine`.
