- The RDF and API JSON writers now own the `Membership` through which a `FeatureReferenceExpression` names its referent and a `FeatureChainExpression` its target feature where the notation places it — before the result parameter, and between the operand and the result for a chain — and list it under `ownedMembership` as well as `ownedRelationship` (KerML 1.1 § 8.2.5.8.3 `FeatureReferenceMember`/`FeatureChainMember`; `referent` and `targetFeature` are derived from it, § 8.3.4.8.5 and § 8.3.4.8.4). The `Membership` a `MetadataAccessExpression` or an invocation owns to the element it names is an `ownedMembership` too. Previously the writer restated the derived edge as a `Membership` appended after the result and absent from `ownedMembership`.
