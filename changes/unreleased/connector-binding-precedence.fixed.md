- A binding an outer part states for a connected port now displaces a connector end body's `default =` for it, whether the default evaluates or fails (`bind inner.k.dst.voltage = supply.src.voltage` gives `28` over an inner `attribute :>> voltage default = 12;` or `default = 1 / zero;`), and an anonymous interface's bindings through its own features (`interface : ThroughShared connect s.src to k.dst;` with `bind a.voltage = shared; bind shared = b.voltage;`) now reach the connected port as a named one's do.
