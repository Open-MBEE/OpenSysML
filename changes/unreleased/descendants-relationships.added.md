- `DocumentQueries::Descendants` takes `relationships = true` (OpenSysML Libraries pin at its merge of Open-MBEE/OpenSysML-Extensions-Library#19): the walk follows ownership as KerML 8.3.2.1 defines it — each element's `ownedRelationship`, then the related elements each relationship owns — so a document query reaches the memberships, specializations, typings, feature values and imports that own a model's elements, and the implied elements those own (a connector's ends, a port definition's conjugated definition, a satisfy usage's subject); the default `false` keeps every existing query reading the owned members as before.
