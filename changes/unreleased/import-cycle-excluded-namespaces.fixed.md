- Name resolution computes a namespace's imported memberships with the namespaces already being read excluded, as KerML 8.3.2.4.5 `Namespace::importedMemberships` and 8.3.2.4.6 `NamespaceImport::importedMemberships` state: on a cycle of imports a membership no longer returns to its namespace through the cycle, so with `package C1 { public import all C2::*; private part def P; }` and `package C2 { public import all C1::*; }` a `private import C1::*;` no longer brings `P`, nor does `C1::P` name it. Unqualified and qualified names, `expose` and the expanded index agree.
