- **A usage declared without a kind keyword is now classified as a referenceUsage.** `x : Integer;`, `ref x : Integer;` and direction-prefixed parameters (`in energy : …`) carry the `referenceUsage` kind and report `@type = ReferenceUsage`, matching what RDF export already wrote (SysML v2 §7.6.3–7.6.4); `attribute`-keyword usages keep `attributeUsage`. Every consumer that treated a kindless usage as an attribute still does — only the metamodel name and the symbol kind differ.
