- **The SysML v1 migrator writes a ReadSelfAction's result as an `out` feature bound to `this`.** The action was written with no body and its readers named `this` themselves; its result pin is now the `out` feature the mapping writes, bound to `this` (or to the context parameter in a definition's body).
- **A structural feature read or write inside a structured node acts on the object it is given.** `this` inside a structured node is the behavior's context rather than the node, and an object a flow brings into the node from outside is read through the object pin instead of being taken for `this`.
- **A ReadSelfAction's result flows to the pins it feeds.** An object flow from the result into an action input or call argument was dropped, leaving the input without a value; it is now written as a flow from the result. A node named `this` is renamed, since every action inherits `this`.
