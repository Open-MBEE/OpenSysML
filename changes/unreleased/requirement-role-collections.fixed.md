- A requirement's `actors` and `stakeholders` collections hold the objects its actor and stakeholder parameters hold, and a case's `actors` its actor parameters: a referential collection (`ref part actors : Part[0..*]`) now holds what the features implicitly subsetting it hold, as a composite one already did, so `%features`, `%eval` and a model's own reads (`sys.r.actors.id`) see the members instead of an empty collection. `%features` lists such a collection as soon as every member filling it is held.
