- **A flow's ends export as `FlowEnd`s.** In the Turtle and API JSON forms, each end of a `flow` or `succession flow` was a `ReferenceUsage` subsetting the whole chain it named. It is now a `FlowEnd`, as the grammar's FlowEndMember says: its `ReferenceSubsetting` names all but the last segment and its owned FlowFeature redefines the last, so `a.p.fuel` subsets `a.p` and redefines `fuel`. The ends read back as written, from the graph alone too (#651).
