- **The migrator no longer writes a `DiagramLayout::Layout` for an association or connector end's symbol.** On a block definition diagram Cameo keeps a member end's role symbol — a 10×10 box at the end of the line — inside the association's symbol; the migration wrote it as a `Layout` of the end property, so a tree rendering drew every part property whose association the diagram shows as a tiny nested node under its definition, as well as on the composition edge. A shape nested in a path symbol is now counted as lying on the connection on every diagram kind, as it already was on use case diagrams: no `Layout` is written for it, and the report's placement line and each diagram's note say how many symbols lay on connections. The association's line now carries the position instead: on a tree rendering an anonymous association, written as its member-end properties, is routed as a `Route` about the classifier-owned end the view exposes — the part usage the rendering draws as the composition edge — where it was counted as having `no v2 member`. A property drawn as its own box in a block's compartment keeps its `Layout`.
