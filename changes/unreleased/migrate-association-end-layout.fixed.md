- **The migrator no longer writes a `DiagramLayout::Layout` for an association or connector end's symbol.** On a block definition diagram Cameo keeps a member end's role symbol — a 10×10 box at the end of the line — inside the association's symbol; the migration wrote it as a `Layout` of the end property, so a tree rendering drew every part property whose association the diagram shows as a tiny nested node under its definition, as well as on the composition edge. A shape nested in a path symbol is now counted as lying on the connection on every diagram kind, as it already was on use case diagrams: no `Layout` is written for it, and the report's placement line and each diagram's note say how many symbols lay on connections. The association's line carries the position instead: its `Route` is pinned to the connection def the association is written as, with the points run from the def's first end's type to its second's — the direction a tree rendering reads a connection def's route in — whichever way the diagram drew the line, so the composition edge follows the line from the owning block's box. A property drawn as its own box in a block's compartment keeps its `Layout`.
