- **`sysml-mcp` runtime tools.** The `runtime` group serves the one-shot service as tools, one per RPC with the RPC's contract: `parse`, `symbol`, `evaluate`, `instantiate`, `execute_action`, `execute_state`, `evaluate_calc`, `verify_constraint`, `verify_requirement`, `verify_satisfaction`, `validate_instance`, `run_analysis`, `run_sweep`, `query`, `run_document_query`, `render_model_document`, `render_model_view`, `export_graphs`, `convert`, `migrate`, `apply_edits`, `list_engines` and `server_info`. Arguments are the request message under its proto JSON names; the structured result is the response as protojson writes it, beside a readable text. Every tool taking a `modelHash` also takes `paths` and inline `sources` and parses them first, so one call suffices; a refused call keeps the status code's name (`NOT_FOUND`, `UNIMPLEMENTED`) and message, and the long-running tools report progress to a client that asks for it.
