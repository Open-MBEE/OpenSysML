- The one-type rule now covers the whole requirement and rendering usage families: a `concern`, `frame concern`, `satisfy requirement` and `objective` are requirement usages (`requirementDefinition : RequirementDefinition [0..1]`) and a `render` is a rendering usage (`renderingDefinition [0..1]`), so a second effective type on any of them is reported with the pilot's requirement or rendering message instead of passing silently (#1885).
