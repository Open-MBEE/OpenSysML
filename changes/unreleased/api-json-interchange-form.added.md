- `sysml -convert api-json -interchange` writes the element form as the normative OMG `SysML.json` describes it (KerML 1.0 §10.4): uuid ids, only the properties of each element's metaclass, and every derived property stated, an empty one as `[]` or `null`, the inherited members included; the mapping's `sysx:` keys are left out. Of the 6,605 elements of the conversion fixtures 5,568 now validate against the schema, where none did; a derived property the implementation does not yet derive stays absent. The default `api-json` output is unchanged.
