- `sysml -convert api-json -interchange` writes the element form as the normative OMG `SysML.json` describes it (KerML 1.0 §10.4): uuid ids, only the properties of each element's metaclass, and every derived property stated, an empty one as `[]` or `null`, the inherited members included; the mapping's `sysx:` keys are left out, except on an element the mapping types outside the metamodel (a `//` note as `sysx:Note`, a pseudostate as `sysx:Pseudostate`), which is written as the default form writes it. Of the 6,691 elements of the conversion fixtures 5,654 now validate against the schema, where none did; a derived property the implementation does not yet derive stays absent. The default `api-json` output is unchanged.
