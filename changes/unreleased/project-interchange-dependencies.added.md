- **Installed dependency projects are found.** A directory holding a `.project.json` is an OMG project interchange project (KerML 1.0 §10.3). When a loaded file belongs to one, the installed projects its `usage` entries name are looked for under the project's well-known library directories (`.sysand/lib` for a sysand project) and under any directory `sysml -library-root`, `sysml-lsp -library-root`, `OPENSYSML_LIBRARY_ROOTS` or the language server's `libraryRoots` setting names, matched by their own `.project.json` (publisher and name against the usage's resource IRI, the latest installed version unless the constraint names one exactly), and their usages followed in turn. `sysml -validate <project directory>` loads the project's files and those of the projects it uses; a file named alone has its imports looked for in its project and the projects that uses, and a file inside an installed project finds the projects installed beside it. The language server indexes the same projects for a workspace folder, so their names resolve in the editor. Unrelated hidden directories stay skipped, the standard library's `.kpar` usages are answered by the bundled library, and no lock file is read.
