- A `drawio` rendering form writes a view as an uncompressed diagrams.net (draw.io) file that draw.io desktop, diagrams.net and the VS Code draw.io extension open and edit: tree, interconnection, state, action, case, mixed, requirement, definition and package renderings, with the §8.2.3 notation's node and edge glyphs, nested parts and regions as container children, ports on the border, stated positions, routes, colours and fonts, notes and pictures, and every cell tagged with the element's qualified name and declaration for later tooling. A view with no stated layout sits on a grid until draw.io's Arrange › Layout, or `drawio --normalize --layout elkLayered`, arranges it. The form is offered wherever forms are: `-render-form drawio`, the REPL's `%render` and `%viz`, the LSP and MCP `render` requests, and the VS Code export picker.
