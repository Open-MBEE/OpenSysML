- **The Node client refuses a repository, release tag or asset name that would change the release URL it builds.** `$OPENSYSML_GITHUB_REPO` and `$OPENSYSML_GRPC_VERSION` were placed into the download and releases-API URLs as they stood, so a value holding `?`, `#`, an extra `/` or `..` fetched a different path or query. The repository must now be `owner/name` and the tag and asset a single path segment; anything else is a `DownloadError` before a request is made.
