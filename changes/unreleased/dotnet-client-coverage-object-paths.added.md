- The .NET client reads the coverage an exploration or a check reports and the object an OSLC query selects. `Exploration.Coverage` and `CheckSearch.Coverage` hold every state entered and transition taken over all the runs or searched schedules, each a `CoverageEntry` with its instance path, its declaration and how many runs did so, and are null when the service reported none; a `QueryElement` an OSLC query selecting held objects answers carries the object's `Path`.
