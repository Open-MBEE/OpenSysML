- **`then [m] x;` in an action body is accepted, with the multiplicity on the target end.** The SysML v2 grammar lets the target a `then` references carry a crossing multiplicity (`then [0..1] b;`, `then [1] b { … }`, `then [m] done;`, and beside a source multiplicity as `[1] then [0..1] b;`), the same end `succession first a then [0..1] b;` states; the pilot implementation accepts these and OpenSysML rejected them with "a multiplicity in an action body must precede `then`". The parser now records the target multiplicity, the semantic model carries it on the target end, RDF export writes it on the target connector end and reads every form back without source text, and the end-feature-multiplicity warning stays limited to source ends. A multiplicity that opens a body member with no succession end to belong to is still rejected, with a diagnostic naming both valid placements.
