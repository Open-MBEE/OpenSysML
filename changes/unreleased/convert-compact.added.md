- **Convert to a compact form of API JSON over the service.** `ConvertRequest.compact` writes `api-json` from notation as one `api-json-compact/1` object in place of the element array: a table of the element ids, each written once, and the elements with every reference spelled as an index into it, unindented. `omit_derived` also leaves out the metamodel's derived properties, except the ones `keep_derived` names. Expanded it is the element array, and it composes with `documents`. Ids and references are most of the bytes of a large model, so a client that reads one receives a fraction of them. Reported as the `convert_compact` capability.
