- The semantic model holds the binding connectors the semantic constraints require, each with its two ends and the feature chain it relates (KerML §8.4 Table 11, SysML v2 §8.4 Table 33): for a feature value, a feature reference expression, the result of a function or an expression, an invocation of a behavior, and the succession and the source of a transition. It holds as well the chain an end owning a cross feature crosses (Table 9 `checkFeatureCrossingSpecialization`), the feature a feature chain expression nests in its source parameter with its two redefinitions, and the chain the result of that expression, or a feature valued without a specialization, subsets. A transition's first parameter and its link feature redefine `transitionLinkSource` and `transitionLink` and answer those names, and the succession a transition owns subsets `Occurrences::happensBeforeLinks`. These elements are read through the semantic model only: no name resolves to them, and element ids and the default export are unchanged.
